# 30분 퀵스타트

README 의 5단계를 조금 더 자세히 풀어 쓴 것입니다. **처음 한 번만 하면 됩니다.**

---

## 준비물

- Claude 데스크탑 앱
- `설정` → `기능` → **「클라우드 코드 실행 및 파일 생성」이 켜져 있어야** 합니다. 꺼져 있으면 스킬도 파일 만들기도 안 됩니다

---

## 1. 파일 받기 — 3분

초록색 `Code` → `Download ZIP` → 압축 해제.

**주의** — 파일 이름에 오른쪽 클릭해서 「다른 이름으로 링크 저장」을 하면 **웹페이지가 저장됩니다.**
파일 이름을 **왼쪽 클릭**해 들어간 뒤 오른쪽 위 **아래 화살표(⤓)** 가 맞는 길입니다.

## 2. 프로젝트 만들기 — 5분

프로젝트는 **그 일만 하는 전용 책상**입니다. 지침을 한 번 붙여두면 그 안의 모든 대화가 그 규칙을 따릅니다.

1. 왼쪽 사이드바 → `프로젝트` → 새 프로젝트
2. 이름은 「슬라이드 만들기」 정도로
3. `지침 편집` 을 열고 **`design-system.md` 전문을 붙여넣기**

**이렇게 되면 성공** — 지침란 아래에 글자 수가 표시되고, 프로젝트 화면에 지침이 저장됩니다.

> 대화창에만 붙여넣으면 **그 대화 하나에만** 적용됩니다. 다음 대화에서 다시 흔들립니다.

## 3. 스킬 3개 올리기 — 7분

`설정` → `사용자 지정` → `스킬` → 우측 상단 `추가` → `스킬 업로드`

`skills/` 아래 세 폴더의 **`SKILL.md` 를 하나씩** 올립니다.

**이렇게 되면 성공** — 스킬 화면에 세 줄이 늘어납니다. 보안 검사에 1~2분 걸리고, **새 대화부터** 적용됩니다.

> 「사용자 지정」이 안 보이면 설정 창 **왼쪽 위 검색칸**에 `스킬` 을 쳐 보세요. 창이 작으면 목록 맨 아래가 잘립니다.

## 4. 브랜드 바꾸기 — 5분

`brand.config.md` 를 메모장이나 VS Code 로 열어 바꿉니다.

| 무엇 | 어떻게 |
|---|---|
| 색 | `Primary` → `PrimaryLight` → `PrimaryLighter` 를 **밝기 순서가 유지되게** 함께 바꿉니다 |
| 서체 | `BodyFont` 를 바꿉니다. **발표할 PC 에도 설치**해야 합니다 |
| 로고 | `assets/logo-placeholder.png` 를 **같은 파일명으로** 덮어씁니다 |

바꾼 `brand.config.md` 는 프로젝트 **지식(컨텍스트)** 에 파일로 올려두면 Claude 가 매번 읽습니다.

## 5. 시켜보기 — 10분

프로젝트 안에서 새 대화를 열고:

```
이 자료로 5장짜리 덱을 만들어줘. design-system.md 규격을 지켜줘.
먼저 HTML 미리보기를 보여주고, 승인하면 pptx로 만들어줘.
```

**이렇게 되면 성공** — 다섯 장 전부 제목이 같은 높이에서 시작하고, 아래쪽이 비지 않고, 금액에 콤마가 들어가 있습니다.
