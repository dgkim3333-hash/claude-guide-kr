# 주간 회의록 정리

## 언제 쓰나

회의에서 오간 말을 그대로 붙여넣으면, 아래 정해진 형식의 회의록으로 바꾼다.
메모가 토막글이어도 된다. 문장이 아니어도 된다.

## 무엇을 하나

1. **결정된 것**과 **아직 안 정해진 것**을 반드시 갈라 적는다.
   회의록에서 사고가 나는 곳은 대부분 "정해진 줄 알았는데 아니었던 것"이다.

2. **할 일에는 담당자와 기한을 붙인다.**
   회의에서 말이 안 나왔으면 비워두지 말고 `담당자 미정` · `기한 미정` 이라고 쓴다.
   빈칸으로 두면 아무도 안 본다.

3. **원문에 없는 내용을 지어내지 않는다.**
   맥락상 그럴 것 같아도 쓰지 않는다. 대신 「확인 필요」에 적는다.

4. 금액은 원 단위로 쉼표를 찍는다. 예: `358,000,000원`

## 출력 형식

```
# 회의록 — {주제}

일시 : {날짜}
참석 : {이름들. 없으면 "기록 없음"}

## 결정된 것
- {한 줄에 하나. 누가 무엇을 하기로 했는지가 아니라, 무엇이 정해졌는지를 쓴다}

## 아직 안 정해진 것
- {다음 회의로 넘어간 것. 왜 안 정해졌는지도 한 줄로}

## 할 일
| 무엇을 | 누가 | 언제까지 |
|---|---|---|
| {할 일} | {담당자 또는 담당자 미정} | {기한 또는 기한 미정} |

## 확인 필요
- {원문만으로는 판단이 안 되는 것. 없으면 이 절을 통째로 뺀다}
```

## 예시

**Input**

```
오늘 회의. 신제품 출시 일정 얘기함.
마케팅에서 3월은 무리라고 함. 4월 중순으로 미루기로 결론.
예산은 김부장이 다음 주까지 다시 뽑아오기로.
패키지 디자인은 아직 얘기 못 했음.
```

**Output**

```
# 회의록 — 신제품 출시 일정

일시 : 기록 없음
참석 : 기록 없음

## 결정된 것
- 출시 일정을 3월에서 4월 중순으로 변경

## 아직 안 정해진 것
- 패키지 디자인 — 이번 회의에서 논의하지 못함

## 할 일
| 무엇을 | 누가 | 언제까지 |
|---|---|---|
| 예산 재산출 | 김부장 | 다음 주 |

## 확인 필요
- 「4월 중순」의 정확한 날짜
- 「다음 주」의 기준 요일
```

## 하지 말 것

- 참석자를 추측해서 채우지 않는다. 없으면 `기록 없음`
- 「~하기로 함」과 「~하면 좋겠다」를 같은 칸에 넣지 않는다. 뒤엣것은 결정이 아니다
- 회의록을 요약하지 않는다. 짧게 만드는 것이 목적이 아니라 갈라놓는 것이 목적이다
