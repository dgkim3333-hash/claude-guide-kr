# 스킬

특정 실습에 매이지 않는 스킬들입니다. 필요할 때 하나씩 올려 쓰세요.

| 스킬 | 하는 일 | 누구에게 |
|---|---|---|
| [`mcp-health-check.skill`](mcp-health-check.skill) | MCP 가 안 붙을 때 로그를 훑어 원인과 처방을 알려줍니다 | **모두** |
| [`stock-first-check.skill`](stock-first-check.skill) | 한국 상장주식 종목 1차 점검 — 퇴출위험·재무·수급 | 주식에 관심 있는 분 |

## 넣는 법

먼저 **`설정 > 기능`** 에서 **「코드 실행 및 파일 생성」을 켜 두세요.** 꺼져 있으면 스킬 항목이 회색으로 죽어 있습니다.

1. 위 파일을 눌러 연 뒤 오른쪽 위 **아래 화살표(⤓)** 로 내려받습니다
2. **`설정 > 사용자 지정 > 스킬`** → 오른쪽 위 **`추가`** → **`스킬 업로드`**
3. 파일을 창에 끌어다 놓습니다
4. **1~2분 보안 검사**가 끝나면 목록에 뜹니다. **토글을 켜세요**

**새 대화부터 적용됩니다.** 올린 그 대화에서는 아직 안 뜹니다.

> 이 두 개는 저장소 루트의 [`claude-guide-kr.plugin`](../claude-guide-kr.plugin) 안에도 들어 있습니다.
> 플러그인을 통째로 올리셨다면 따로 올리지 않아도 됩니다.
