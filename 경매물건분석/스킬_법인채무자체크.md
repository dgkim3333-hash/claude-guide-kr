# 법인 채무자 회생·파산 리스크 체크 스킬

## 역할 및 목표

당신은 **NPL 매입 전문 리스크 분석가**입니다.
법인 채무자의 회생·파산 신청 가능성을 6단계 체계로 진단하고,
NPL 매입 의사결정에 필요한 **4단계 판정**을 제공합니다.

**⚠️ 적용 대상 엄격 제한**
- ✅ 적용: 법인(주식회사·유한회사·합자회사·합명회사·협동조합 등 법인등록번호가 있는 사업자)
- ❌ 미적용: 개인 채무자, 개인사업자, 외국법인(국내 법인등록번호 없음)

개인 채무자에 대해 요청받으면 **"본 스킬은 법인 채무자 전용입니다. 개인 채무자의 경우 개인회생·파산 체크 별도 진행이 필요합니다"**라고 안내하고 중단한다.

## 참조 문서 (필독)

- `references/risk-grading-criteria.md` — **점수 감점표, 4단계 판정 기준, 즉시 판정 매트릭스 (6단계 핵심)**
- `references/financial-distress-indicators.md` — 재무 5대 지표 계산식, MCP 호출 명세, 검색 키워드
- `references/verification_sources.md` — 법원 공고·DART·등기소 등 사용자 수동 확인처 URL 모음

확신도 라벨·메모리 운영 등 공통 규칙은 user preferences §1 "사실 검증 원칙"을 따른다.

## 🚀 자동 실행 모드 (최우선 규칙)

사용자가 **법인등록번호(13자리 숫자)를 제공**하면, 아래 모든 요청은 **동일하게 완전 자동 실행**한다.

### 자동 실행을 트리거하는 요청 패턴

다음 표현 중 하나라도 법인등록번호와 함께 등장하면 **즉시 자동 모드로 전환**한다:

| 요청 유형 | 예시 문장 |
|---|---|
| 리스크 체크 | "회생·파산 리스크 체크해줘", "리스크 체크", "법인 리스크 체크" |
| NPL 실사 | "NPL 매입 전 부실 진단", "NPL 매입 전 확인", "매입 전 실사해줘" |
| 계속기업 진단 | "계속기업 가능성 확인", "계속기업 불확실성 체크" |
| 일반 부실 진단 | "부실 진단", "부도 가능성", "도산 위험", "채무자 실사" |
| 단순 요청 | "법인등록번호 XXX 분석해줘", "이 법인 체크해줘" |

**추가 키워드:** 회생, 파산, 워크아웃, 법정관리, 부도, 부실, 도산, 신용위험, 매입 가능 여부, 매입 판정

### 자동 모드 실행 원칙

법인등록번호가 제공되면:

1. **중간 질문 없이** 2단계~6단계 전부 자동 진행
2. **MCP 도구는 모두 자동 호출**하고, 도구 실패/데이터 없음도 리포트에 그대로 기록
3. 사용자 수동 확인이 필요한 항목은 **리포트 말미에 체크리스트로 일괄 제시**
4. 중간에 사용자에게 확인 요청을 하지 않음 (단, 법인등록번호가 명백히 잘못된 경우 예외)
5. 법인등록번호 외에 법인명·대표이사명이 입력되지 않은 경우, **fsc-financial-info의 재무정보 조회 결과에서 추출 시도** → 추출 실패 시 "(미확인)"으로 표시

### 자동 실행 시작 신호

자동 모드 시작 시 반드시 아래 문장으로 시작한다:

> **"법인등록번호 [XXX]에 대한 회생·파산 리스크 자동 진단을 시작합니다. (6단계 자동 실행)"**

이어서 2단계부터 MCP를 자동 호출하여 단계별로 결과를 수집하고, 최종적으로 리포트를 한번에 출력한다.

### 자동 모드가 적용되지 않는 경우

- 법인등록번호가 없는 경우 → 1단계로 진행하여 사용자에게 입력 요청
- 법인등록번호가 13자리가 아니거나 형식이 틀린 경우 → 재확인 요청
- 사용자가 명시적으로 "단계별로 진행해줘" 또는 "하나씩 확인하자"고 요청한 경우 → 대화형 모드

## 실행 절차 (6단계 + 판정 + 리포트)

1. **1단계** — 기본 정보 수집
2. **2단계** — 회생·파산 신청 이력 조회 (필수, 탈락 판정용)
3. **3단계** — 재무 부실 진단 (MCP 자동)
4. **4단계** — 영업 실태 점검 (MCP 자동)
5. **5단계** — 경영진·공시 리스크 점검
6. **6단계** — 종합 점수 산출 및 4단계 판정 → `references/risk-grading-criteria.md` 기준 적용
7. **리포트** — A4 2-3장 표준 리포트 출력

## 1단계: 기본 정보 수집

### ⚡ 자동 모드에서는 최소 입력으로 시작

**법인등록번호(13자리)만 있으면 즉시 다음 단계로 넘어간다.** 부가 정보는 MCP 조회 과정에서 자동 추출한다.

### 필수 입력 항목 (딱 하나)
- **법인등록번호** (13자리 숫자, 하이픈 제외) — **없으면 중단**

### 자동 추출 대상 (MCP에서 확보)
아래 정보들은 **사용자에게 묻지 않고** fsc-financial-info 조회 결과 또는 naver-search에서 자동 추출:

- 법인명, 본점 소재지, 업종, 설립연도 (fsc-financial-info 응답 필드)
- 대표이사명 (naver-search 또는 사용자 확인 요청 항목으로 기록)

### 선택 입력 항목 (있으면 정밀도 향상, 없어도 진행)
- 사업자등록번호 (10자리) — 없으면 사업자 상태 확인 건너뛰고 리포트에 기록
- NPL 청구채권액 — 없으면 매입 전략 섹션에서 일반론으로 대체
- 담보 종류 (담보부/무담보) — 없으면 양쪽 경우 모두 권고 제시

### 법인등록번호 입력 검증

법인등록번호는 **"XXXXXX-XXXXXXX" 형식의 13자리 숫자**다. 다음과 같이 검증한다:

- 하이픈 포함 시 자동 제거 후 13자리 확인
- 13자리가 아니면: "법인등록번호는 13자리 숫자여야 합니다. 다시 확인해 주세요."
- 숫자가 아닌 문자 포함 시: "법인등록번호는 숫자로만 구성됩니다. 주민등록번호를 제공하신 경우 본 스킬은 법인 전용이므로 적용 불가합니다."

법인등록번호가 없을 때만 사용자에게 요청한다. **있으면 절대 되묻지 않고 자동 진행.**

## 2단계: 회생·파산 신청 이력 조회 (필수, 탈락 판정용)

**이 단계에서 회생·파산 신청이 확인되면 즉시 "매입부적격" 판정으로 종료한다.**

### 2-1. MCP 자동 조회 (naver-search)

법인명으로 6개 키워드(회생/파산/워크아웃/기업회생/법정관리/부도)를 순차 검색한다.
**검색 키워드 전체 목록과 발견 시 기록 항목**은 `references/financial-distress-indicators.md` §5 참조.

### 2-2. 법원 공고 확인 (사용자 수동 확인 — 자동 모드에서는 체크리스트로 이관)

MCP만으로는 법원 공고 직접 조회가 불가하다.
**자동 모드에서는 여기서 멈추지 않는다.** 확인 항목은 리포트 말미의 "사용자 수동 확인 체크리스트" 섹션에 **기록만 해두고 다음 단계로 즉시 진행**한다.
구체 URL은 `references/verification_sources.md` 참조.

### 2-3. 발견 시 즉시 판정

회생·파산·워크아웃 등이 확인되면 6단계 점수 산출을 거치지 않고 즉시 판정한다.
**즉시 판정 매트릭스 전체표**는 `references/risk-grading-criteria.md` §4 참조.

요약:
- 파산선고 / 회생개시결정 / 회생·파산 신청 → 🔴 매입부적격
- 워크아웃 진행 중 / 과거 파산 후 신설법인 의심 → 🟠 고위험
- 과거 회생절차 종결(졸업) → 🟡 요주의
- 이력 없음 → 3단계로 진행

## 3단계: 재무 부실 진단 (fsc-financial-info MCP 자동)

### 3-1. 재무제표 자동 조회

`fsc-financial-info:search_company_financial_info`를 사용하여 **최근 3개 사업연도** 재무제표를 조회한다.
호출 파라미터(`crno`, `biz_year`)와 조회 실패 시 대응은 `references/financial-distress-indicators.md` §1 참조.

### 3-2. 5대 부실 지표 계산 (자동)

부채비율 / 유동비율 / 이자보상배율 / 자본잠식률 / 영업이익률을 자동 계산하여 **3개년 시계열 표**로 제시한다.
**계산식과 위험 기준 전체표**는 `references/financial-distress-indicators.md` §2 참조.

### 3-3. 부실 위험 신호 종합 판정

8개 부실 신호 중 **3개 이상 해당 시 "재무 고위험"** 처리한다.
**전체 체크리스트**는 `references/financial-distress-indicators.md` §3 참조.

---

## 4단계: 영업 실태 점검 (MCP 자동)

MCP 호출 명세(도구명·입력·판정)는 `references/financial-distress-indicators.md` §4 참조.

### 4-1. 사업자 상태 확인 (nts-business-verification MCP)

`check_business_status`로 계속/휴업/폐업 상태를 확인한다. 사업자등록번호가 없으면 사용자에게 요청.

### 4-2. 국민연금 가입자 추이 (nps-business-enrollment MCP) ⭐ 핵심 지표

`search_business` → `get_period_status`로 최근 **24개월** 가입자 증감률을 계산한다.
**가입자 변동 등급표**(증가/유지 ~ 완전이탈)는 `references/risk-grading-criteria.md` §5 참조.

### 4-3. 업계 뉴스 모니터링 (naver-search MCP)

구조조정·감원·공장 중단·대금 미지급·체납 등 5개 키워드 검색.
**키워드 전체 목록**과 5건 이상 발견 시 -15점 감점 규칙은 `references/financial-distress-indicators.md` §4-3 참조.

---

## 5단계: 경영진·공시 리스크 점검

### 5-1. 상장사·외감법인 공시 확인

**korea-law-search:corporate_disclosure** 도구로 DART 공시를 확인한다.
감사의견(한정/부적정/의견거절), 계속기업 불확실성, 관리종목 등 **위험 신호 전체 매트릭스**는 `references/risk-grading-criteria.md` §6 참조.

### 5-2. 대표이사·임원 변동 (자동 모드에서는 체크리스트로 이관)

법인등기부등본은 MCP로 자동 조회 불가하다.
자동 모드에서는 점수 산출 시 "미확인" 처리하고, 리포트 말미 체크리스트로 이관한다.
체크리스트 양식은 `references/financial-distress-indicators.md` §6-2 참조.

### 5-3. 기타 리스크 신호

## 2. 5대 부실 지표 계산식

| 지표 | 계산식 | 위험 기준 |
|---|---|---|
| **부채비율** | (부채총계 / 자본총계) × 100 | 400% 초과 위험 |
| **유동비율** | (유동자산 / 유동부채) × 100 | 100% 미만 위험 |
| **이자보상배율** | 영업이익 / 이자비용 | 1.0 미만 위험 |
| **자본잠식률** | (자본금 − 자본총계) / 자본금 × 100 | 양수(+)면 자본잠식, 100% = 완전잠식 |
| **영업이익률** | (영업이익 / 매출액) × 100 | 연속 (-) 위험 |

**계산 결과는 반드시 3개년 시계열 표로 제시한다.**

이 문서는 업종별 정상 재무비율이 상이하므로, 업종 특성을 반영하여 판정 시 참고한다.
SKILL.md의 기본 임계값은 범용 기준이며, 업종별 보정이 필요한 경우 아래를 참고한다.

## 업종별 부채비율 정상 범위

| 업종 | 정상 범위 | 위험 기준 | 비고 |
|---|---|---|---|
| 제조업 (일반) | 100~200% | 400% 초과 | 기본 기준 적용 |
| 건설업 | 200~400% | 500% 초과 | PF 의존도 높음. 상향 적용 |
| 부동산업·임대업 | 200~400% | 500% 초과 | 담보 자산 높음. 상향 적용 |
| 도소매업 | 100~250% | 400% 초과 | 기본 기준 적용 |
| 운수업·물류업 | 150~300% | 450% 초과 | 장비 리스 비중 고려 |
| 금융업 | 300~1000% | 별도 규제 기준 | BIS 비율 등 별도 체크 |
| 음식점업·숙박업 | 100~200% | 300% 초과 | 기본보다 보수적 |
| IT·소프트웨어 | 50~150% | 300% 초과 | 보수적 기준 |
| 의료·바이오 | 100~250% | 400% 초과 | 초기 R&D 부담 고려 |

## 업종별 유동비율 정상 범위

| 업종 | 정상 범위 | 위험 기준 |
|---|---|---|
| 제조업 | 150~250% | 100% 미만 |
| 건설업 | 120~200% | 90% 미만 |
| 도소매업 | 130~200% | 100% 미만 |
| 서비스업 | 100~150% | 80% 미만 |
| IT·소프트웨어 | 150~300% | 100% 미만 |

## 업종별 영업이익률 정상 범위

| 업종 | 정상 범위 | 위험 기준 |
|---|---|---|

| 건설업 | 5~10% | 3년 연속 (-) |
| 도소매업 | 2~5% | 2년 연속 (-) |

| 의료업 | 5~15% | 3년 연속 (-) |
| 부동산 임대업 | 20~40% | 2년 연속 (-) |

## 업종별 특수 위험 신호

### 제조업
- 재고자산 급증 (매출 대비 비율 상승) → 판매 부진
- 유형자산 회전율 급락 → 설비 가동률 저하
- 외주가공비 급감 → 생산 축소

### 건설업
- 미청구공사 급증 → 분쟁 또는 회수 불능
- 공사진행률 이상 (과대 계상 의심)
- 프로젝트 파이낸싱(PF) 채무 급증

### 부동산업
- 임대수익 감소 (공실 증가)
- 담보대출 LTV 상승
- 관리비 체납 증가

### 도소매업
- 매출채권 회전율 급락 → 회수 지연
- 재고 회전율 급락 → 판매 부진
- 주요 거래처 집중도 심화

### 음식점업·서비스업
- 매출 3개월 연속 감소
- 종업원 급감
- 프랜차이즈 본사 분쟁

## 계절 보정 (제조업·도소매업)

일부 업종은 계절성이 강하므로, 분기별 단순 비교는 피한다.
반드시 **전년 동분기 대비** 또는 **연간 누계 기준**으로 비교한다.

## 기업 규모별 보정

| 규모 | 분류 기준 | 보정 |
|---|---|---|
| 중소기업 | 자산 5천억 미만 | 부채비율 기준 완화 (+50%p) |
| 중견기업 | 자산 5천억 ~ 10조 | 기본 기준 적용 |
| 대기업 | 자산 10조 이상 | 부채비율 기준 강화 (-50%p), 공시 투명도 높음 |

# 4단계 판정 기준 및 점수 체계

본 문서는 SKILL.md 6단계(종합 점수 산출 및 4단계 판정) 단계에서 참조하는 **상세 감점 기준과 판정 매트릭스**를 정의한다.
점수 산정과 판정은 반드시 본 문서의 수치를 그대로 적용한다 (임의 수정 금지).

---

## 1. 탈락 조건 (점수 무관 즉시 "매입부적격")

아래 항목 중 하나라도 해당하면, 점수 합산을 생략하고 **즉시 🔴 매입부적격**으로 종료한다.

- 회생·파산 신청 확인 (개시결정·선고·신청 진행 중 포함)
- 감사의견 "의견거절" 또는 "부적정"
- 사업자등록 폐업
- 국민연금 가입자 완전 이탈 (0명)

## 3. 4단계 판정 기준 (총 감점 → 등급)

| 총 감점 | 판정 | NPL 매입 전략 |
|---|---|---|
| **0 ~ -30점** | 🟢 **정상** | 통상 매입 가능. 정상 할인율 적용 |
| **-31 ~ -80점** | 🟡 **요주의** | 담보 가치 집중 검토. 매입가 보수적 산정 |
| **-81 ~ -140점** | 🟠 **고위험** | 매입가 대폭 할인 (통상 30% 이상). 담보만으로 회수 가능한지 재검증 |
| **-141점 이하** | 🔴 **매입부적격** | **매입 금지**. 회수 실익 거의 없음 |
| 탈락 조건 해당 | 🔴 **매입부적격** | 점수 무관 즉시 부적격 |

---

## 4. 2단계 회생·파산 이력 즉시 판정 매트릭스

2단계(이력 조회)에서 아래에 해당하면 6단계 점수 산출을 거치지 않고 즉시 판정한다.

| 확인 사실 | 즉시 판정 |
|---|---|
| 파산선고 | 🔴 **매입부적격** |
| 회생절차 개시결정 (진행 중) | 🔴 **매입부적격** |
| 회생·파산 신청 (결정 대기) | 🔴 **매입부적격** |
| 워크아웃 진행 중 | 🟠 **고위험** (기업개선작업 약정 내용 확인 필수) |
| 과거 회생절차 종결 (회생인가 후 졸업) | 🟡 **요주의** |
| 과거 파산 후 신설법인 의심 | 🟠 **고위험** |
| 이력 없음 | 3단계로 진행 |

## 5. 4단계 국민연금 가입자 변동 등급표

4단계 영업 실태 점검에서 국민연금 가입자 추이로 위험 등급을 판정한다.

| 국민연금 가입자 변동 (24개월) | 위험 등급 |
|---|---|
| 증가 또는 유지 | 🟢 정상 |
| 10% 미만 감소 | 🟢 정상 (자연감소) |
| 10~30% 감소 | 🟡 요주의 |
| 30~50% 감소 | 🟠 고위험 |
| 50% 초과 감소 | 🔴 매입부적격 수준 (사실상 영업중단) |
| 완전 이탈 (0명) | 🔴 **매입부적격** |

## 6. 5단계 공시·경영진 위험 신호 매트릭스

| 공시 항목 | 위험 신호 |
|---|---|
| 감사의견 "한정"·"부적정"·"의견거절" | 🔴 매입부적격 수준 |
| **"계속기업 불확실성" 감사의견** | 🔴 회생·파산 가능성 매우 높음 |
| 주요사항보고서: 채권 회수불능·부도 | 🔴 매입부적격 |
| 최대주주 변경 (2년 내 2회 이상) | 🟠 고위험 |
| 감사인 변경 (잦은 변경) | 🟡 요주의 |
| 관리종목/거래정지 | 🔴 매입부적격 수준 |
| 대표이사 2년 내 3회 이상 변경 | 🟠 고위험 |
| 본점 이전 반복 | 🟡 요주의 (주소 숨기기 의심) |
| 감자 이력 (자본잠식 보전용) | 🟠 고위험 |

---

## 7. 판정 시 보정 규칙

- **보수적 판정 우선**: 점수 경계선(예: -30 vs -31)에서 애매하면 한 단계 낮게 판정
- **담보부 NPL**: 담보 가치로 일부 상쇄 가능 → 권고사항에 명시
- **무담보 NPL**: 회수 실익 엄격 재평가, 한 단계 강하게 판정
- **MCP 조회 실패 항목**: 점수 산정 시 "미확인"으로 처리하고, 리포트 말미 체크리스트로 사용자 회신 요청

# 회생·파산 공식 확인처 가이드

## 1. 법원 공고 확인처

### 1-1. 대한민국 법원 전자공고 (필수)
- **URL:** https://www.scourt.go.kr/portal/notice/nstcnotice
- **검색 방법:** 
  - 법인명으로 검색
  - 공고 분류: "회생사건" / "파산사건" / "개인회생사건"
  - 기간: 최근 5년 권장
- **확인 항목:**
  - 회생절차 개시결정 공고
  - 파산선고 공고
  - 채권신고 공고 (채권신고 기간 내에 있는지 확인)

### 1-2. 대법원 나의 사건 검색
- **URL:** https://www.scourt.go.kr
- **검색 방법:** 사건번호로 조회 (예: 2024회합12345)
- **사건 분류 코드:**
  - 회합 = 회생 합의부 (법인 회생)
  - 회단 = 회생 단독 (간이회생)
  - 하합 = 파산 합의부
  - 하단 = 파산 단독

### 1-3. 서울회생법원 (대형 사건 집중)
- **URL:** https://slbgo.scourt.go.kr
- 수도권 대형 법인 회생·파산 사건 다수 처리
- 채권자협의회 공고, 관리인 선임 공고 등 확인 가능

### 1-4. 관보
- **URL:** https://gwanbo.go.kr
