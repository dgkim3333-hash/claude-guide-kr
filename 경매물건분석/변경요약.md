### 「입지조사」를 왜 없앴나

스킬 자체가 없어졌습니다. 대신 **물건카드 스킬이 직접 잽니다.**

이전 배포본에는 배점표에 「입지·교통 25점」이 있는데 **거리를 재는 절차가 없었습니다.**
감정평가서의 「인근에 지하철이 소재하는 등 교통상황은 보통임」 한 줄로 25점을 매기고 있었습니다.
이번에 **STEP 5-B 「지하철 접근성」**을 신설해 좌표·직선거리·도보경로를 실측하게 했습니다.

### 물건카드 스킬 주요 변경

| 항목 | 이전 | 이번 |
|---|---|---|
| 공시가격 가정 | 감정평가액 × **50%** | 감정평가액 × **60%** |
| 공시가격 분모 | 낙찰가를 쓰는 경로가 있었음 | **언제나 감정평가액.** 낙찰가 금지 |
| 지하철·역세권 | 없음 | **STEP 5-B 신설** (직선거리 + 도보 + 등급 5단계) |
| `[정보부족]` 라벨 | 자유롭게 사용 | **게이트 신설.** 도구 3~4번으로 확인되는 건 라벨 금지 |
| 임차권등기 | 존재만 확인 | **명의 확인 추가** (보증기관 대위변제 여부 → 명도 난이도) |
| 취득세 부속토지 | 따로 4% 적용 사례 | **주택 = 건물 + 부속토지 일체.** 연면적 안분 |
| 종부세 재산세공제 | 누락 가능 | 계산식 명시 + **안분 후 과세표준으로** 계산 |
| 슬라이드 수 | 22~24장 | **23~25장** (지하철 슬라이드 추가) |
| 산출물 | PPTX + PDF | **PPTX 1부만.** PDF·PNG 를 폴더에 남기지 않음 |
