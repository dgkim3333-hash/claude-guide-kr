# 경매 물건 분석 — Claude 프로젝트 배포본

경매 서류 PDF를 넣으면 **권리분석 → 임차인 판정 → 예상 배당 → 권장 입찰가 → 세금 → 명도까지**
한 번에 검토하고 **PPTX 물건카드 1부**를 만들어 주는 Claude 프로젝트입니다.

> ⚠️ **이 도구는 판단 재료를 모아줄 뿐, 대신 결정하지 않습니다.**
> 실제 입찰 전에는 등기부·매각물건명세서 원문과 전문가 확인이 반드시 필요합니다.
> 투자 판단과 그 결과는 본인 책임입니다.

---

## 설치 — 3단계

### 1단계. 폴더 만들기

내 컴퓨터 아무 곳에나 물건을 담을 폴더를 만듭니다. 예를 들면 이렇게요.

```
C:\경매\
```

그 아래 물건마다 폴더를 하나씩 만듭니다. **소재지로 이름을 짓습니다.**

```
C:\경매\평택 고덕동 1990-13\
C:\경매\화성 남양읍 2274-13\
```

사건번호로 짓지 않습니다 — 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

### 2단계. 프로젝트 만들기

Claude 데스크탑을 엽니다.

1. 왼쪽 사이드바에서 **`프로젝트`** → **`새 프로젝트`**
2. 이름을 이렇게 넣습니다 → `경매 물건 분석`
3. **`지침 편집`** 을 누릅니다
4. 이 폴더의 **`프로젝트지침.md`** 파일을 메모장으로 열고 `Ctrl+A` → `Ctrl+C` → 지침 칸에 `Ctrl+V`
5. 프로젝트에 1단계에서 만든 폴더(`C:\경매`)를 연결합니다

### 3단계. 스킬 넣기

스킬은 **넣는 방법이 두 가지**입니다. 아래 표의 「설치법」 칸을 보고 맞는 쪽으로 하세요.

| 스킬 | 하는 일 | 설치법 | 우선순위 |
|---|---|---|---|
| `auction-property-card` | **주 스킬.** 서류 → 분석 → 물건카드 | 파일 | 필수 |
| `auction-bid-price` | 저감률 판정 · 권장 입찰가 산출 | 파일 | 필수 |
| `residential-auction` | 다가구·다세대·아파트 GO/NO-GO 투자판단 | **붙여넣기** | 권장 |
| `property-location-scan` | 주소만으로 입지·상권·규제 조사 | 파일 | 권장 |
| `post-auction-eviction` | 낙찰 후 인도명령·명도 문서 | 파일 | 나중에 |
| `bid-result-log` | 입찰 결과 기록 · 예측 오차 누적 | 파일 | 나중에 |
| `corporate-debtor-bankruptcy-check` | 채무자가 법인일 때 회생·파산 확인 | 파일 | 필요할 때 |

**`auction-property-card` 하나만 넣어도 기본 분석은 됩니다.** 나머지는 쓰면서 하나씩 늘리세요.

#### 설치법 ① 파일 — `skills` 폴더

`skills` 폴더에 `.skill` 파일이 들어 있습니다. Claude 설정에서 스킬로 추가합니다.

#### 설치법 ② 붙여넣기 — `실습_경매분석스킬_통합본.md`

이 파일 하나가 `residential-auction` 스킬입니다. 첨부할 다른 파일이 없습니다.

1. [`실습_경매분석스킬_통합본.md`](실습_경매분석스킬_통합본.md) 를 엽니다
2. 오른쪽 위 **복사 버튼**으로 파일 전체를 복사합니다
3. Claude 데스크탑 대화창에 붙여넣습니다
4. 맨 아래에 한 줄 덧붙이고 엔터를 칩니다

```
위 내용을 그대로 스킬로 저장해줘. 요약하거나 바꾸지 마.
```

**이렇게 되면 성공** — 새 대화에서 `다가구 경매 분석해줘` 라고 쳤을 때 분석이 시작됩니다.

#### ⚠️ 두 스킬이 겹칩니다 — 헷갈리기 쉬운 곳

`auction-property-card` 와 `residential-auction` 은 **권리분석·임차인 판정이 겹칩니다.**
둘 다 깔려 있으면 상황에 따라 어느 쪽이 뜰지 모릅니다. 이렇게 나눠서 쓰세요.

| 상황 | 쓰는 스킬 | 나오는 것 |
|---|---|---|
| 서류(매각물건명세서·등기부)가 있다 | `auction-property-card` | PPTX 물건카드 |
| 서류 없이 물건 종류로 판단만 본다 | `residential-auction` | 100점 채점 + GO/NO-GO |

원하는 쪽이 안 뜨면 **스킬 이름을 직접 불러 주세요.** 예 — `residential-auction 으로 봐줘`

## MCP 연결

MCP를 하나도 안 붙여도 **서류만 가지고 분석은 됩니다.** 다만 시세·법령·공시지가를 직접 못 가져와서
"확인이 필요합니다"가 많아집니다.

무엇을 붙이면 무엇이 좋아지는지는 **`필요한MCP.md`** 를 보세요.
수업 시간에 강사가 같이 붙여 줍니다.

## 첫 사용법

물건 폴더에 서류 PDF를 넣고, 프로젝트 안에서 새 대화를 열어 이렇게 말합니다.

```
이 물건 분석해줘
```

넣으면 좋은 서류 (많을수록 정확해집니다):

- **매각물건명세서** ← 이게 없으면 분석의 절반이 날아갑니다
- 현황조사서
- 전입세대열람
- 감정평가서
- 등기사항전부증명서 (토지·건물 **각각**)
- 건축물대장
- 문건/송달내역
- 경매정보 출력물

## 자주 쓰는 말

- `이 물건 분석해줘`
- `물건카드 만들어줘. 개인·법인 두 경우로 세금 넣어줘`
- `입찰가 다시 계산해줘. 다음 기일이 34.3%로 확인됐어`
- `공시가격 000원으로 확인됐어. 보유세 다시 산출해줘`
- `낙찰됐어. 명도 계획 만들어줘`
- `패찰했어. 낙찰가 000원, 응찰 0명, 2순위 000원`

## 알아두실 것

**공시가격은 감정평가액의 50%로 가정합니다.**
주택 공시가격을 개인이 조회할 수 있는 공개 API가 없기 때문입니다.
정확한 값이 필요하면 [부동산공시가격알리미](https://www.realtyprice.kr) 에서 확인해 알려주세요. 즉시 다시 계산합니다.

**종부세는 낙찰 다음 해가 첫 과세연도입니다.**
과세기준일이 6월 1일이라, 6월 이후 잔금을 내면 그 해 종부세는 없습니다.
그래서 현행 세율이 아니라 **2027년 이후 세율**로 계산합니다.
2026.08.03 재정경제부 세제개편안 기준이며 **국회 통과 전 정부안**입니다.

**낙찰 계수는 실측 데이터지만 시장에 따라 변합니다.**
산출일이 6개월을 넘으면 참고치로만 쓰고, 인근 낙찰사례로 반드시 교차 검증하세요.

**민간 추정시세는 쓰지 않습니다.**
국토교통부 실거래가만 씁니다. 경매정보 사이트의 AI 추정가도 쓰지 않습니다.

## 이 폴더의 갱신에 대하여

**여기 있는 스킬은 자동으로 갱신되지 않습니다.**
강사 PC의 스킬을 손으로 복사해 올린 것이라, 강사가 스킬을 고쳐도 여기는 그대로 남습니다.
아래 날짜가 오래됐으면 최신판이 아닐 수 있습니다.
