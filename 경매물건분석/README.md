# 경매 물건 분석 — Claude 프로젝트 배포본

경매 서류 PDF를 넣으면 **권리분석 → 임차인 판정 → 예상 배당 → 세금 → 명도까지**
한 번에 검토하고 **PPTX 물건카드 1부**를 만들어 주는 Claude 프로젝트입니다.

> ⚠️ **이 도구는 판단 재료를 모아줄 뿐, 대신 결정하지 않습니다.**
> 실제 입찰 전에는 등기부·매각물건명세서 원문과 전문가 확인이 반드시 필요합니다.
> 투자 판단과 그 결과는 본인 책임입니다.

---

## 설치 — 3단계

### 1단계. 폴더 만들기

내 컴퓨터 아무 곳에나 물건을 담을 폴더를 만듭니다. 예를 들면 이렇게요.

```
C:\AI\경매\
```

그 아래 물건마다 폴더를 하나씩 만듭니다. **소재지로 이름을 짓습니다.**

```
C:\AI\경매\평택 고덕동 1990-13\
C:\AI\경매\화성 남양읍 2274-13\
```

사건번호로 짓지 않습니다 — 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

### 2단계. 프로젝트 만들기

Claude 데스크탑을 엽니다.

1. 왼쪽 사이드바에서 **`프로젝트`** → **`새 프로젝트`**
2. 이름을 이렇게 넣습니다 → `경매 물건 분석`
3. **`지침 편집`** 을 누릅니다
4. 이 폴더의 **`프로젝트지침.md`** 파일을 메모장으로 열고 `Ctrl+A` → `Ctrl+C` → 지침 칸에 `Ctrl+V`
5. 프로젝트에 1단계에서 만든 폴더(`C:\AI\경매`)를 연결합니다

### 3단계. 스킬 넣기

**스킬은 6개입니다. 넣는 방법이 두 가지인데, 같은 스킬이라 아무 쪽이나 쓰시면 됩니다.**

| 스킬 | 무엇에 쓰나 | ① 붙여넣기용 | ② 파일 설치용 |
|---|---|---|---|
| 물건카드 | **서류를 넣고 물건카드를 뽑는 주 스킬** | [`스킬_물건카드.md`](스킬_물건카드.md) | [`auction-property-card.skill`](skills/auction-property-card.skill) |
| 주거용 | 다가구 · 다세대 · 연립 · 아파트 | [`스킬_주거용경매.md`](스킬_주거용경매.md) | [`residential-auction.skill`](skills/residential-auction.skill) |
| 상가 호실 | 구분상가 · 오피스 호실 · 근린생활시설 | [`스킬_상가호실.md`](스킬_상가호실.md) | [`commercial-unit-auction.skill`](skills/commercial-unit-auction.skill) |
| 토지 | 토지 · 농지 · 임야 · 잡종지 | [`스킬_토지.md`](스킬_토지.md) | [`land-auction.skill`](skills/land-auction.skill) |
| 꼬마빌딩 | 소형 상업용 건물 **전체** (호실 아님) | [`스킬_꼬마빌딩.md`](스킬_꼬마빌딩.md) | [`small-building-auction.skill`](skills/small-building-auction.skill) |
| 입지 조사 | 주소만으로 입지 · 상권 · 규제 훑기 | [`스킬_입지조사.md`](스킬_입지조사.md) | [`property-location-scan.skill`](skills/property-location-scan.skill) |

**「물건카드」부터 넣으세요. 이것 하나로 기본 분석은 됩니다.**
물건 종류별 넷은 **본인이 보는 종류 하나만** 골라 넣으면 충분합니다. 다 넣을 필요 없습니다.

> **「입지 조사」는 MCP 를 붙인 뒤에 쓰세요.** 브이월드·공공데이터포털·지도 서비스를 부르는 스킬이라,
> MCP 가 없으면 대부분 「확인 필요」로만 나옵니다.

#### ① 대화창에 붙여넣기 — 준비물이 없습니다

1. 위 표의 **붙여넣기용** 문서를 클릭해 엽니다
2. 오른쪽 위 **복사 버튼**으로 파일 전체를 복사합니다
3. Claude 데스크탑 대화창에 붙여넣습니다
4. 맨 아래에 한 줄 덧붙이고 엔터를 칩니다

```
위 내용을 그대로 스킬로 저장해줘. 요약하거나 바꾸지 마.
```

5. 스킬이 저장되면 **새 대화**부터 작동합니다

> 여기서 많이 막힙니다. **붙여넣은 그 대화에서는 아직 안 뜹니다.** 새 대화를 여세요.

> **`.md` 파일도 그냥 올릴 수 있습니다.** 업로드 창이 `.md` 를 받습니다 — 붙여넣기가 번거로우면 `스킬_○○.md` 를 그대로 끌어다 놓으세요.

#### ② 파일로 설치하기 — 여러 개를 한 번에 넣을 때 편합니다

먼저 **`설정 > 기능`** 에서 **「코드 실행 및 파일 생성」을 켜 두세요.**
꺼져 있으면 스킬 항목이 아예 안 보이거나 회색으로 죽어 있습니다.

1. 위 표의 **파일 설치용** `.skill` 을 내려받습니다
2. **`설정 > 사용자 지정 > 스킬`** 로 들어갑니다
3. 오른쪽 위 **`추가`** → **`스킬 업로드`**
4. 파일을 창에 **끌어다 놓습니다**
5. **1~2분 보안 검사**가 끝나면 목록에 뜹니다. **토글을 켜세요**

**이렇게 되면 성공** — 어느 방법이든, 새 대화에서 `이 물건 분석해줘` 라고 쳤을 때 분석이 시작됩니다.
각 문서 맨 위에 스킬마다 확인 문구가 적혀 있으니 그대로 쳐 보세요.

#### ⚠️ 스킬끼리 겹칩니다 — 헷갈리기 쉬운 곳

`물건카드` 와 종류별 스킬 넷은 **권리분석·임차인 판정이 겹칩니다.**
둘 다 깔려 있으면 상황에 따라 어느 쪽이 뜰지 모릅니다. 이렇게 나눠서 쓰세요.

| 상황 | 쓰는 스킬 | 나오는 것 |
|---|---|---|
| 서류(매각물건명세서·등기부)가 있다 | `물건카드` | PPTX 물건카드 |
| 서류 없이 물건 종류로 판단만 본다 | 종류별 스킬 | 100점 채점 + GO/NO-GO |

원하는 쪽이 안 뜨면 **스킬 이름을 직접 불러 주세요.** 예 — `residential-auction 으로 봐줘`

종류별 넷은 **서로 대상이 다릅니다.** 상가 「호실 하나」는 `상가 호실`,
상가 「건물 전체」는 `꼬마빌딩` 입니다. 여기서 자주 헷갈립니다.

## 여기에 없는 것 — 미리 알아두세요

### 입찰가를 자동으로 뽑아 주는 스킬은 배포하지 않습니다

**스킬들은 「살지 말지」까지만 판단합니다. 「얼마를 쓸지」는 알려주지 않습니다.**

금액을 정하는 스킬은 강사가 직접 모은 낙찰 실측 자료로 만든 것이라 공개하지 않습니다.
**얼마를 쓸지는 스스로 정하셔야 합니다.**

스킬이 알려주는 것은 여기까지입니다.

- **저감률을 먼저 확인하세요.** 법원마다 20%/30%로 갈립니다.
  서울 5개 법원(중앙·남부·동부·서부·북부)과 수원지법 안양지원은 20% 저감이라
  1회 유찰 최저가가 **80%** 입니다. 여기에 30% 기준(70%)을 쓰면 최저가보다 낮은 값이 나옵니다.
- **인근 낙찰 사례를 직접 대조하세요.** 법원경매정보와 온비드에서
  같은 지역·같은 용도·같은 유찰 회차의 최근 낙찰가를 찾습니다.

이 부분은 **수업 시간에 따로 다룹니다.**

### 그 밖에 빠진 것

- **세금 계산 스킬** — 취득세·보유세·양도세를 자동 계산하는 스킬은 넣지 않았습니다.
  물건카드 안에 세금 항목은 나오지만, 정확한 금액은 세무 상담으로 확인하세요
- **낙찰 후 명도 스킬** — 워드 서식이 빠져 서류가 만들어지지 않아 내렸습니다
- **입찰 결과 기록 스킬** — 강사 실적 자료라 공개하지 않습니다
- **법인 채무자 회생·파산 확인** — 법원 나의사건검색과 대법원 공고를 직접 보세요

## 첫 사용법

물건 폴더에 서류 PDF를 넣고, 프로젝트 안에서 새 대화를 열어 이렇게 말합니다.

```
이 물건 분석해줘
```

넣으면 좋은 서류 (많을수록 정확해집니다):

- **매각물건명세서** ← 이게 없으면 분석의 절반이 날아갑니다
- 현황조사서
- 전입세대열람
- 감정평가서
- 등기사항전부증명서 (토지·건물 **각각**)
- 건축물대장
- 문건/송달내역
- 경매정보 출력물

## 자주 쓰는 말

- `이 물건 분석해줘`
- `물건카드 만들어줘. 개인·법인 두 경우로 세금 넣어줘`
- `공시가격 000원으로 확인됐어. 보유세 다시 산출해줘`
- `임차인이 인수되는지만 다시 봐줘`
- `이 다가구 GO 인지 NO-GO 인지 판단해줘`
- `이 상가 호실 분석해줘` · `이 토지 분석해줘` · `이 꼬마빌딩 분석해줘`
- `이 주소 입지 조사해줘`

## 알아두실 것

**공시가격은 감정평가액의 50%로 가정합니다.**
주택 공시가격을 개인이 조회할 수 있는 공개 API가 없기 때문입니다.
정확한 값이 필요하면 [부동산공시가격알리미](https://www.realtyprice.kr) 에서 확인해 알려주세요. 즉시 다시 계산합니다.

**종부세는 낙찰 다음 해가 첫 과세연도입니다.**
과세기준일이 6월 1일이라, 6월 이후 잔금을 내면 그 해 종부세는 없습니다.
그래서 현행 세율이 아니라 **2027년 이후 세율**로 계산합니다.
2026.08.03 재정경제부 세제개편안 기준이며 **국회 통과 전 정부안**입니다.

**민간 추정시세는 쓰지 않습니다.**
국토교통부 실거래가만 씁니다. 경매정보 사이트의 AI 추정가도 쓰지 않습니다.

**스킬 안에 나오는 상세 양식 일부는 생략됩니다.**
종류별 스킬 넷 중 특히 **상가 호실**과 **토지**는 본문에 `references/○○.md 참조` 라고 적힌 자리가 많은데,
그 참조 파일은 배포하지 않습니다. **토지가 영향이 가장 큽니다** — 8개 섹션 중 6개가 참조 파일의
상세 체크리스트·템플릿에 기대는 구조입니다.
그래도 분석은 멈추지 않습니다. 참조 파일이 있으면 상세 체크리스트로 보강하고, 없으면 본문 요약만으로
판단하며 확인 못 한 세부 항목은 `[정보부족]`으로 표시됩니다. 빠지는 것은 상세 양식·부록 표뿐이고,
권리분석 → 판정 → 종합점수 → GO/NO-GO로 이어지는 판단 흐름 자체는 그대로 작동합니다.

아래 날짜가 오래됐으면 최신판이 아닐 수 있습니다.
