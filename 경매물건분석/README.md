# 경매 물건 분석 — 수업용 배포본

법원경매로 **부동산을 직접 낙찰**받기 위해 서류를 읽고 분석해 **PPTX 물건카드 1부**를 만드는
Claude 프로젝트 한 벌입니다. 스킬 8개 · MCP 5개(+선택 2개)로 구성됩니다.

> **NPL 채권 매입 분석이 아닙니다.** 채권을 얼마에 살지 정하는 로직은 들어 있지 않습니다.
> **입찰 금액을 계산해 주는 로직도 들어 있지 않습니다.** 이유는 아래 「빠져 있는 것」 참조.

---

## 무엇을 해 주나

경매 서류(등기부·건축물대장·매각물건명세서·현황조사서·감정평가서·문건접수내역·전입세대열람)를
폴더에 넣고 **「이 물건 분석해줘」** 라고 하면 순서대로 진행합니다.

```
서류 판독 → 문건 타임라인 → 권리 순위·말소기준 → 인수·소멸 판정
   → 임차인 대항력·소액임차인 최우선변제 → 국토교통부 실거래가 대조
   → 지하철 접근성 실측 → 예상 배당 → 입찰 상한선
   → 취득세·재산세·종부세(개인/법인 2경우) → 자금·명도
   → 확인해야 할 것 → PPTX 23~25장
```

**「확인해야 할 것」이 결론입니다.** 답을 준 게 아니라 무엇을 더 봐야 하는지를 줍니다.

---

## 설치 — 4단계

### 1단계. MCP 붙이기

`필요한MCP.md` 를 보고 인증키를 발급받은 뒤, `config_경매용.json` 을 참고해
Claude 데스크탑 설정 파일에 서버를 추가합니다. **Claude 를 완전히 종료했다가 다시 켭니다.**

### 2단계. 스킬 설치

`skills\` 폴더의 `.skill` 파일 8개를 Claude 에 올립니다.

> **압축(.zip)이 아니라 `.skill` 파일 그대로 올립니다.** 풀지 마세요.

붙여넣기로 설치하려면 `스킬_○○.md` 파일을 열어 **전문을 그대로** 복사해 넣습니다.
두 방법 중 하나만 하면 됩니다. 둘 다 하면 중복 설치됩니다.

### 3단계. 프로젝트 지침 넣기

Claude 에서 새 프로젝트를 만들고, `프로젝트지침.md` 전문을 「지침」 칸에 붙여넣습니다.

### 4단계. 폴더 연결

물건 서류를 담을 폴더를 만들어 프로젝트에 연결합니다.
**연결한 폴더 안에서만** 파일을 읽고 씁니다.

---

## 폴더 구조

```
<연결한 폴더>\<소재지>\
  ├ 원본 서류 PDF 여러 개
  ├ 물건카드_<사건번호>.pptx   ← 유일한 산출물
  ├ _card.js / _deck-flow.js   ← 생성 스크립트 (분석 중 자동 생성)
  └ 백업\
```

폴더 이름은 **사건번호가 아니라 소재지**로 짓습니다. 재경매로 사건번호가 바뀌어도 물건은 그대로입니다.

---

## 첫 실행

1. 물건 폴더에 서류 PDF 를 전부 넣습니다
2. `이 물건 분석해줘`
3. 중간에 물어보는 것에 답합니다 (개인/법인, 낙찰가 가정 등)
4. `물건카드_<사건번호>.pptx` 가 폴더에 생깁니다

실습 문장은 `실습_프롬프트_경매.md` 에 있습니다.

## 빠져 있는 것 — 미리 알아 두세요

| 없는 것 | 왜 |
|---|---|
| **예상 낙찰가·응찰자수 산출** | 직접 수집한 실측 낙찰 데이터가 있어야 합니다. 그 데이터는 배포되지 않습니다 |
| **NPL 채권 매입가 산정** | 이 프로젝트의 범위가 아닙니다 |
| **공시가격 DB** | 대용량 파일이라 뺐습니다. 없으면 「감정평가액 × 60%」 가정으로 진행하고 그 사실을 슬라이드에 크게 밝힙니다 |
| **입지 조사 전용 스킬** | 없어졌습니다. 지하철·규제는 물건카드 스킬이 직접 잽니다 |

**입찰 금액은 「상한 − 차감」 범위만 제시합니다.** 그 안에서 얼마를 쓸지는 본인이 정합니다.

- 채무자·임차인 **실명과 주민번호는 산출물에 남기지 않습니다**
