# 실습 프롬프트 — 경매 물건 분석

순서대로 따라 하면 물건카드 1부가 나옵니다.
**서류는 본인이 구한 실제 물건 것을 쓰십시오.** 예제 서류는 배포하지 않습니다.

---

## 0. 붙었는지 확인 (분석 전 1회)

```
지금 붙어 있는 MCP 목록을 보여주고, 경매 물건 분석에 필요한 것 중 빠진 게 있는지 알려줘
```

```
설치된 스킬 목록을 보여줘
```

---

## 1. 서류 정리

물건 폴더에 PDF 를 전부 넣은 뒤:

```
이 폴더 서류 정리해줘
```

> **확인할 것** — 등기부가 **토지·건물 각각** 있는지. 토지 등기부가 빠지는 일이 잦습니다.
> 매각물건명세서가 없으면 임차인·인수 판정의 절반이 날아갑니다.

---

## 2. 기본 분석

```
이 물건 분석해줘
```

중간에 물어봅니다. 이렇게 답하면 됩니다.

| 질문 | 답 예시 |
|---|---|
| 어떤 분석인가 | `직접 낙찰 물건카드` |
| 세금은 누구 기준인가 | `개인·법인 두 경우 다` |
| 감정평가서를 다 읽을까 | `잘 안 보이는 건 스킵해도 됩니다` |

> **10분 이상 걸립니다.** 서류를 이미지로 렌더링해 한 장씩 눈으로 읽기 때문입니다.
> 텍스트 추출은 숫자가 빠져 나와서 쓰지 않습니다.

---

## 3. 중간에 확인하기 — 하나씩 물어보기

```
말소기준권리가 뭐고 왜 그렇게 판정했는지 근거를 보여줘
```

```
임차인별로 대항력 있는지, 배당 얼마 받는지, 인수 금액이 얼마인지 표로 보여줘
```

```
소액임차인 최우선변제 기준일을 뭘로 잡았어? 근거 조문 보여줘
```

> **정답** — 기준일은 **최선순위 담보물권(근저당) 설정일**입니다.
> 임차인 계약일이나 전입일로 잡으면 금액이 크게 틀립니다.

```
당해세 판정 근거를 보여줘. 갑구 압류 권리자가 누구야?
```

```
지하철 접근성 다시 재줘. 직선거리랑 도보 시간 둘 다
```

## 5. 낙찰가 시나리오 추가

```
0,000,000,000원에 낙찰받는 조건으로 슬라이드 추가해줘.
기존 슬라이드는 그대로 두고 뒤에 붙여줘.
수익성·취득세·재산세·종부세·자금조달·총소요자금
```

> **확인할 것** — 시나리오를 여러 개 만들면 **재산세·종부세는 전부 같은 값**이어야 합니다.
> 보유세의 분모는 공시가격(감정평가액 × 60%)이지 낙찰가가 아니기 때문입니다.
> 시나리오마다 보유세가 달라지면 잘못 계산한 것입니다. 지적하십시오.

## 스스로 검증해 보기 — 수업용 체크

분석이 끝나면 아래를 물어보고 **답이 막히는 곳을 찾으십시오.**

```
이 분석에서 [정보부족]으로 남긴 항목을 전부 나열하고,
각각 내가 무엇을 구해오면 해결되는지 한 줄로 알려줘
```

```
네가 계산한 종부세에서 재산세 공제를 뺐어? 계산식 보여줘
```

```
취득세 계산할 때 주택 부속토지를 어떻게 처리했어?
```

> **정답** — 주택은 **건물 + 부속토지 일체**입니다. 연면적 비율로 안분한 주택분 **전체**에
> 주택 세율을 적용합니다. 토지를 따로 떼어 전부 4% 를 매기면 크게 과소 계상됩니다.

```
종부세 첫 과세연도를 몇 년으로 잡았고 왜 그래?
```

> **정답** — 과세기준일은 **매년 6월 1일**입니다. 6월 1일 이후 잔금을 내면 그 해는 0원이고
> **낙찰 다음 해가 첫 과세연도**입니다. 현행 세율로 계산하면 틀립니다.

## 자주 나오는 실수

| 증상 | 원인 | 고치는 법 |
|---|---|---|
| 금액이 이상하다 | 스캔 PDF 텍스트 추출로 숫자가 빠짐 | `서류를 이미지로 렌더링해서 다시 읽어줘` |
| 시세가 없다고 나온다 | 그 지역·유형 실거래 표본이 실제로 0건 | 정상입니다. 감정평가서 거래사례를 쓰게 하십시오 |
| PPTX 가 안 만들어진다 | PowerPoint 가 파일을 열고 있음 | PowerPoint 를 완전히 닫고 다시 요청 |
| 글자가 잘려 보인다 | 표가 12행을 넘음 | `표를 나눠서 슬라이드 쪼개줘` |
| 낙찰가를 안 알려준다 | **의도된 동작** | 이 배포본에는 낙찰가 예측 로직이 없습니다 |
