# 실습 프롬프트 — 경매 물건 분석

교재 **섹션 09 (p.66~73)** 를 손으로 따라 해 보는 자료입니다.
한 단계씩 회색 상자를 복사해 대화창에 넣고, **「이렇게 되면 성공」** 을 눈으로 확인한 뒤 다음으로 넘어가세요.

> **AI 분석은 검토 출발점입니다. 실제 입찰 전 등기부·매각물건명세서 원문과 전문가 확인이 필요합니다.**
> 이 실습은 도구 사용법을 익히는 것이 목적이며, 특정 물건의 입찰을 권유하지 않습니다.

---

## 시작 전 — 세 가지만 확인합니다

| 확인할 것 | 어디서 | 안 되어 있으면 |
|---|---|---|
| 프로젝트 `경매 물건 분석` 을 만들고 지침을 넣었는가 | 왼쪽 사이드바 → 프로젝트 | 교재 p.69 |
| 스킬 `물건카드` 를 넣었는가 | 설정 → 사용자 지정 → 스킬 | 교재 p.69 |
| 물건 폴더를 프로젝트에 연결했는가 | 프로젝트 화면 | 교재 p.69 |

**MCP는 하나도 안 붙어 있어도 됩니다.** 서류만으로 분석은 돌아갑니다.
다만 시세를 직접 못 가져와서 `[확인 필요]` 가 늘어납니다 (교재 p.70~71).

> **여기서 많이 막힙니다.** 스킬을 방금 넣었다면 **열려 있던 대화에서는 안 잡힙니다.** 새 대화를 여세요.

---

## 실습에 쓸 물건 — 가공한 예시입니다

실제 사건이 아닙니다. **아래 값은 실습용으로 만들어낸 숫자입니다.**

| 항목 | 값 |
|---|---|
| 물건 종류 | 다세대주택 (전용 44.82㎡) |
| 감정평가액 | 250,000,000원 |
| 최저매각가격 | 122,500,000원 |
| 유찰 | 2회 |
| 등기부 갑구 | 압류 1건 |
| 등기부 을구 | 근저당권 2건 |
| 임차인 | 1명 (전입신고 있음, 확정일자 여부 불명) |

**본인 물건으로 하셔도 됩니다.** 그 편이 훨씬 남습니다.
다만 **남의 물건카드를 만들어 밖으로 보내지 마세요.** 임차인 정보가 들어 있습니다.

> 실습 폴더를 하나 만들고 이름을 **소재지로** 짓습니다. 사건번호로 짓지 않습니다 —
> 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

---

# 1부. 서류를 읽히기 (1~4단계)

## 1단계 — 무엇을 넣어야 하는지부터 묻습니다

폴더에 서류를 넣기 전에 **무엇이 필요한지** 먼저 물어봅니다.

```
경매 물건 하나를 분석하려고 해. 어떤 서류를 넣어야 하는지,
없으면 무엇을 판단 못 하게 되는지 표로 알려줘.
```

**이렇게 되면 성공** — 서류 여덟 가지가 표로 나오고, 각각 무엇을 말해주는지가 붙어 나옵니다.
교재 p.68 표와 같은 내용입니다.

**자주 막히는 곳** — 표가 아니라 줄글로 나오면 스킬이 안 잡힌 것입니다. 새 대화를 열어 다시 해보세요.

---

## 2단계 — 서류를 넣고 무엇이 들어왔는지 확인시킵니다

물건 폴더에 PDF를 넣습니다. 바로 분석시키지 말고 **읽혔는지부터** 확인합니다.

```
폴더에 넣은 서류가 각각 무엇인지, 몇 쪽짜리인지 목록으로 정리해줘.
읽히지 않은 파일이 있으면 그것도 알려줘.
```

**이렇게 되면 성공** — 파일 이름과 서류 종류가 짝지어 나옵니다.

**자주 막히는 곳**
- **매각물건명세서가 목록에 없으면 여기서 멈추세요.** 이게 빠지면 분석의 절반이 날아갑니다.
- **토지 등기부가 자주 빠집니다.** 건물 등기부만 넣으면 토지 권리를 못 봅니다.
- 스캔본이라 글자가 안 읽히면 → `이미지로 읽어줘` 라고 한 줄 덧붙입니다.

---

## 3단계 — 금액부터 확인시킵니다

숫자를 잘못 읽는 일이 가장 흔합니다. **분석 전에 숫자부터 맞춰 놓습니다.**

```
감정평가액, 최저매각가격, 청구금액, 유찰 회차를 원 단위로 정확히 적어줘.
어느 서류 몇 쪽에서 가져왔는지도 같이 써줘.
```

**이렇게 되면 성공** — `250,000,000원` 처럼 원 단위로 나오고, 출처 쪽수가 붙습니다.

**★ 여기가 이 실습에서 가장 중요한 대목입니다.**
경매정보 PDF는 숫자가 **그림으로** 들어 있는 경우가 많아, 금액을 엉뚱하게 읽는 일이 자주 있습니다.
**나온 숫자를 서류에서 직접 눈으로 대조하세요.** 틀렸으면 이렇게 잡아줍니다.

```
최저매각가격이 틀렸어. 경매정보 2쪽을 이미지로 다시 읽고 고쳐줘.
```

---

## 4단계 — 문건접수내역으로 시간 순서를 세웁니다

```
문건/송달내역을 날짜순으로 정리해줘.
누가 무엇을 언제 냈는지, 기일을 누가 세웠는지 표로 만들어줘.
```

**이렇게 되면 성공** — 날짜 · 제출자 · 문건명이 시간순 표로 나옵니다.

**왜 하나** — 채무자가 저항하고 있는지, 기일이 왜 미뤄졌는지가 여기서 드러납니다.
명도 난이도를 가늠하는 첫 단서입니다.

---

# 2부. 권리를 따지기 (5~8단계)

## 5단계 — 말소기준권리를 세웁니다

```
등기부를 보고 말소기준권리가 무엇인지, 그보다 앞선 권리와 뒤선 권리를
표로 나눠줘. 낙찰 후 지워지는 것과 인수되는 것을 구분해줘.
```

**이렇게 되면 성공** — 순위 · 권리 종류 · 설정일 · 소멸/인수 판정이 한 표에 나옵니다.

**자주 막히는 곳** — 근저당권이 여러 개면 **가장 빠른 것**이 기준입니다.
가압류·담보가등기·경매개시결정등기도 기준이 될 수 있습니다. 판정 근거를 물어보세요.

```
그 권리를 말소기준으로 본 근거가 뭐야? 조문으로 알려줘.
```

---

## 6단계 — 임차인을 한 명씩 따집니다

```
임차인이 몇 명이고 각각 대항력이 있는지 한 명씩 판정해줘.
전입일 · 확정일자 · 보증금 · 배당요구 여부를 표로 정리하고,
낙찰자가 인수해야 하는 보증금이 있으면 원 단위로 적어줘.
```

**이렇게 되면 성공** — 임차인별로 전입일과 말소기준권리 설정일이 나란히 비교되어 나옵니다.

**★ 이 한 줄이 입찰 여부를 가릅니다.** 대항력 있는 선순위 임차인이 있으면
낙찰가와 별개로 보증금을 떠안게 됩니다.

**자주 막히는 곳** — 전입세대열람과 현황조사서가 서로 다르게 적힌 경우가 있습니다.
그때는 이렇게 물어보세요.

```
전입세대열람과 현황조사서 내용이 다르면 어느 쪽을 믿어야 하고,
다르다는 사실 자체가 무엇을 뜻하는지 설명해줘.
```

---

## 7단계 — 일부러 틀리게 해 보는 단계

**이 단계는 검증 습관을 들이려고 넣었습니다.** 건너뛰지 마세요.

먼저 확인할 수 없는 것을 일부러 물어봅니다.

```
이 물건의 공시가격이 얼마야?
```

**무엇이 나오나** — 주택 공시가격을 개인이 조회할 수 있는 공개 API가 없어서,
**감정평가액의 50%를 가정값으로 씁니다.** 실제 값이 아닙니다.

그다음 이렇게 되물어 보세요.

```
그 숫자가 실제 조회한 값이야, 가정한 값이야? 근거를 대줘.
```

**이렇게 되면 성공** — "가정값"이라고 스스로 밝힙니다.
안 밝히고 실제 값처럼 답하면 **그 답 전체를 의심해야 합니다.**

정확한 값은 [부동산공시가격알리미](https://www.realtyprice.kr) 에서 확인해 알려주면 즉시 다시 계산합니다.

```
공시가격이 118,000,000원으로 확인됐어. 보유세를 다시 산출해줘.
```

> **숫자의 출처를 묻는 습관이 이 교육에서 얻어 가실 것 중 가장 값어치 있는 것입니다.**

---

## 8단계 — 시세를 대조합니다

```
국토교통부 실거래가로 같은 단지·비슷한 면적의 최근 6개월 거래를 찾아서
감정평가액이 적정한지 대조해줘. 조회한 시각도 같이 적어줘.
```

**이렇게 되면 성공** — 실거래 사례가 표로 나오고 감정가와 비교됩니다.

**MCP를 안 붙였으면** `[확인 필요]` 로만 나옵니다. 고장이 아닙니다 (교재 p.70~71).
그때는 **국토교통부 실거래가 공개시스템에서 직접 찾아** 값을 알려주세요.

> **민간 추정시세는 쓰지 않습니다.** 국토교통부 실거래가만 씁니다.
> 경매정보 사이트의 AI 추정가도 쓰지 않습니다.

---

# 3부. 결과를 뽑기 (9~12단계)

## 9단계 — 예상 배당을 봅니다

```
예상 배당표를 만들어줘. 순위별로 누가 얼마를 받고,
남는 게 있는지 없는지 원 단위로 보여줘.
```

**이렇게 되면 성공** — 순위 · 권리자 · 채권액 · 배당액이 표로 나옵니다.

**자주 막히는 곳** — 당해세가 있으면 순위가 뒤집힙니다. 압류 권리자가 물건 소재지의 구청·시청이면
당해세일 가능성이 큽니다. 그 판정 근거를 물어보세요.

---

## 10단계 — 세금을 개인·법인 두 경우로 봅니다

```
물건카드 만들어줘. 개인·법인 두 경우로 세금 넣어줘.
```

**이렇게 되면 성공** — 취득세 · 재산세 · 종합부동산세가 두 경우로 나뉘어 나옵니다.

**반드시 알아두실 것 (교재 p.72)**
- **공시가격은 감정평가액의 50%로 가정한 값입니다.** 실제 값이 아닙니다.
- **종부세는 낙찰 다음 해가 첫 과세연도입니다.** 과세기준일이 6월 1일이라,
  6월 이후 잔금을 내면 그 해 종부세는 없습니다.
- 세율은 **국회 통과 전 정부안** 기준입니다. 확정 세율이 아닙니다.

**정확한 세액은 세무 상담으로 확인하세요.**

---

## 11단계 — 마지막 장을 먼저 읽습니다

물건카드가 나오면 **맨 뒤부터** 봅니다.

```
마지막 장의 「확인해야 할 것」만 다시 정리해줘.
그중에 입찰 전에 반드시 봐야 하는 것 세 가지를 골라줘.
```

**이렇게 되면 성공** — 확인이 필요한 항목이 우선순위대로 나옵니다.

**★ 이 장이 사실상 결론입니다 (교재 p.73).**
답을 준 게 아니라 **무엇을 더 봐야 하는지**를 알려주는 장입니다.
「살지 말지」를 여기서 판단하시는 게 아니라, **여기서부터 본인 확인이 시작됩니다.**

---

## 12단계 — 스스로 요약해 보기

마지막으로 **본인 말로** 정리해 봅니다. 그다음 검토를 시킵니다.

```
내가 이해한 걸 적어볼게. 틀린 데가 있으면 짚어줘.
- 말소기준권리는 ○○이고
- 임차인은 대항력이 (있다 / 없다)
- 인수해야 할 보증금은 ○○○원이고
- 가장 큰 위험은 ○○다
```

**이렇게 되면 성공** — 틀린 부분을 근거와 함께 잡아줍니다.

> **이 단계를 하시면 실습이 남고, 안 하시면 화면만 지나갑니다.**

# 자주 막히는 곳 — 한눈에

| 증상 | 원인과 해결 |
|---|---|
| 스킬이 안 잡힌다 | **새 대화**를 열었는지 확인하세요. 열려 있던 대화에는 안 붙습니다 |
| 금액을 엉뚱하게 읽는다 | 경매정보 PDF는 숫자가 그림으로 들어 있습니다. `이미지로 읽어줘` |
| 시세를 못 가져온다 | `real-estate` MCP가 안 붙은 것입니다. 채팅창 `+` → `Connectors` 확인 |
| 공시가격이 이상하다 | 감정평가액의 50% 가정값입니다. 실제 값을 알려주면 다시 계산합니다 |
| 세금이 현행 세율과 다르다 | 종부세는 **낙찰 다음 해** 기준으로 계산합니다. 고장이 아닙니다 |
| 슬라이드 글자가 겹친다 | PPTX를 손으로 고치지 마시고 다시 생성하게 하세요 |
| 원하는 스킬이 안 뜬다 | 스킬 이름을 직접 부르세요. 예 — `residential-auction 으로 봐줘` |

# 하지 않는 것

**이 스킬들은 「살지 말지」까지만 판단합니다. 「얼마를 쓸지」는 알려주지 않습니다.**

입찰 금액을 정하는 것은 이 실습의 범위가 아닙니다.
직접 정하실 때는 최소한 아래 둘은 확인하세요.

- **저감률을 먼저 확인하세요.** 법원마다 20% / 30% 로 갈립니다.
  기준을 잘못 잡으면 최저매각가격보다 낮은 값이 나옵니다.
- **인근 낙찰 사례를 직접 대조하세요.** 법원경매정보와 온비드에서
  같은 지역 · 같은 용도 · 같은 유찰 회차의 최근 낙찰가를 찾습니다.

이 부분은 **수업 시간에 따로 다룹니다.**

> 투자 판단과 그 결과는 본인 책임입니다.
>
> 채무자·임차인 실명, 주민등록번호, 연락처는 대화에도 산출물에도 넣지 마세요.
