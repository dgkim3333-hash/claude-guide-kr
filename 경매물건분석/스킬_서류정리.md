# 물건 서류 접수·분류

## 표준 구조

이미 `_템플릿/물건폴더_표준`에 뼈대가 있습니다. 이 스킬은 그 구조를 따릅니다.

```
[소재지 전체주소]/
├─ 00_물건카드.md      ← 모든 판단의 단일 출처
├─ 01_원본서류/        ← 등기·대장·감정평가서·명세서 등 원본
├─ 02_분석/            ← 수익률 엑셀, 시세 조사, 분석 노트
└─ 03_산출물/          ← 브리핑 PPTX, 의향서, 신청서
```

새 구조를 만들지 마세요. 이미 정해둔 것을 쓰는 게 맞습니다.

## 두 가지 작업

```bash
python scripts/intake.py plan --folder "<물건폴더>"            # 예행연습
python scripts/intake.py plan --folder "<물건폴더>" --apply    # 실제 이동
python scripts/intake.py init --folder "<새폴더>" --template "<템플릿경로>"
```

`--apply` 없이 실행하면 **무엇이 어디로 갈지만** 보여줍니다. 결과를 사용자에게 보여주고
동의를 받은 뒤 적용하세요. 파일명이 바뀌는 작업이라 되돌리기가 번거롭습니다.

## 표준 파일명

원본서류는 번호를 붙여 정렬 순서를 고정합니다. 폴더를 열었을 때 늘 같은 순서로
보이면, 어떤 서류가 빠졌는지 눈에 바로 들어옵니다.

| 02 | 등기부_토지 | 토지등기 |

오타 변형을 규칙에 넣어둔 이유는, 실제 폴더에서 `건출물대장`·`사곤내역`처럼
잘못 적힌 파일이 발견됐기 때문입니다. 사람이 손으로 받아 적는 이상 오타는 계속 생깁니다.

## 미분류를 남기는 이유

종류를 특정하지 못한 파일은 **옮기지 않고 그대로 둡니다.** 잘못된 위치에 잘못된 이름으로
들어간 파일은, 그냥 정리 안 된 파일보다 찾기 어렵습니다. 원본 이름이 사라져서 무엇이었는지
추적할 단서도 없어지고요.

미분류가 나오면 사용자에게 파일명을 보여주고 **어느 분류인지 물어보세요.** 답을 들으면
그때 옮기면 됩니다. 반복적으로 나오는 유형이면 규칙에 추가할 만합니다.

## 확장자 게이트

원본서류 판정은 **PDF·HWP·이미지에만** 적용합니다.

`공시지가 기준시가 임차보증금 임차권등기.xlsx` 같은 파일이 이름에 '등기'가 들어갔다는
이유로 `01_원본서류/04_등기부.xlsx`가 되면 곤란합니다. 이건 분석용 엑셀입니다.
확장자로 한 번 거르면 이런 사고가 사라집니다.

## 새 물건 시작

```bash
python scripts/intake.py init --folder "<연결한 폴더>/<소재지 전체주소>" --template "<연결한 폴더>/_템플릿/물건폴더_표준"
```

템플릿을 복사하고 `README_사용법.md`는 제거합니다. 그다음 `00_물건카드.md`의
기본 정보부터 채우도록 안내하세요. 물건카드가 채워져 있으면 이후 분석 스킬들이
같은 숫자를 보고 움직입니다.

폴더명은 **소재지 전체주소**로 짓습니다. 사건번호만 쓰면 나중에 어디 물건인지
알아보기 어렵고, 소재지만 쓰면 같은 건물의 다른 호실과 헷갈립니다.

## 정리 후

서류가 제자리에 들어갔으면 분석으로 넘어갑니다. 어떤 스킬이 붙는지는
`_템플릿/물건폴더_표준/README_사용법.md`에 정리돼 있습니다. 물건 유형에 따라
`auction-property-card`, `commercial-unit-auction`, `residential-auction` 등이 이어집니다.

**빠진 서류가 있으면 정리 단계에서 짚어주세요.** 등기부·감정평가서·매각물건명세서·
현황조사서는 판단에 반드시 필요한데, 이 중 없는 게 있으면 분석을 시작하기 전에
확보하는 편이 낫습니다. 나중에 다시 돌아오면 그만큼 시간이 듭니다.
