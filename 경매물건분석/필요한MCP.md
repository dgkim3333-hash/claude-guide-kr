# 필요한 MCP — 무엇을 붙이면 무엇이 좋아지나

MCP(Model Context Protocol)는 Claude가 바깥 자료를 직접 가져오게 해주는 연결 장치입니다.

**하나도 안 붙여도 서류만으로 분석은 됩니다.** 다만 시세·법령을 못 가져와서
`[확인 필요]` 가 많아집니다. 아래 순서대로 하나씩 늘리세요.

---

## 필수 — 이 두 개부터

### 1. `real-estate` — 국토교통부 실거래가

| | |
|---|---|
| 안 붙이면 | **시세 대조를 못 합니다.** 감정가가 적정한지 판단할 근거가 사라집니다 |
| 붙이면 | 아파트·단독·빌라·오피스텔의 **매매·전월세 실거래가**를 직접 가져옵니다 |
| 쓰는 스킬 | `auction-property-card` · `property-location-scan` · `post-auction-eviction` |
| 키 | 공공데이터포털 인증키 |

> 이 프로젝트는 **국토부 실거래가만** 씁니다. KB·호갱노노·아실 같은 민간 추정시세는
> 조회도 인용도 하지 않습니다. 경매정보 사이트의 AI 추정가도 마찬가지입니다.

### 2. `korean-law` — 국가법령정보센터

| | |
|---|---|
| 안 붙이면 | 세율·법령을 **기억에 의존**하게 됩니다. 세법은 자주 바뀌어서 위험합니다 |
| 붙이면 | 조문을 그 자리에서 읽고 **법령ID·시행일까지 근거로 남깁니다** |
| 쓰는 스킬 | `auction-property-card` (취득세·재산세·종부세 계산) |
| 키 | 국가법령정보센터 OC (이메일 아이디) · 무료 |

---

## 권장 — 분석이 훨씬 깊어집니다

### 3. `vworld-landuse` — 브이월드 (국토교통부 공간정보)

| | |
|---|---|
| 붙이면 | **개별공시지가**, 용도지역, 토지거래허가구역 등 규제를 주소만으로 확인 |
| 쓰는 스킬 | `auction-property-card` · `property-location-scan` |
| 키 | 브이월드(vworld.kr) 인증키 · 무료 |

### 4. `datagokr` — 공공데이터포털 묶음

| | |
|---|---|
| 붙이면 | **건축물대장**(면적·용도·위반건축물), 반경 500m **상권 정보**, 온비드 공매, 실거래가 보조 |
| 쓰는 스킬 | `auction-property-card` · `property-location-scan` · `auction-bid-price` |
| 키 | 공공데이터포털 인증키 + 우체국 주소 API 키 |
| 주의 | **설치가 가장 까다롭습니다.** 소스를 직접 받아야 합니다. 수업 시간에 같이 합니다 |

### 5. `court-auction` — 법원경매정보

| | |
|---|---|
| 붙이면 | 사건 상세, **인근 낙찰 통계**, 법원 목록. 입찰가 검증에 씁니다 |
| 쓰는 스킬 | `auction-bid-price` · `post-auction-eviction` |

---

## 필요할 때만

### 6. `korea-law-search` — 판례·법령 검색

명도 단계(`post-auction-eviction`)에서 판례를 찾을 때 씁니다. 입찰 전 분석에는 없어도 됩니다.

### 7~9. 법인 채무자 확인용 3종

채무자가 **법인**일 때 회생·파산 위험을 보는 `corporate-debtor-bankruptcy-check` 가 씁니다.
개인 채무자만 다룬다면 안 붙여도 됩니다.

| MCP | 하는 일 |
|---|---|
| `fsc-financial-info` | 법인 재무제표 |
| `nps-business-enrollment` | 국민연금 가입 사업장 — **직원이 빠져나가면 부실 신호** |
| `nts-business-verification` | 사업자등록 상태 (휴업·폐업) |

## 인증키 발급처

| 발급처 | 주소 | 쓰는 곳 |
|---|---|---|
| 공공데이터포털 | https://www.data.go.kr | `real-estate` · `datagokr` · 법인 3종 |
| 브이월드 | https://www.vworld.kr | `vworld-landuse` |
| 국가법령정보센터 | https://open.law.go.kr | `korean-law` |

**공공데이터포털 키 하나로 여러 서비스를 씁니다.** 다만 서비스마다 **활용신청**을 따로 눌러야
그 서비스가 열립니다. 신청 후 승인까지 시간이 걸리는 것도 있습니다.

## 연결이 안 될 때 확인 순서

1. **Claude 데스크탑을 완전히 껐다 켰습니까?** — 설정을 바꾸면 재시작해야 반영됩니다
2. **채팅창 아래 `+` → `커넥터`** 에 그 이름이 보입니까? — 안 보이면 설정 파일이 안 읽힌 것입니다
3. **키를 붙여넣을 때 앞뒤 공백이나 줄바꿈이 섞이지 않았습니까?** — 가장 흔한 원인입니다

그래도 안 되면 강사에게 **화면 그대로** 보여주세요. 오류 메시지가 원인을 말해 줍니다.
