# 필요한 MCP

이 프로젝트는 MCP **5개**가 필수, **2개**가 선택입니다.
이전 배포본(4개)에서 **KakaoMap 1개가 늘었습니다.**

**하나도 안 붙여도 서류만으로 분석은 됩니다.** 다만 시세·법령을 못 가져와서
`[정보부족]` 이 많아집니다. 아래 순서대로 하나씩 늘리세요.

---

## 미리 만들 폴더

소스를 받아 두는 곳입니다. **`C:\AI` 폴더 안에 `mcp` 폴더를** 만드십시오.

```
C:\AI\mcp\
```

수강생 전원이 같은 경로를 써야 **설정 파일을 그대로 복사해 쓸 수 있습니다.**
다른 곳에 두면 경로를 일일이 고쳐야 합니다.

> 이 폴더는 **MCP 소스를 두는 곳**이고, 물건 서류를 넣는 작업 폴더와 다릅니다.
> 작업 폴더는 따로 만들어 프로젝트에 연결합니다.

| 3 | `datagokr` | 건축물대장(총괄·표제부·전유부·층별), 법정동코드, 실거래가 폴백 | **필요** (2번과 같은 키) | 필요 |

## 1순위 — `korean-law` (국가법령정보센터)

| | |
|---|---|
| 안 붙이면 | 세율·법령을 **기억에 의존**합니다. 세법은 자주 바뀌어서 위험합니다 |
| 붙이면 | 조문을 그 자리에서 읽고 **법령ID·시행일까지 근거로 남깁니다** |
| 설치 | **폴더가 필요 없습니다.** 설정에 한 줄이면 끝 |

공개 패키지입니다 — https://github.com/chrisryugj/korean-law-mcp

```json
"korean-law": {
  "command": "npx",
  "args": ["-y", "korean-law-mcp"],
  "env": { "LAW_OC": "발급받은_OC" }
}
```

**OC 발급** — https://open.law.go.kr 에서 신청합니다. 무료이고 **이메일 아이디**가 곧 OC입니다.

## 2순위 — `real-estate` (국토교통부 실거래가)

| | |
|---|---|
| 안 붙이면 | **시세 대조를 못 합니다.** 감정가가 적정한지 판단할 근거가 사라집니다 |
| 붙이면 | 아파트·단독·빌라·오피스텔의 **매매·전월세 실거래가** |

공개 저장소입니다 — https://github.com/tae0y/real-estate-mcp

**받는 법** — 위 주소에서 초록색 `Code` 버튼 → `Download ZIP` → 압축을 풀어
`C:\AI\mcp\real-estate-mcp\` 으로 이름을 맞춥니다.

```json
"real-estate": {
  "command": "uv",
  "args": ["run", "--directory", "C:\\AI\\mcp\\real-estate-mcp", "python", "src/real_estate/mcp_server/server.py"],
  "env": { "PYTHONIOENCODING": "utf-8", "PYTHONUTF8": "1" }
}
```

키는 공공데이터포털에서 받습니다. **필요한 키 이름과 신청할 서비스는 저장소 README를 따릅니다.**

## 3순위 — `datagokr` (공공데이터포털 묶음)

| | |
|---|---|
| 붙이면 | **건축물대장**(9) · 국토부 실거래가(12) · 법정동코드 · 도로명주소 · 상권정보 |
| 주의 | **설치가 가장 까다롭습니다.** 수업 시간에 같이 합니다 |

**받는 법** — 이 저장소 안에 소스가 들어 있습니다. `vworld-landuse` 와 같은 방식입니다.

1. 저장소 첫 화면에서 초록색 `Code` 버튼 → `Download ZIP`
2. 압축을 풀고 `경매물건분석/mcp/datagokr-mcp/` 폴더를 통째로 복사
3. `C:\AI\mcp\datagokr-mcp\` 에 붙여넣기 — **폴더 이름을 바꾸지 마세요**

**설치 — 명령어 창(검은 창)에서 두 줄입니다.**

```
cd C:\AI\mcp\datagokr-mcp
```

```
uv sync
```

`uv sync` 는 필요한 파이썬 꾸러미를 받아옵니다. **처음 한 번은 몇 분 걸립니다.**
`uv` 가 없다고 나오면 사전 준비의 uv 설치부터 하십시오.

끝나면 아래 블록을 설정 파일에 넣고 Claude 를 껐다 켭니다.

```json
"datagokr": {
  "command": "uv",
  "args": ["--directory", "C:\\AI\\mcp\\datagokr-mcp", "run", "python", "server.py"],
  "env": {
    "DATA_GO_KR_SERVICE_KEY": "공공데이터포털_인증키",
    "EPOST_SERVICE_KEY": "공공데이터포털_인증키",
    "PYTHONIOENCODING": "utf-8",
    "PYTHONUTF8": "1"
  }
}
```

**인증키는 `real-estate` 와 같은 값**입니다. 공공데이터포털에서 받은 **Decoding 된 일반 인증키**를 넣습니다.
`EPOST_SERVICE_KEY` 는 우정사업본부 도로명주소 조회에 쓰이며, 같은 포털에서 따로 활용신청합니다.

> **★ 47개 도구가 전부 검증된 것은 아닙니다.**
> 건축물대장(9) · 실거래가(12) · 법정동코드 · 도로명주소 · 상권정보는 **확인 완료**입니다.
> **캠코 온비드(19)는 1개만 확인**됐고 나머지는 활용신청 상태에 따라 다릅니다.
> 공동주택 단지·도시철도(3)는 디코딩 확인이 남아 있습니다. 자세한 내용은 소스 폴더의 `README.md` 를 보십시오.

## 5순위 — `KakaoMap` (카카오 공식 커넥터)

**설정 파일에 넣는 것이 아닙니다.** 커넥터 목록에서 붙입니다.

| 순서 | 할 일 | 이렇게 되면 성공 |
|---|---|---|
| 1 | `설정` → `커넥터` → **`커넥터 둘러보기`** | 목록이 열립니다 |
| 2 | **KakaoMap** 을 찾아 `연결` | 카카오 로그인 창이 뜹니다 |
| 3 | 카카오 계정으로 로그인 | 목록에 체크 표시가 뜹니다 |
| 4 | **새 대화**를 엽니다 | — |

키를 발급받거나 폴더를 만들 일이 없습니다. **로그인 한 번으로 끝납니다.**

> 커넥터는 **유료 플랜에서만** 제공됩니다.

## 선택 2개

| 서버 이름 | 무엇에 쓰나 | 없으면 |
|---|---|---|
| `duckdb` | 아파트·연립·다세대의 **호별 실제 공시가격** 조회 | 「감정평가액 × 60%」 가정으로 진행. 슬라이드 맨 위에 가정임을 크게 밝힘 |
| `powerpoint` | 열려 있는 PPTX 를 닫아 파일 잠금 해제 | PowerPoint 를 직접 닫으면 됨 |

**둘 다 없어도 분석은 끝까지 돕니다.** 설치 명령은 각 저장소 안내를 따르십시오. `[검증필요]`

### duckdb 를 쓰려면

공공데이터포털 「국토교통부_주택 공시가격 정보」(연 1회 갱신)를 내려받아
`주택공시가격` 테이블로 적재해야 합니다. **전국 1,500만 행이 넘는 대용량**이라
이 배포본에는 포함하지 않았습니다.

```sql
CREATE TABLE 주택공시가격 AS
SELECT * FROM read_csv('<내려받은 파일 경로>', header=true, all_varchar=true);
```

> **`datagokr` 의 `building_housing_price` 로 대체하려 하지 마십시오.**
> 적재가 멈춰 옛 기준연도 값만 반환하고, 단독·다가구는 0건입니다.
> 옛 값을 지금 세금에 쓰면 보유세가 과소 산출됩니다. (스킬 8-E 1-A 참조)

## 폴더 요구 정리

| 무엇 | 필요 여부 |
|---|---|
| `C:\AI\mcp\` — MCP 소스를 두는 곳 | **필수.** `real-estate` · `datagokr` · `vworld-landuse` 셋이 여기서 실행됩니다 |
| 프로젝트에 연결할 작업 폴더 1개 | **필수.** 물건 서류를 넣고 PPTX 가 여기 생깁니다 |
| 그 밖의 폴더 | 없음. 연결한 폴더 밖은 읽지도 쓰지도 않습니다 |

**작업 폴더 경로를 지침에 박지 마십시오.** 「이 프로젝트에 연결한 폴더」로 두면
사람마다 다른 경로에서 그대로 동작합니다.

## 설정 파일 위치

| 설치 방식 | 경로 |
|---|---|
| 일반 설치 | `%APPDATA%\Claude\claude_desktop_config.json` |
| **Microsoft Store 버전** | `%LOCALAPPDATA%\Packages\Claude_<고유문자열>\LocalCache\Roaming\Claude\claude_desktop_config.json` |

Store 버전은 `%APPDATA%\Claude\` 를 쓰면 **작동하지 않습니다.**
어느 쪽인지 모르면 두 경로를 모두 열어보고 파일이 있는 쪽을 씁니다.

**설정 파일을 고친 뒤에는 Claude 를 완전히 종료했다가 다시 켭니다.**
창만 닫으면 반영되지 않습니다.

## 연결이 안 될 때 확인 순서

1. **Claude 데스크탑을 완전히 껐다 켰습니까?** — 설정을 바꾸면 재시작해야 반영됩니다
2. **새 대화를 열었습니까?** — 열려 있던 대화에서는 새 MCP가 안 잡힙니다
3. **채팅창 아래 `+` → `커넥터`** 에 그 이름이 보입니까?
4. **키를 붙여넣을 때 앞뒤 공백이나 줄바꿈이 섞이지 않았습니까?** — 가장 흔한 원인입니다
5. **JSON 콤마** — 서버 블록 사이에 콤마 하나가 빠지면 **전체가 깨집니다**

그래도 안 되면 강사에게 **화면 그대로** 보여주세요. 오류 메시지가 원인을 말해 줍니다.

> 화면을 보여줄 때 **인증키 부분은 가리세요.** 남이 보면 그대로 쓸 수 있습니다.
