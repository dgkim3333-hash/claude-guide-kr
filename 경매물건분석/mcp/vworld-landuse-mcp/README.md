# 브이월드 토지이용 MCP 서버

주소만 넣으면 **개별공시지가 · 용도지역 · 토지이용계획**을 가져옵니다.
경매 물건카드의 「입지·규제」 부분에 쓰입니다.

| 도구 | 하는 일 |
|---|---|
| `get_parcel_info` | PNU · 지번 · **개별공시지가** |
| `get_land_use_plan` | 용도지역 · 토지이용계획 (핵심) |
| `geocode_address` | 주소 → 좌표 |
| `probe_layer` | 레이어 ID가 맞는지 확인 |
| `server_config` | 키가 들어갔는지 확인 (키 값은 안 보여줌) |

---

## 1. 인증키 받기

브이월드는 **각자 발급**받아야 합니다. 남의 키를 같이 쓰면 호출 한도를 같이 소진합니다.

| 순서 | 할 일 |
|---|---|
| 1 | https://www.vworld.kr 회원가입 |
| 2 | 마이포털 → **나의 오픈API → 인증키 관리** |
| 3 | **인증키 발급하기** |
| 4 | 활용 용도에서 **`부동산토지이용계획조회`** 를 고릅니다 |
| 5 | 발급된 키를 복사합니다 |

**개발키는 유효기간이 6개월입니다.** 최대 3회 연장되니 최장 2년입니다.
**만료 전에 연장해야 합니다** — 지나면 새로 발급받아야 합니다.

---

## 2. 파일 두기

이 폴더를 통째로 아래 위치에 둡니다.

```
C:\mcp\vworld-landuse-mcp\
```

---

## 3. 설정 파일에 넣기

`claude_desktop_config.json` 의 `mcpServers` 안에 아래를 추가합니다.

```json
"vworld-landuse": {
  "command": "uv",
  "args": ["run", "--directory", "C:\\mcp\\vworld-landuse-mcp", "python", "vworld_landuse_mcp.py"],
  "env": {
    "VWORLD_API_KEY": "여기에_발급받은_키",
    "PYTHONIOENCODING": "utf-8",
    "PYTHONUTF8": "1"
  }
}
```

**앞뒤에 콤마가 필요한지 확인하십시오.** JSON은 콤마 하나로 전체가 깨집니다.

---

## 4. 확인

Claude 데스크탑을 **완전히 껐다 켜고**, **새 대화**를 열어 물어봅니다.

```
서울특별시 강남구 대치동 316 의 용도지역과 개별공시지가 알려줘
```

키가 들어갔는지만 보려면 이렇게 물어봅니다.

```
vworld-landuse 의 server_config 실행해줘
```

`api_key_set: true` 가 나오면 키는 들어간 것입니다.

---

## 안 될 때

| 증상 | 원인 |
|---|---|
| 도구가 안 보임 | 재시작을 안 했거나, 기존 대화에서 보고 있음. **새 대화**에서 확인 |
| `VWORLD_API_KEY not set` | `env` 에 키가 안 들어감 |
| `geocode_failed` | 주소 형식 문제. 지번 주소로 다시 시도 |
| `zoning` 이 비어 있음 | 레이어 ID 문제. `probe_layer` 로 확인 |
| 인증 오류 | 키 만료(6개월) 또는 활용 용도 미선택 |

---

## 참고

의존성은 `mcp<2` 로 고정돼 있습니다. MCP SDK 2.0에서 `mcp.server.fastmcp` 모듈이
없어졌기 때문입니다. 이 고정을 풀면 서버가 뜨지 않습니다.
