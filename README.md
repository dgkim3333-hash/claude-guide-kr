# Claude 활용 가이드 (한국어)

Claude 데스크탑을 처음 쓰시는 분들을 위한 실습 자료입니다.
투자·경매에 관심 있는 비개발자를 기준으로 만들었습니다.

## 교재부터 받으세요

| 파일 | 내용 |
|---|---|
| ★ [클로드교육_01회차_v3.pdf](클로드교육_01회차_v3.pdf) | **교재 전체.** 설치부터 실전까지 |

**받는 법** — 파일 이름을 누른 뒤, 화면 오른쪽 위의 **다운로드 버튼(아래쪽 화살표)** 을 누르세요.
파일 이름에 마우스 오른쪽 버튼을 눌러 저장하면 **엉뚱한 파일이 받아집니다.**
`.skill` · `.plugin` · `.json` 파일도 모두 같습니다.

이 문서는 교재를 옆에 두고 보는 **설치 안내서**입니다. 순서대로 따라오시면 됩니다.

## 읽는 순서

위에서 아래로 이어집니다. 건너뛰지 말고 차례대로 하시는 편이 덜 막힙니다.

| 단계 | 무엇을 | 비고 |
|---|---|---|
| **1단계** | 설치 — Node.js · uv | 5단계를 하려면 필요합니다 |
| **2단계** | 개인설정 — 나를 알려주기 | ★ 붙여넣기 한 번. 가장 먼저 체감됩니다 |
| **3단계** | Cowork 지침 — 파일 사고 막기 | 파일을 만들게 하실 분만 |
| **4단계** | 스킬 넣기 | 끌어다 놓고 저장 |
| **5단계** | MCP 붙이기 + 인증키 | 키 승인에 1~2일 걸리는 것이 있습니다 |
| **6단계** | 첫 실습 — 테마 레이더 | 화면 하나를 직접 만들어 봅니다 |
| **7단계** | 실전 — 경매 물건 분석 | 관심 있는 분만 |

**2 · 3 · 4단계는 복사해서 붙여넣기만 하면 끝납니다.** 시간이 없으시면 여기까지만 하셔도 Claude가 눈에 띄게 달라집니다.
설치가 필요한 것은 1단계와 5단계뿐입니다.

# 1단계. 설치 — Node.js 와 uv

MCP를 붙이려면 Node.js와 uv가 먼저 깔려 있어야 합니다. **이 둘이 없으면 MCP가 하나도 나타나지 않습니다.**

| 문서 | 내용 |
|---|---|
| [사전준비_설치.md](사전준비_설치.md) | Node.js·uv 설치와 안 될 때 대처법 |

MCP를 아직 안 붙이실 거라면 이 단계는 건너뛰셔도 됩니다.
**2 · 3 · 4단계는 아무것도 설치하지 않아도 됩니다.**

# 잠깐 — 지침을 넣는 자리가 여러 곳입니다

다음 단계로 가기 전에 이것만 알고 가시면 훨씬 덜 헷갈립니다.
Claude는 지침을 넣는 자리가 여러 곳이고, **자리마다 적용 범위가 다릅니다.**

| 자리 | 넣는 곳 | 어디에 적용되나 | 이 문서에서는 |
|---|---|---|---|
| 개인 설정 | 설정 → 개인 설정 | 채팅·Cowork **전부** | 2단계 |
| Cowork 전역 지침 | 설정 → Cowork | **Cowork만** | 3단계 |
| 폴더 지침 | 폴더를 연결한 뒤 폴더 설정 | 그 폴더에서 일할 때만 | — |
| 프로젝트 지침 | 프로젝트 → 지침 편집 | 그 프로젝트에서만 | 7단계 |
| CLAUDE.md 파일 | 홈 폴더의 `.claude` 폴더 | **Claude Code만** | 부록 |

위 네 자리는 넓은 것부터 좁은 것 순서이고, 서로 덮어쓰지 않고 겹쳐서 함께 적용됩니다.

**Claude Code는 위 네 자리를 하나도 읽지 않고, `CLAUDE.md` 만 읽습니다.**
반대로 Cowork과 채팅은 `CLAUDE.md` 를 읽지 않습니다.

# 3단계. Cowork 전역 지침 — 파일 사고 막기

Cowork은 Claude가 **내 컴퓨터의 파일을 직접 만들고 고치는 곳**입니다.
파일을 엉뚱한 데 저장하거나, 내가 손본 걸 덮어써 버리는 일이 자주 생깁니다.
그걸 막는 규칙입니다.

| 파일 | 이런 분께 |
|---|---|
| [Cowork_전역지침.md](Cowork_전역지침.md) | Cowork으로 문서·엑셀·PPT를 만드시는 분 |

개인설정과 달리 **분야를 나누지 않습니다.** 누구에게나 같은 내용이고, 고칠 곳도 없습니다.

| 순서 | 할 일 |
|---|---|
| 1 | 위 파일을 열어 회색 상자 안의 내용을 전부 복사합니다 |
| 2 | Claude 데스크탑 → 좌측 하단 내 이름 → 설정 → Cowork 에 붙여넣습니다 |
| 3 | 새 대화를 열고 "파일을 만들 때 네가 지켜야 할 규칙을 알려줘" 라고 물어 확인합니다 |

# 5단계. MCP 붙이기

여기부터는 Claude가 **바깥 자료를 직접 가져오게** 만드는 단계입니다.
시세·법령·공시자료를 기억에 의존하지 않고 원본에서 읽어 옵니다.

| 문서 | 내용 |
|---|---|
| ★ [중요_claude_desktop_config_기본.json](중요_claude_desktop_config_기본.json) | **MCP 12개.** 여기부터 시작하세요 |
| [claude_desktop_config_실습용.jsonc](claude_desktop_config_실습용.jsonc) | 설명이 잔뜩 달린 확장판. 키 발급처와 주의사항 포함 |

> **6단계 실습에는 이 config가 필요 없습니다.** 실습은 커넥터 하나(PlayMCP)만 있으면 됩니다.
> 키 승인을 기다리는 동안 6단계를 먼저 하셔도 됩니다.
> 여기 MCP들은 **7단계 경매 분석**에서 본격적으로 쓰입니다.

## 기본 config 안에는 세 종류가 섞여 있습니다

| 구분 | 서버 | 준비물 |
|---|---|---|
| **바로 되는 것 (7개)** | youtube · youtube-transcript · context7 · sequential-thinking · playwright · hwp-read · word | **없음.** 붙여넣고 재시작하면 끝 |
| **키만 있으면 되는 것 (2개)** | firecrawl · korean-law | 인증키. **폴더는 필요 없습니다** |
| **키 + 폴더가 필요한 것 (3개)** | real-estate · datagokr · vworld-landuse | 인증키 + `C:\mcp` 폴더 |

**키가 없는 상태로 붙여넣으면 그 5개는 붉은 오류가 납니다.** 고장이 아닙니다.
나머지 7개는 정상 작동합니다. 아직 준비가 안 됐으면 **그 블록들은 지우고 쓰셔도 됩니다.**

준비 방법은 [경매물건분석/필요한MCP.md](경매물건분석/필요한MCP.md) 에 있습니다.

## 인증키는 네 가지입니다

| 키 | 발급처 | 넣는 곳 |
|---|---|---|
| 공공데이터포털 인증키 | https://www.data.go.kr | **3곳 — 전부 같은 값** |
| 브이월드 인증키 | https://www.vworld.kr | 1곳 |
| 법령센터 OC (이메일 아이디) | https://open.law.go.kr | 1곳 |
| Firecrawl API 키 | https://www.firecrawl.dev | 1곳 |

**공공데이터포털은 계정당 키 하나입니다.** 서비스마다 키가 따로 나오지 않으니 같은 값을 세 번 넣으시면 됩니다.
다만 **서비스마다 「활용신청」은 따로 눌러야** 열립니다. 승인에 1~2일 걸리는 것도 있으니 **수업 전날까지 신청을 끝내세요.**
키가 Encoding / Decoding 두 벌로 나오면 보통 **Decoding** 쪽을 씁니다.

# 6단계. 첫 실습 — 내 화면 만들기 (주식 테마 레이더)

한 문장씩 넣어 **내 노트북에 화면 하나를 직접 만들어 보는** 실습입니다.
코드는 한 줄도 쓰지 않고, 커넥터도 하나만 붙이면 됩니다 (PlayMCP).

| 파일 | 내용 |
|---|---|
| [실습_프롬프트_한국테마레이더.md](실습_프롬프트_한국테마레이더.md) | 프롬프트 20개. **한 번에 한 문장씩** 넣습니다 |
| [theme-radar-edu-full.html](theme-radar-edu-full.html) | 완성본. 똑같은 화면이 필요하면 이 파일을 주고 "이대로 만들어줘" 하면 됩니다 |

시작 전에 네 가지를 확인하세요.

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 → 계정 |
| 도구함에 도구 2개를 담았는가 | playmcp.kakao.com (웹) |
| PlayMCP 커넥터가 켜져 있는가 | 채팅창 아래 `+` → `Connectors` |
| **새 대화**를 열었는가 | 왼쪽 사이드바 |

도구함에 담을 두 가지입니다. **웹에서 먼저 담고, 그다음 앱에서 연결합니다.**

| 도구 | 담당 |
|---|---|
| 한국 주식 정보 | 시세 · 순위 · 차트 |
| 네이버 검색 mcp | 뉴스 |

둘 다 API 키를 넣는 칸이 없습니다. 담기만 하면 바로 씁니다.
거꾸로 앱부터 연결하면 **연결은 되는데 쓸 도구가 하나도 없습니다.**

마지막 줄에서도 많이 막힙니다. 커넥터를 방금 켰다면 **열려 있던 대화에서는 잡히지 않습니다.**

같은 문장을 넣어도 사람마다 다른 화면이 나옵니다. 고장이 아닙니다.
똑같은 화면이 필요할 때만 완성본 파일을 쓰세요.

> 시세·순위·차트는 한국투자증권(KIS) 공식 API 실측값이고, 뉴스는 네이버 뉴스 검색 결과입니다.
> 도구 사용법을 익히는 실습이며, 특정 종목의 매수·매도를 권하지 않습니다.

# 7단계. 실전 — 경매 물건 분석

여기까지 오셨으면 이제 실제 업무에 씁니다.
경매 서류를 넣으면 물건카드가 나오는 **프로젝트 한 벌**을 통째로 받으시는 단계입니다.

## 무엇을 해주나

경매 서류 PDF를 폴더에 넣고 **"이 물건 분석해줘"** 한 마디만 하면, 아래를 순서대로 검토해서
**PPTX 물건카드 22~24장**을 만들어 줍니다.

| 넣는 것 | 나오는 것 |
|---|---|
| 매각물건명세서 | 인수되는 권리가 있나 · 임차인이 몇 명이고 각각 대항력이 있나 |
| 등기부 (토지·건물) | 말소기준권리가 무엇이고 무엇이 지워지나 |
| 현황조사서 · 전입세대열람 | 실제로 누가 살고 있나 · 전입일이 근저당보다 빠른가 |
| 감정평가서 | 감정가가 적정한가 · 기준시점이 얼마나 지났나 |
| 문건/송달내역 | 채무자가 저항하고 있나 · **기일을 누가 세웠나** |
| 경매정보 출력물 | 유찰 회차 · 최저매각가격 |

여기에 더해 **권장 입찰가**, **취득세·재산세·종부세**(개인·법인 두 경우), **명도 난이도**,
그리고 마지막 장에 **「확인해야 할 것」** 이 나옵니다. 마지막 장이 사실상 결론입니다 —
답을 준 게 아니라 무엇을 더 봐야 하는지를 알려줍니다.

## 설치 — 세 가지만 하면 됩니다

### ① 물건을 담을 폴더 만들기

내 컴퓨터 아무 곳에나 만듭니다. 예를 들면 `C:\경매\` 처럼요.
그 아래 물건마다 폴더를 하나씩 만들고, **소재지로 이름을 짓습니다.**

```
C:\경매\평택 고덕동 1990-13\
C:\경매\화성 남양읍 2274-13\
```

사건번호로 짓지 않습니다 — 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

### ② 프로젝트 만들고 지침 붙여넣기

| 순서 | 할 일 |
|---|---|
| 1 | Claude 데스크탑 왼쪽 사이드바 → **`프로젝트`** → **`새 프로젝트`** |
| 2 | 이름을 `경매 물건 분석` 으로 넣습니다 |
| 3 | **`지침 편집`** 을 누릅니다 |
| 4 | [경매물건분석/프로젝트지침.md](경매물건분석/프로젝트지침.md) 를 열어 회색 상자 안 내용을 **전부** 복사해 붙여넣습니다 |
| 5 | 프로젝트에 ①에서 만든 폴더(`C:\경매`)를 **연결**합니다 |

### ③ 경매용 스킬 넣기

[경매물건분석/skills](경매물건분석/skills) 에서 `.skill` 파일을 내려받아
**채팅창에 끌어다 놓고 저장 버튼**을 누릅니다. 새 대화부터 적용됩니다.

| 스킬 | 하는 일 | 우선순위 |
|---|---|---|
| auction-property-card | **주 스킬.** 서류 → 분석 → 물건카드 | 필수 |
| auction-bid-price | 저감률 판정 · 권장 입찰가 산출 | 필수 |
| property-location-scan | 주소만으로 입지·상권·규제 조사 | 권장 |
| post-auction-eviction | 낙찰 후 인도명령·명도 문서 | 나중에 |
| bid-result-log | 입찰 결과 기록 · 예측 오차 누적 | 나중에 |
| corporate-debtor-bankruptcy-check | 채무자가 법인일 때 회생·파산 확인 | 필요할 때 |

**`auction-property-card` 하나만 넣어도 기본 분석은 됩니다.** 나머지는 쓰면서 하나씩 늘리세요.
`auction-property-card` 가 나머지를 알아서 불러 씁니다.

## MCP — 안 붙여도 되지만, 붙이면 달라집니다

**하나도 안 붙여도 서류만으로 분석은 됩니다.** 다만 시세·법령을 직접 못 가져와서
`[확인 필요]` 가 많아집니다.

| MCP | 안 붙이면 | 준비물 |
|---|---|---|
| ★ **korean-law** | 세율·법령을 기억에 의존합니다. 세법은 자주 바뀌어서 위험합니다 | OC만 (폴더 불필요) |
| ★ **real-estate** | **시세 대조를 못 합니다.** 감정가가 적정한지 판단할 근거가 사라집니다 | 키 + `C:\mcp` |
| datagokr | 건축물대장·상권 정보·온비드 공매를 못 가져옵니다 | 키 + `C:\mcp` |

## 첫 사용법

물건 폴더에 서류 PDF를 넣고, 프로젝트 안에서 **새 대화**를 열어 이렇게 말합니다.

```
이 물건 분석해줘
```

**매각물건명세서가 없으면 분석의 절반이 날아갑니다.** 이것만은 꼭 넣으세요.
**토지 등기부도 자주 빠집니다** — 건물 등기부만 넣으면 토지 권리를 못 봅니다.

자주 쓰는 다른 말들입니다.

```
물건카드 만들어줘. 개인·법인 두 경우로 세금 넣어줘
```
```
입찰가 다시 계산해줘. 다음 기일이 34.3%로 확인됐어
```
```
공시가격 000원으로 확인됐어. 보유세 다시 산출해줘
```
```
낙찰됐어. 명도 계획 만들어줘
```

## 미리 알아두실 것

**공시가격은 감정평가액의 50%로 가정합니다.**
주택 공시가격을 개인이 조회할 수 있는 공개 API가 없기 때문입니다.
정확한 값이 필요하면 [부동산공시가격알리미](https://www.realtyprice.kr) 에서 확인해 알려주세요.
알려주면 즉시 다시 계산합니다.

**종부세는 낙찰 다음 해가 첫 과세연도입니다.**
과세기준일이 매년 6월 1일이라, 6월 이후에 잔금을 내면 그 해 종부세는 없습니다.
그래서 현행 세율이 아니라 **다음 해 세율**로 계산합니다.
2026.08.03 재정경제부 세제개편안 기준이며 **국회 통과 전 정부안**입니다.

**낙찰 계수는 실측 데이터지만 시장에 따라 변합니다.**
산출일이 6개월을 넘으면 참고치로만 쓰고, 인근 낙찰사례로 반드시 교차 검증하세요.

**민간 추정시세는 쓰지 않습니다.**
국토교통부 실거래가만 씁니다. 경매정보 사이트의 AI 추정가도 쓰지 않습니다.

**물건카드를 남에게 보내지 마세요.** 임차인 정보가 들어 있습니다.

> 이 도구는 판단 재료를 모아줄 뿐 대신 결정하지 않습니다.
> 실제 입찰 전에는 등기부·매각물건명세서 원문과 전문가 확인이 반드시 필요합니다.
> 특정 물건의 입찰을 권유하지 않으며, 투자 판단과 그 결과는 본인 책임입니다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| 지침이 안 먹는 것 같다 | **새 대화**를 열었는지 확인하세요. 열려 있던 대화에는 안 붙습니다 |
| MCP 5개가 붉게 뜬다 | 키·폴더가 아직 없는 것입니다. 나머지 7개는 정상입니다 |
| 키를 넣었는데 인증 오류 | Encoding / Decoding 을 바꿔 넣어보세요. 앞뒤 공백도 확인 |
| 특정 조회만 실패한다 | 그 서비스를 **활용신청** 안 한 것입니다 |
| 금액을 엉뚱하게 읽는다 | 경매정보 PDF는 텍스트에 숫자가 없는 경우가 많습니다. "이미지로 읽어줘" 라고 하세요 |
| 시세를 못 가져온다 | `real-estate` 가 안 붙은 것입니다. 채팅창 `+` → `Connectors` 에서 확인하세요 |
| 슬라이드 글자가 겹친다 | `_card.js` 를 고쳐 다시 생성하게 하세요. PPTX를 손으로 고치지 마세요 |
