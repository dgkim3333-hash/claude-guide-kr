# Claude 활용 가이드 (한국어)

Claude 데스크탑을 처음 쓰시는 분들을 위한 실습 자료입니다.
투자·경매에 관심 있는 비개발자를 기준으로 만들었습니다.

## 시작하기 전에

MCP를 붙이려면 Node.js와 uv가 먼저 깔려 있어야 합니다. 이 둘이 없으면 MCP가 하나도 나타나지 않습니다.

| 문서 | 내용 |
|---|---|
| ★ [중요_claude_desktop_config_기본.json](중요_claude_desktop_config_기본.json) | 붙여넣기만 하면 바로 연결되는 MCP 8개. 여기부터 시작하세요 |
| [사전준비_설치.md](사전준비_설치.md) | Node.js·uv 설치와 안 될 때 대처법 |
| [claude_desktop_config_실습용.jsonc](claude_desktop_config_실습용.jsonc) | MCP 설정 파일 템플릿. 넣는 위치와 API 키 발급처 포함  |

## 어디에 무엇을 넣나

Claude는 지침을 넣는 자리가 여러 곳이고, **자리마다 적용 범위가 다릅니다.**

| 자리 | 넣는 곳 | 어디에 적용되나 |
|---|---|---|
| 개인 설정 | 설정 → 개인 설정 | 채팅·Cowork **전부** |
| Cowork 전역 지침 | 설정 → Cowork | **Cowork만** |
| 폴더 지침 | 폴더를 연결한 뒤 폴더 설정 | 그 폴더에서 일할 때만 |
| 프로젝트 지침 | 프로젝트 → 지침 편집 | 그 프로젝트에서만 |
| CLAUDE.md 파일 | 홈 폴더의 `.claude` 폴더 | **Claude Code만** |

위 네 자리는 넓은 것부터 좁은 것 순서이고, 서로 덮어쓰지 않고 겹쳐서 함께 적용됩니다.

**Claude Code는 위 네 자리를 하나도 읽지 않고, `CLAUDE.md` 만 읽습니다.**
반대로 Cowork과 채팅은 `CLAUDE.md` 를 읽지 않습니다.

## 개인설정 템플릿

Claude가 매번 나에 대해 알고 답하도록 만드는 설정입니다.
아래 세 가지 중 **본인에게 맞는 것 하나만** 골라 쓰세요.

| 파일 | 이런 분께 |
|---|---|
| [개인설정_A_주식용.md](개인설정_A_주식용.md) | 주식 투자에 관심 있는 분 |
| [개인설정_B_경매공매용.md](개인설정_B_경매공매용.md) | 부동산 경매·공매에 관심 있는 분 |
| [개인설정_C_주식과경매공매용.md](개인설정_C_주식과경매공매용.md) | 둘 다 관심 있는 분 |

| 순서 | 할 일 |
|---|---|
| 1 | 위 표에서 본인에게 맞는 파일 하나를 클릭합니다 |
| 2 | 회색 상자 안의 내용을 전부 복사합니다 |
| 3 | Claude 데스크탑 → 좌측 하단 내 이름 → 설정 → 개인 설정 에 붙여넣습니다 |
| 4 | 맨 첫 줄을 본인에 맞게 고칩니다 |
| 5 | 새 대화를 열고 "내가 어떤 일을 하는 사람인지 알고 있어?" 라고 물어 확인합니다 |

## Cowork 전역 지침

Cowork은 Claude가 **내 컴퓨터의 파일을 직접 만들고 고치는 곳**입니다.
파일을 엉뚱한 데 저장하거나, 내가 손본 걸 덮어써 버리는 일이 자주 생깁니다.
그걸 막는 규칙입니다.

| 파일 | 이런 분께 |
|---|---|
| [Cowork_전역지침.md](Cowork_전역지침.md) | Cowork으로 문서·엑셀·PPT를 만드시는 분 |

개인설정과 달리 **분야를 나누지 않습니다.** 누구에게나 같은 내용이고, 고칠 곳도 없습니다.

| 순서 | 할 일 |
|---|---|
| 1 | 위 파일을 열어 회색 상자 안의 내용을 전부 복사합니다 |
| 2 | Claude 데스크탑 → 좌측 하단 내 이름 → 설정 → Cowork 에 붙여넣습니다 |
| 3 | 새 대화를 열고 "파일을 만들 때 네가 지켜야 할 규칙을 알려줘" 라고 물어 확인합니다 |

## Claude Code 지침 (CLAUDE.md)

**명령어 창에서 Claude Code를 쓰시는 분만** 해당됩니다.
안 쓰시면 넘어가셔도 됩니다.

| 파일 | 이런 분께 |
|---|---|
| [ClaudeCode_전역지침.md](ClaudeCode_전역지침.md) | 명령어 창에서 Claude Code를 쓰시는 분 |

Claude Code는 개인 설정도 Cowork 지침도 읽지 않습니다.
그래서 이 파일은 혼자서 완결되도록 따로 썼습니다.

`.claude` 는 숨은 폴더라 손으로 찾아가기 번거롭습니다.
문서 안에 **Cowork에게 시켜서 만드는 프롬프트**가 들어 있으니 그대로 복사해 쓰시면 됩니다.

## 주의

주민번호, 계좌번호, 비밀번호, 거래처·채무자 실명은 개인설정에도 대화에도 넣지 마세요.

지침은 **새 대화**부터 적용됩니다. 저장해도 기존 대화에는 붙지 않습니다.

지침은 모든 대화에 매번 얹힙니다. 길수록 중요한 규칙이 묻히니 함부로 늘리지 마세요.

여기 있는 건 **출발점이지 정답이 아닙니다.** 본인 방식에 맞게 고쳐 쓰세요.

이 자료의 내용은 참고용이며, 투자와 입찰의 결과는 본인 책임입니다.
