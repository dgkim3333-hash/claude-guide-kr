### 받는 법 — 통째로 받는 게 가장 빠릅니다

파일이 여러 개입니다. **하나씩 받지 마세요.**

1. 이 화면 오른쪽 위 **초록색 `Code`** 버튼을 누릅니다
2. 맨 아래 **`Download ZIP`** 을 누릅니다
3. 받은 파일을 **오른쪽 클릭 → 「압축 풀기」**

한 번에 **교재 PDF · 스킬 · 설정 파일 · 개인설정 템플릿 · 실습 자료가 전부** 들어옵니다.
풀면 `claude-guide-kr-main` 폴더가 생기고, 폴더 구조는 이 화면과 같습니다.

**여기서 많이 막힙니다.**

- **압축을 반드시 푸세요.** 윈도우는 zip 안을 폴더처럼 열어줘서, 안 푼 채로 쓰려다 실패하는 분이 많습니다
- **파일 이름이 한글이라 깨질 수 있습니다.** 깨지면 반디집 같은 프로그램으로 다시 풀어 보세요
- **ZIP 은 받는 순간의 사본입니다.** 자료가 갱신되면 다시 받아야 합니다

**파일 하나만 받고 싶을 때** — 파일 이름을 누른 뒤, 화면 오른쪽 위의 **다운로드 버튼(아래쪽 화살표)** 을 누르세요.
파일 이름에 마우스 오른쪽 버튼을 눌러 저장하면 **엉뚱한 파일이 받아집니다.**
`.skill` · `.plugin` · `.json` 파일도 모두 같습니다.
`Raw` → `Ctrl+S` 로도 되지만 **`.txt` 로 저장되는 일이 잦으니** 저장 창에서 확장자를 꼭 확인하세요.

| **Git** | 부록 A (데스크탑 `Code` 탭) | `Code` 탭이 열리지 않습니다 |

| 문서 | 내용 |
|---|---|
| [사전준비_설치.md](사전준비_설치.md) | Node.js·uv 설치와 안 될 때 대처법 |

## ★ 검은 창은 두 종류입니다 — 여기서 제일 많이 막힙니다

설치 명령을 넣는 **검은 창이 두 가지**인데 생김새가 거의 같습니다. 그런데 **문법이 다릅니다.**

| | PowerShell | 명령 프롬프트 (cmd) |
|---|---|---|
| 첫 줄 | `PS C:\Users\내이름>` | `C:\Users\내이름>` |
| 내 폴더를 뜻하는 말 | `$env:USERPROFILE` | `%USERPROFILE%` |

**앞에 `PS` 가 붙어 있는지만 보시면 됩니다.** 이 교재는 전부 **PowerShell 기준**입니다.
(PowerShell 5.1 이든 7.x 든 문법은 같습니다. `PS` 로 시작하면 맞게 여신 것입니다.)

명령 프롬프트에 PowerShell 문법을 넣으면 이렇게 나옵니다.

```
파일 이름, 디렉터리 이름 또는 볼륨 레이블 구문이 잘못되었습니다.
```

**설치가 실패한 게 아닙니다.** 창을 잘못 고른 것입니다.

## ★ "uv 를 찾을 수 없습니다" 가 뜰 때

원인이 두 가지입니다. **설치가 안 됐거나, 열려 있던 창이 예전 경로를 기억하고 있거나.**
어느 쪽인지부터 가르세요.

**① 파일이 실제로 깔렸는지 봅니다** (PowerShell 기준)

```powershell
dir "$env:USERPROFILE\.local\bin\uv.exe"
```

- 날짜와 크기가 나오면 **설치는 된 것** → ②로
- 여기서도 "찾을 수 없습니다" → **설치가 안 된 것** → 설치 명령을 다시

**② 창을 완전히 닫고 새로 엽니다** → **③ 그래도 안 되면 컴퓨터 재시작**

자세한 절차와 명령 프롬프트용 명령어는 [사전준비_설치.md](사전준비_설치.md) §4 에 있습니다.

## ★ 회사 PC 라 설치 자체가 안 될 때 — 이 두 줄을 순서대로

회사 PC 는 **인터넷에서 받은 스크립트를 실행하지 못하게** 막아둔 곳이 많습니다.
그래서 위 설치 명령이 그대로는 안 먹힙니다. 아래 두 가지를 순서대로 해보시면 원인이 갈립니다.

**[1] 실행 권한을 이번 한 번만 풀고 설치합니다** — 한 줄 전체를 복사하셔야 합니다

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**[2] 위가 안 되면 winget 으로 깝니다**

```powershell
winget install --id=astral-sh.uv -e
```

**[3] 확인** — 창을 완전히 닫고 새로 연 다음

```powershell
uv --version
```

버전 번호가 나오면 성공입니다.

> **`[2]` 로 깔았다면 폴더 확인이 아니라 `uv --version` 으로만 판정하세요.**
> winget 은 설치 위치가 달라서, 앞의 `dir` 확인이 **성공했는데도 "찾을 수 없습니다"로 나옵니다.**

**`[1]` `[2]` 가 모두 실패하면 회사 정책·방화벽 문제입니다.**
**개인이 우회하지 마세요.** 회사 규정 위반이 될 수 있습니다.
전산팀에 「astral.sh 접속과 uv 설치 허용」을 요청하시거나, 개인 PC 로 실습하세요.
어떤 문구가 나오면 보안인지는 [사전준비_설치.md](사전준비_설치.md) §4 「회사 PC라 보안 정책에 막힐 때」에 표로 정리해 두었습니다.

> **uv 가 없어도 대부분은 됩니다.** 채팅·개인설정·스킬·프로젝트·엑셀 실습은 uv 없이 전부 돌아갑니다.
> uv 가 필요한 것은 파이썬으로 만든 일부 MCP 뿐입니다.

## ★ 폴더 하나를 먼저 만드세요

**`C:` 드라이브 바로 아래에 `AI` 폴더**를 만듭니다. 앞으로 쓰는 것을 전부 여기 모읍니다.

```
C:\AI
```

| 안에 생길 것 | 무엇 |
|---|---|
| `C:\AI\mcp\` | 5단계에서 받는 MCP 서버 소스 |
| `C:\AI\경매\` | 8단계에서 쓰는 경매 물건 서류 |

**수강생 전원이 같은 경로를 씁니다.** 그래야 설정 파일을 그대로 복사해 쓸 수 있습니다.
다른 곳에 두면 경로를 일일이 고쳐야 하고, 거기서 대부분 막힙니다.

설치 자체는 5단계 직전에 하셔도 늦지 않습니다.
다만 **여기서 막히는 분이 가장 많습니다.** 수업 전에 미리 깔아두시면 그날 시간을 벌 수 있습니다.

## Git 은 무엇이고 왜 필요한가

**파일이 언제 어떻게 바뀌었는지 기록해 두는 프로그램**입니다.
사진 찍듯이 상태를 저장해 두고, 나중에 아무 시점으로나 되돌아갈 수 있게 해줍니다.
**무한 되돌리기 + 변경 장부**라고 생각하시면 됩니다.

| | Git 이 없으면 | Git 이 있으면 |
|---|---|---|
| 되돌리기 | 못 합니다 | 며칠 전 상태로도 돌아갑니다 |
| 뭐가 바뀌었나 | 모릅니다 | 바뀐 줄에 색이 칠해집니다 |

부록 B 의 「Code 에만 있는 것 — 되돌리기가 됩니다 · 어디를 고쳤는지 보여줍니다」가
**전부 Git 덕분**입니다. 그래서 `Code` 탭이 Git 을 요구합니다.

### ★ Git 과 GitHub 는 다른 것입니다

이름이 비슷해서 가장 많이 헷갈립니다.

| | 무엇 |
|---|---|
| **Git** | 내 컴퓨터에 까는 **프로그램**. 혼자 돌아갑니다 |
| **GitHub** | 그 기록을 올려두는 **웹사이트**. 이 자료를 받는 그곳 |

**교재를 받으려고 GitHub 에 가입할 필요가 없듯이, Git 을 깐다고 GitHub 를 쓰는 것도 아닙니다.**

### 까는 법

아래 주소에서 받아 **계속 「다음」만 누르시면 됩니다.** 설정은 하나도 안 건드려도 됩니다.

```
https://git-scm.com/downloads/win
```

깔고 나면 **Claude 데스크탑을 껐다 켜세요.** 그래야 `Code` 탭이 Git 을 찾습니다.

> **`Code` 탭을 안 쓰실 거면 Git 은 안 깔아도 됩니다.** 채팅·Cowork·MCP 는 Git 없이 전부 됩니다.

# 잠깐 — 지침을 넣는 자리가 여러 곳입니다

다음 단계로 가기 전에 이것만 알고 가시면 훨씬 덜 헷갈립니다.
Claude는 지침을 넣는 자리가 여러 곳이고, **자리마다 적용 범위가 다릅니다.**

| 자리 | 넣는 곳 | 어디에 적용되나 | 이 문서에서는 |
|---|---|---|---|
| 개인 설정 | 설정 → **일반** → 「Claude 지침」 | 채팅·Cowork **전부** | 2단계 |
| Cowork 전역 지침 | 설정 → **Cowork** → 「전역 지침」 | **Cowork만** | 3단계 |
| 폴더 지침 | 폴더를 연결한 뒤 폴더 설정 | 그 폴더에서 일할 때만 | — |
| 프로젝트 지침 | 프로젝트 → 지침 편집 | 그 프로젝트에서만 | 6단계 · 8단계 |
| CLAUDE.md 파일 | 홈 폴더의 `.claude` 폴더 | **Claude Code만** | 부록 |

위 네 자리는 넓은 것부터 좁은 것 순서이고, 서로 덮어쓰지 않고 겹쳐서 함께 적용됩니다.

**Claude Code는 위 네 자리를 하나도 읽지 않고, `CLAUDE.md` 만 읽습니다.**
반대로 Cowork과 채팅은 `CLAUDE.md` 를 읽지 않습니다.

# 여는 법과 저장하는 법

넣는 방식이 두 갈래입니다. **이것만 구분하면 헷갈리지 않습니다.**

| 갈래 | 무엇 | 어떻게 |
|---|---|---|
| **화면에 붙여넣기** | 개인설정 · Cowork 전역지침 | 설정 화면의 입력칸에 **내용을 복사해** 붙여넣습니다 |
| **파일 그대로 놓기** | `claude_desktop_config.json` · `CLAUDE.md` | 받은 **파일을 제자리에 놓습니다.** 내용을 복사할 필요가 없습니다 |

## ① 개인설정 — 설정 → 일반 → 「Claude 지침」

| 순서 | 할 일 |
|---|---|
| 1 | Claude 데스크탑에서 **설정**을 엽니다 |
| 2 | 왼쪽 목록 맨 위 **`일반`** |
| 3 | 「프로필」 아래 **「Claude 지침」** 이라는 큰 입력칸에 붙여넣습니다 |
| 4 | **창을 닫으면 자동 저장됩니다.** 저장 버튼은 없습니다 |
| 5 | **새 대화**를 열고 "내가 어떤 일을 하는 사람인지 알고 있어?" 라고 물어 확인합니다 |

> **「개인 설정」이라는 메뉴는 없습니다.** `일반` 탭 안의 「Claude 지침」이 그것입니다.
> 화면 설명에 *"채팅 및 Cowork 전반에 걸쳐 이 내용을 기억합니다"* 라고 적혀 있으면 제자리입니다.

## ② Cowork 전역 지침 — 설정 → Cowork → 「전역 지침」

| 순서 | 할 일 |
|---|---|
| 1 | 설정 → 왼쪽 목록 **`Cowork`** |
| 2 | **화면을 아래로 끝까지 내립니다** |
| 3 | 맨 아래 「전역 지침」 오른쪽의 **[편집]** 버튼 |
| 4 | 붙여넣고 창을 닫으면 자동 저장됩니다 |
| 5 | **새 대화**를 열고 "파일을 만들 때 네가 지켜야 할 규칙을 알려줘" 로 확인합니다 |

> **스크롤을 안 내리면 안 보입니다.** 여기서 많이 막힙니다.
> 같은 화면 맨 위의 「신뢰할 수 있는 Cowork 폴더 [관리]」는 자주 쓰는 폴더를 미리 등록해
> 매번 확인을 묻지 않게 하는 기능입니다.

## ③ 설정 파일 — 설정 → 데스크톱 앱 → 개발자 → [구성 편집]

**숨은 폴더 경로를 손으로 찾아갈 필요가 없습니다.** 버튼이 대신 열어줍니다.

| 순서 | 할 일 |
|---|---|
| 1 | 설정 → 왼쪽 목록 아래쪽 **`데스크톱 앱`** → **`개발자`** |
| 2 | 「로컬 MCP 서버」의 **[구성 편집]** 을 누릅니다 |
| 3 | 파일 탐색기가 열리고 **`claude_desktop_config`** 파일이 보입니다 |
| 4 | 그 파일을 **더블클릭** — 메모장이나 VS Code로 열립니다 |
| 5 | 내용을 바꾸고 **저장**합니다 (인코딩 UTF-8) |
| 6 | **Claude 데스크탑을 완전히 종료했다 다시 켭니다** → 아래 ⑤ 를 그대로 따라 하세요 |

**처음 쓰시는 분은** 3번에서 열린 폴더에 받은 `중요_claude_desktop_config_기본.json` 을
**`claude_desktop_config.json` 으로 이름을 바꿔 넣으면** 됩니다. 내용을 복사할 필요가 없습니다.

> ★ **고치기 전에 원본을 복사해 두세요.** 콤마 하나만 어긋나도 MCP가 하나도 안 뜹니다.
> ★ `claude_desktop_config_실습용.jsonc` 는 **그대로 넣으면 안 됩니다.** 주석(`//`)이 들어 있어
>   앱이 못 읽을 수 있습니다. 그건 읽고 이해하는 용도이고, 실제로 넣는 것은 주석 없는 `.json` 쪽입니다.

### MCP가 안 붙을 때도 이 화면에서 봅니다

같은 `개발자` 화면 왼쪽에 **붙어 있는 서버 목록**이 나옵니다. 하나를 고르면

- 실행에 쓰는 **명령어**와 **인수**(경로가 맞는지 여기서 확인)
- **[로그 보기]** — 왜 실패했는지 이 로그에 적혀 있습니다

붉은 오류가 났을 때 "왜 안 되지" 하고 헤매지 마시고 **로그부터 여세요.**

## ⑤ 「Claude 를 완전히 종료한다」가 무슨 뜻인가

**창 오른쪽 위 X 를 눌러도 Claude 는 꺼지지 않습니다.**
화면에서만 사라지고 **뒤에서 계속 돌아갑니다.** 이 상태로 다시 열면
설정을 아무리 고쳐도 반영되지 않습니다. **여기서 가장 많이 막힙니다.**

| 순서 | 할 일 |
|---|---|
| 1 | 창의 **X** 를 눌러 창을 닫습니다 |
| 2 | 화면 **오른쪽 아래, 시계 왼쪽**을 보세요. **`∧`** (위를 향한 작은 화살표) 가 있습니다 |
| 3 | **`∧`** 를 클릭하면 아이콘이 여러 개 든 **작은 상자**가 뜹니다 |
| 4 | 그 안에서 **Claude 아이콘**을 찾습니다 — **검은 별표(✳) 모양**입니다. 마우스를 올리면 이름이 떠서 확인됩니다 |
| 5 | 그 아이콘에 **마우스 오른쪽 버튼** → **종료**(Quit) |
| 6 | **아이콘이 상자에서 사라지면** 완전히 꺼진 것입니다 |
| 7 | 시작 메뉴에서 Claude 를 다시 실행합니다 |

> **상자에 Claude 아이콘이 아예 없으면** 이미 꺼져 있는 것입니다. 그냥 다시 실행하세요.
> **`∧` 가 안 보이면** 아이콘이 이미 펼쳐져 있는 것입니다. 작업 표시줄 오른쪽을 그대로 살펴보세요.
> 사람마다 상자 안 아이콘 개수와 배치가 다릅니다. 개수로 찾지 마시고 **모양으로** 찾으세요.

**컴퓨터를 다시 시작하는 것과는 다른 이야기입니다.** Claude 만 껐다 켜면 됩니다.

### 파일은 어디에 있나

받으신 ZIP 을 푸셨으면 **그 안에 이미 들어 있습니다.** 따로 받을 필요 없습니다.

```
claude-guide-kr-main\claude-guide-kr.plugin
```

저장소에서 이 파일만 받으시려면 위 표의 파일 이름을 누른 뒤 화면 오른쪽 위 **다운로드 버튼(아래쪽 화살표)** 을 누르세요.
**오른쪽 클릭 → 「다른 이름으로 저장」은 엉뚱한 파일이 받아집니다.**

### 넣는 순서

| 순서 | 할 일 | 이렇게 되면 성공 |
|---|---|---|
| 1 | `설정` → `기능` → **「코드 실행 및 파일 생성」을 켭니다** | 스위치가 켜짐으로 바뀝니다 |
| 2 | `설정` → `사용자 지정` → `플러그인` | 플러그인 목록 화면이 열립니다 |
| 3 | 우측 상단 **`추가`** → **`플러그인 업로드`** | 파일 고르는 창이 뜹니다 |
| 4 | `claude-guide-kr.plugin` 을 고릅니다 | 목록에 **claude-guide-kr** 이 생깁니다 |
| 5 | **새 대화**를 엽니다 | — |

「설치했는데 아무것도 안 돼요」는 대부분 이것입니다.

### 들어갔는지 확인하기

`설정` → `사용자 지정` → `스킬` 에 **8개가 한꺼번에** 나타나면 성공입니다.

새 대화에서 이렇게 물어봐도 됩니다.

```
지금 쓸 수 있는 스킬 목록을 보여줘
```

### 눈으로 확인하는 법 — 금액 서식이 가장 빠릅니다

새 대화에 이렇게 넣어보세요.

```
감정가 3억5800만원인 물건의 70%가 얼마인지 알려줘
```

| 스킬이 걸렸을 때 | 안 걸렸을 때 |
|---|---|
| `250,600,000원` | `2억 5060만원` · `25,060만원` |

**원 단위 콤마로 나오면 `number-format-guard` 가 작동한 것입니다.**
차이가 바로 보여서 확인용으로 좋습니다.

### 스킬은 불러서 쓰는 게 아닙니다

여덟 개를 넣었다고 매번 여덟 개가 도는 것이 아닙니다.
**그 상황이 올 때만** 해당 스킬이 저절로 켜집니다. 금액을 쓸 때, 경매 물건을 물을 때, MCP 가 안 붙을 때처럼요.
그래서 평소에는 있는지도 모르고 쓰게 됩니다.

### 마켓플레이스로는 안 됩니다

「저장소에서 추가」에 이 저장소 주소를 넣어도 **잡히지 않습니다.**
저장소 안에 플러그인 표시 파일(`.claude-plugin`)이 없기 때문입니다.
이 묶음은 **파일 업로드로만** 설치됩니다. 마켓플레이스는 아래 「남이 만든 스킬 묶음」 절에서 따로 다룹니다.

> **이미 같은 스킬을 개인 스킬로 넣어두셨다면** 플러그인까지 넣으면 같은 스킬이 두 벌이 됩니다.

> ### ★ `.skill` 파일은 열어보지 마세요
>
> 압축 파일입니다. 메모장이나 VS Code 로 열면 **「파일이 이진이거나 지원되지 않는 텍스트 인코딩」** 이라고만 나옵니다.

> 부동산·주식 스킬은 자료를 정리하고 위험을 드러낼 뿐, 투자를 권유하지 않습니다.

그 창구를 **마켓플레이스**라고 합니다. 앱 스토어라고 생각하시면 됩니다.

Claude 에는 **「Knowledge Work」 마켓플레이스가 처음부터 붙어 있습니다.**
그 밖의 것은 직접 추가해야 하고, **GitHub 저장소 주소만 있으면 추가할 수 있습니다.**

### Superpowers — Anthropic 공식 목록에 올라 있는 스킬 묶음

Jesse Vincent 가 만든 **개발 방법론 스킬 묶음**입니다.
「먼저 물어보고 → 설계를 보여주고 → 계획을 세우고 → 테스트부터 짜고 → 스스로 코드리뷰」 순서를
Claude 에게 강제합니다. Anthropic 공식 플러그인 목록에 등재돼 있습니다.

> **솔직히 말씀드립니다.** 이건 **코드를 짜는 분에게 유용한 도구**입니다.
> 이 교육의 주식·경매 실습에는 직접 쓸 일이 거의 없습니다.

# 5단계. MCP 붙이기

여기부터가 이 자료의 핵심입니다.
지금까지는 Claude에게 **말하는 법**을 가르쳤다면, 여기서는 Claude에게 **눈과 손**을 달아줍니다.
시세·법령·공시자료를 기억에 의존하지 않고 **원본에서 직접 읽어 오게** 만드는 단계입니다.

> ### 오늘 다 못 붙여도 괜찮습니다. 다만 건너뛰지는 마세요.
>
> 키를 받고, 폴더를 만들고, 설정 파일을 고치는 일입니다.
> 앞 단계들처럼 붙여넣기 한 번으로 끝나지 않아 시간이 걸립니다.
> 그래도 이 단계는 **읽고 넘어가셔야 합니다.**
>
> - MCP가 무엇인지 알아야 **7단계 실습에서 커넥터를 왜 켜는지** 이해됩니다
> - MCP가 무엇인지 알아야 **8단계에서 시세가 안 나올 때 원인을 짚을 수 있습니다**
> - 붉은 오류가 떴을 때 **고장인지 준비가 덜 된 것인지** 구분할 수 있습니다
>
> **키는 나중에 넣으셔도 됩니다. 구조를 아는 것은 지금 하셔야 합니다.**

| 문서 | 내용 |
|---|---|
| ★ [중요_claude_desktop_config_기본.json](중요_claude_desktop_config_기본.json) | **MCP 12개.** 여기부터 시작하세요 |
| [claude_desktop_config_실습용.jsonc](claude_desktop_config_실습용.jsonc) | 설명이 잔뜩 달린 확장판. 키 발급처와 주의사항 포함 |

**넣는 법은 위 「여는 법과 저장하는 법」 ③ 을 그대로 따르세요.**
설정 → 데스크톱 앱 → 개발자 → [구성 편집] 입니다.

## 기본 config 안에는 세 종류가 섞여 있습니다

| 구분 | 서버 | 준비물 |
|---|---|---|
| **바로 되는 것 (7개)** | youtube · youtube-transcript · context7 · sequential-thinking · playwright · hwp-read · word | **없음.** 붙여넣고 재시작하면 끝 |
| **키만 있으면 되는 것 (2개)** | firecrawl · korean-law | 인증키. **폴더는 필요 없습니다** |
| **키 + 폴더가 필요한 것 (3개)** | real-estate · datagokr · vworld-landuse | 인증키 + `C:\AI\mcp` 폴더 |

**키가 없는 상태로 붙여넣으면 그 5개는 붉은 오류가 납니다.** 고장이 아닙니다.
나머지 7개는 정상 작동합니다. 아직 준비가 안 됐으면 **그 블록들은 지우고 쓰셔도 됩니다.**

준비 방법은 [경매물건분석/필요한MCP.md](경매물건분석/필요한MCP.md) 에 있습니다.

## 인증키는 네 가지입니다

| 키 | 발급처 | 넣는 곳 |
|---|---|---|
| 공공데이터포털 인증키 | https://www.data.go.kr | **3곳 — 전부 같은 값** |
| 브이월드 인증키 | https://www.vworld.kr | 1곳 |
| 법령센터 OC (이메일 아이디) | https://open.law.go.kr | 1곳 |
| Firecrawl API 키 | https://www.firecrawl.dev | 1곳 |

**공공데이터포털은 계정당 키 하나입니다.** 서비스마다 키가 따로 나오지 않으니 같은 값을 세 번 넣으시면 됩니다.
다만 **서비스마다 「활용신청」은 따로 눌러야** 열립니다. 이걸 안 누르면 그 조회만 실패합니다.
키가 Encoding / Decoding 두 벌로 나오면 보통 **Decoding** 쪽을 씁니다.

**수업 전에 미리 발급받아 오시면 그날 시간을 벌 수 있습니다.**

> **이 네 가지는 8단계 경매용입니다.** 주식 실습에 필요한 **KIS · DART** 키는 종류가 달라
> **7단계**에서 따로 안내합니다. 테마 레이더 실습은 둘 다 필요 없습니다.

## 커넥터와 config — 붙이는 길이 두 가지입니다

같은 MCP라도 붙이는 길이 둘이고, 준비물이 다릅니다. 이 차이를 알아두시면 다음 단계가 수월합니다.

| 길 | 어떻게 | 준비물 | 이 문서에서는 |
|---|---|---|---|
| **커넥터** | 설정 → 커넥터 에서 목록에서 고르고 연결 | 대개 없음. 로그인만 | 7단계 (PlayMCP) |
| **설정 파일 직접 편집** | 개발자 → [구성 편집] 로 열어 붙여넣고 재시작 | Node.js · uv · 인증키 | 5단계 · 8단계 |

커넥터가 쉽고, 설정 파일 쪽이 훨씬 많은 것을 할 수 있습니다.
**7단계 실습은 커넥터 길로 갑니다. 8단계 경매 분석은 설정 파일 길로 갑니다.**

# 6단계. 프로젝트 · 아티팩트 · 예정됨

여기는 깔거나 붙이는 단계가 아니라 **Claude 화면에 이미 있는 세 가지를 아는 단계**입니다.
7단계 실습에서 셋 다 쓰게 되니, 그 전에 한 번 읽어두시면 훨씬 수월합니다.

## 프로젝트 — 그 일만 쓰는 전용 책상

책상 위에 자료가 늘 펼쳐져 있어서, 앉으면 바로 이어서 일합니다.
다른 일을 할 때는 다른 책상에 앉으면 됩니다.

| 담기는 것 | 무엇 |
|---|---|
| 프로젝트 지침 | 이 프로젝트에서 지킬 규칙 (금액은 원 단위 콤마로 · 결론을 먼저 · 리스크를 빠뜨리지 말 것) |
| 프로젝트 지식 | 매번 올리지 않아도 되는 자료 (계약서 양식 · 우리 기준표 · 체크리스트) |
| 대화 이력 | 그 프로젝트 안에 쌓입니다. "지난주에 본 그 물건"을 다시 찾기 쉬워집니다 |

**만드는 곳** — 좌측 사이드바의 `프로젝트` → `새 프로젝트`. 경매용·주식용처럼 일 단위로 나눠 만듭니다.

### 스킬이 있는데 왜 프로젝트까지 만드나

스킬로는 안 되는 네 가지가 있습니다.

| | 프로젝트가 하는 일 |
|---|---|
| 1 | **내 자료를 담을 수 있다** — 스킬은 절차를 담지만 내 자료는 못 담습니다 |
| 2 | **대화가 한곳에 쌓인다** — 스킬은 대화를 보관하지 않습니다 |
| 3 | **조건 없이 늘 켜져 있다** — 스킬은 발동 조건에 맞아야 켜집니다 |
| 4 | **일과 일이 섞이지 않는다** — 개인설정에 다 넣으면 주식 얘기에 경매 규칙이 섞입니다 |

넷을 이렇게 구분하세요.

| 무엇 | 무엇을 정하나 | 언제 적용되나 |
|---|---|---|
| 개인 설정 | 나는 누구인가 | 어디서나 항상 |
| 프로젝트 | 이 일의 배경과 자료 | 그 프로젝트 안에서 항상 |
| 스킬 | 이 일을 어떻게 하는가 | 그 일이 생길 때만 |
| MCP | 무엇을 만질 수 있는가 | 손과 발이 된다 |

넷은 경쟁 관계가 아닙니다. **프로젝트 안에서 스킬이 돌고, 스킬이 MCP를 씁니다.**

## 아티팩트 — 대화는 흘러가고 아티팩트는 남습니다

답이 대화 속에 묻히지 않고 **옆에 전용 창**으로 뜹니다.
문서 · 표 · 코드 · 웹페이지 · 그림 · 계산기가 대상이고,
**15줄이 넘고, 따로 떼어 써도 말이 되고, 나중에 다시 볼 만한 것**이면 자동으로 만들어집니다.

| 할 수 있는 것 | 어떻게 |
|---|---|
| 버전을 넘나든다 | 이전 버전으로 되돌릴 수 있습니다 |
| 그 자리에서 고친다 | 고칠 부분을 드래그해 `Edit with Claude` |
| 그대로 꺼낸다 | 코드 보기 · 복사 · 내려받기 |

**자주 놓치는 것** — 대화에서 만든 아티팩트는 목록에 자동으로 올라가지 않습니다.
열어서 **`Publish`** 를 눌러야 남습니다. 오류가 나면 `Try fixing with Claude` 를 누르면 됩니다.

### 아티팩트는 두 종류입니다

| | 채팅 아티팩트 | Cowork 라이브 아티팩트 |
|---|---|---|
| 성격 | 만든 그때 그대로 고정 | **열 때마다 새로 채워집니다** |
| 어디에 남나 | 대화 안 | 사이드바 목록에 계속 |
| 버전 | — | 고칠 때마다 이전 버전 저장 |
| 요금제 | **무료도 됩니다** | **Pro 이상 · 데스크탑 전용** |

라이브 아티팩트는 아침 브리핑 · 현황 추적판 · 관심 대상 감시 같은 데 씁니다.
**내 컴퓨터에만 저장되어 기기를 바꾸면 따라오지 않습니다.**

> 먼저 켜야 합니다 — `설정` → `기능` → 「코드 실행 및 파일 생성」.
> 꺼져 있으면 아티팩트가 아예 나오지 않습니다.
> > 출처: support.claude.com/en/articles/9487310 · articles/14729249

## 예정됨 — 한 번 설명하면 알아서 반복합니다

매번 같은 부탁을 다시 하지 않습니다. 결과물만 받아보면 됩니다.
매일 브리핑 · 주간 보고 · 반복 조사 · 파일 정리 · 진행 상황 정리에 씁니다.

주기는 **매시간 · 매일 · 매주 · 평일만 · 수동으로만** 중에 고릅니다.
평소 쓰는 커넥터 · 스킬 · 플러그인을 그대로 씁니다.

**만드는 곳** — 좌측 사이드바의 `예정됨` → `새 작업`.
「Claude 와 함께 만들기」를 고르면 무엇을 언제 하고 싶은지 말만 해도 Claude가 되물어 채워줍니다.
만든 뒤에는 **지금 바로 실행 · 잠시 멈춤 · 다시 시작 · 수정 · 삭제**를 같은 화면에서 합니다.

> **함정 — 내 컴퓨터의 폴더나 프로그램이 필요한 작업은 컴퓨터가 켜져 있어야 실행됩니다.**
> 원격에서 도는 작업만 컴퓨터를 꺼둬도 돌아갑니다.
> **유료 플랜(Pro 이상)에서 쓸 수 있습니다.**

# 7단계. 첫 실습 — 내 화면 만들기

한 문장씩 넣어 **내 노트북에 결과물 하나를 직접 만들어 보는** 실습입니다.
코드는 한 줄도 쓰지 않습니다.

## ① 주식 — 실습 셋

**셋이 준비물이 다릅니다.** 5단계에서 배운 두 길이 여기서 갈립니다.

| 실습 | 준비물 | 어느 길 |
|---|---|---|
| **테마 레이더** | **PlayMCP 커넥터만.** 키가 없습니다 | 커넥터 길 |
| 코스피200 등락 상위 | + **KIS 앱키** → 설정 파일에 넣습니다 | 설정 파일 길 |
| 텐베거 발굴 | + **KIS · DART 키 2종** → 설정 파일에 넣습니다 | 설정 파일 길 |

**수업에서 다 같이 하는 것은 테마 레이더 하나입니다.** 나머지 둘은 **키 승인에 1~2일** 걸려서
집에서 하십니다. 그래서 아래 PlayMCP 절차는 **셋 다 필요하고**, 키 이야기는 각 실습 폴더에 있습니다.

| 파일 | 내용 |
|---|---|
| [주식실습/한국테마레이더/](주식실습/한국테마레이더/) | **테마 레이더.** 프롬프트 20개 · 30~40분. PlayMCP 만 있으면 됩니다 |

### PlayMCP 붙이는 법 — 순서를 거꾸로 하면 막힙니다

**붙일 커넥터는 하나뿐입니다.** 시세도 순위도 차트도 뉴스도 전부 그 하나에서 나옵니다.
다만 **커넥터는 하나인데 그 안에 담는 도구는 두 개**입니다. 이 구분을 놓치면 헷갈립니다.

| 순서 | 어디서 | 할 일 |
|---|---|---|
| **①** | **웹** | `playmcp.kakao.com` 에 카카오 계정으로 로그인 → 도구함에 **「한국 주식 정보」·「네이버 검색 mcp」** 두 개를 담습니다 |
| **②** | **앱** | `설정` → `커넥터` → **`커넥터 둘러보기`** → **PlayMCP** 선택 → **`연결`** → 카카오 로그인 |

**PlayMCP 는 커넥터 목록에 이미 등록돼 있습니다.** 주소를 복사해 붙일 일도, 설정 파일을 열 일도 없습니다.

> ### ★ ①과 ②를 거꾸로 하면 반드시 막힙니다
>
> 도구함이 빈 채로 연결부터 하면 **연결은 되는데 쓸 도구가 하나도 없습니다.**

**②에서 쓰는 카카오 계정은 ①에서 가입할 때 쓴 계정과 같아야 합니다.**
두 도구 모두 **API 키를 넣는 칸이 없습니다.** 담기만 하면 바로 씁니다.

## 설치 — 세 가지만 하면 됩니다

### ① 물건을 담을 폴더 만들기

**`C:\AI\경매\`** 에 만듭니다.
그 아래 물건마다 폴더를 하나씩 만들고, **소재지로 이름을 짓습니다.**

```
C:\AI\경매\평택 고덕동 1990-13\
C:\AI\경매\화성 남양읍 2274-13\
```

사건번호로 짓지 않습니다 — 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

> **왜 `C:\AI` 아래인가** — 수강생 전원이 같은 경로를 써야 설정 파일을 그대로 복사해 쓸 수 있습니다.
> 다른 곳에 두면 경로를 일일이 고쳐야 합니다.

## 어떤 MCP가 무슨 일을 하나

5단계에서 붙인 것들이 여기서 이렇게 쓰입니다.
**하나도 안 붙여도 서류만으로 분석은 됩니다.** 다만 시세·법령을 직접 못 가져와서
`[확인 필요]` 가 많아집니다.

| MCP | 안 붙이면 | 준비물 |
|---|---|---|
| ★ **korean-law** | 세율·법령을 기억에 의존합니다. 세법은 자주 바뀌어서 위험합니다 | OC만 (폴더 불필요) |
| ★ **real-estate** | **시세 대조를 못 합니다.** 감정가가 적정한지 판단할 근거가 사라집니다 | 키 + `C:\AI\mcp` |
| datagokr | 건축물대장·상권 정보·온비드 공매를 못 가져옵니다 | 키 + `C:\AI\mcp` |
| vworld-landuse | 개별공시지가·용도지역을 확인 못 합니다 | 키 + `C:\AI\mcp` |

위 둘(**korean-law · real-estate**)부터 붙이시면 체감이 가장 큽니다.
`korean-law` 는 폴더가 필요 없어 가장 쉽습니다.
