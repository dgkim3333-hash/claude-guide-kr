# Claude 활용 가이드 (한국어)

Claude 데스크탑을 처음 쓰시는 분들을 위한 실습 자료입니다.
투자·경매에 관심 있는 비개발자를 기준으로 만들었습니다.

## 개인설정 템플릿

Claude가 매번 나에 대해 알고 답하도록 만드는 설정입니다.
아래 세 가지 중 **본인에게 맞는 것 하나만** 골라 쓰세요.

| 파일 | 이런 분께 |
|---|---|
| [개인설정_A_주식용.md](개인설정_A_주식용.md) | 주식 투자에 관심 있는 분 |
| [개인설정_B_경매공매용.md](개인설정_B_경매공매용.md) | 부동산 경매·공매에 관심 있는 분 |
| [개인설정_C_주식과경매공매용.md](개인설정_C_주식과경매공매용.md) | 둘 다 관심 있는 분 |

## 쓰는 법

1. 위 표에서 파일 하나를 클릭합니다.
2. 회색 상자 안의 내용을 전부 복사합니다.
3. Claude 데스크탑 → 좌측 하단 내 이름 → `설정` → `개인 설정`에 붙여넣습니다.
4. 맨 첫 줄을 본인에 맞게 고칩니다.
5. 새 대화를 열고 "내가 어떤 일을 하는 사람인지 알고 있어?"라고 물어 확인합니다.

## 주의

- 주민번호, 계좌번호, 비밀번호, 거래처·채무자 실명은 개인설정에도 대화에도 넣지 마세요.
- 이 자료의 내용은 참고용이며, 투자와 입찰의 결과는 본인 책임입니다.
