# Claude 활용 가이드 (한국어)

Claude 데스크탑을 처음 쓰시는 분들을 위한 실습 자료입니다.
투자·경매에 관심 있는 비개발자를 기준으로 만들었습니다.

## 교재부터 받으세요

| 파일 | 내용 |
|---|---|
| ★ [클로드교육_01회차_v3.pdf](클로드교육_01회차_v3.pdf) | **교재 전체.** 설치부터 실전까지 |

**받는 법** — 파일 이름을 누른 뒤, 화면 오른쪽 위의 **다운로드 버튼(아래쪽 화살표)** 을 누르세요.
파일 이름에 마우스 오른쪽 버튼을 눌러 저장하면 **엉뚱한 파일이 받아집니다.**
`.skill` · `.plugin` · `.json` 파일도 모두 같습니다.

이 문서는 교재를 옆에 두고 보는 **설치 안내서**입니다. 순서대로 따라오시면 됩니다.

## 읽는 순서

위에서 아래로 이어집니다. **일곱 단계 전부 한 번씩은 읽고 넘어가세요.**
지금 당장 못 하는 단계가 있어도, 그것이 무엇인지 알고 지나가는 것과 모르고 건너뛰는 것은 다릅니다.

| 단계 | 무엇을 | 비고 |
|---|---|---|
| **1단계** | 설치 — Node.js · uv | 5단계를 하려면 반드시 필요합니다 |
| **2단계** | 개인설정 — 나를 알려주기 | ★ 붙여넣기 한 번. 가장 먼저 체감됩니다 |
| **3단계** | Cowork 지침 — 파일 사고 막기 | 파일을 만들게 하실 분만 |
| **4단계** | 스킬 넣기 | 끌어다 놓고 저장 |
| **5단계** | MCP 붙이기 + 인증키 | ★ **키는 나중에 넣어도 됩니다. 구조는 지금 알고 가세요** |
| **6단계** | 첫 실습 — 테마 레이더 | 화면 하나를 직접 만들어 봅니다 |
| **7단계** | 실전 — 경매 물건 분석 | 5단계에서 붙인 MCP를 본격적으로 씁니다 |

**먼저 손에 잡히는 것은 2 · 3 · 4단계입니다.** 복사해서 붙여넣기만 하면 끝나고, 그 자리에서 Claude가 눈에 띄게 달라집니다.
**손이 가는 것은 1단계와 5단계입니다.** 프로그램을 깔고 설정 파일을 고쳐야 해서 그렇습니다. 그래서 미리 읽어두셔야 합니다.

# 1단계. 설치 — Node.js 와 uv

MCP를 붙이려면 Node.js와 uv가 먼저 깔려 있어야 합니다. **이 둘이 없으면 MCP가 하나도 나타나지 않습니다.**

| 문서 | 내용 |
|---|---|
| [사전준비_설치.md](사전준비_설치.md) | Node.js·uv 설치와 안 될 때 대처법 |

설치 자체는 5단계 직전에 하셔도 늦지 않습니다.
다만 **여기서 막히는 분이 가장 많습니다.** 수업 전에 미리 깔아두시면 그날 시간을 벌 수 있습니다.

# 잠깐 — 지침을 넣는 자리가 여러 곳입니다

다음 단계로 가기 전에 이것만 알고 가시면 훨씬 덜 헷갈립니다.
Claude는 지침을 넣는 자리가 여러 곳이고, **자리마다 적용 범위가 다릅니다.**

| 자리 | 넣는 곳 | 어디에 적용되나 | 이 문서에서는 |
|---|---|---|---|
| 개인 설정 | 설정 → **일반** → 「Claude 지침」 | 채팅·Cowork **전부** | 2단계 |
| Cowork 전역 지침 | 설정 → **Cowork** → 「전역 지침」 | **Cowork만** | 3단계 |
| 폴더 지침 | 폴더를 연결한 뒤 폴더 설정 | 그 폴더에서 일할 때만 | — |
| 프로젝트 지침 | 프로젝트 → 지침 편집 | 그 프로젝트에서만 | 7단계 |
| CLAUDE.md 파일 | 홈 폴더의 `.claude` 폴더 | **Claude Code만** | 부록 |

위 네 자리는 넓은 것부터 좁은 것 순서이고, 서로 덮어쓰지 않고 겹쳐서 함께 적용됩니다.

**Claude Code는 위 네 자리를 하나도 읽지 않고, `CLAUDE.md` 만 읽습니다.**
반대로 Cowork과 채팅은 `CLAUDE.md` 를 읽지 않습니다.

# 여는 법과 저장하는 법

넣는 방식이 두 갈래입니다. **이것만 구분하면 헷갈리지 않습니다.**

| 갈래 | 무엇 | 어떻게 |
|---|---|---|
| **화면에 붙여넣기** | 개인설정 · Cowork 전역지침 | 설정 화면의 입력칸에 **내용을 복사해** 붙여넣습니다 |
| **파일 그대로 놓기** | `claude_desktop_config.json` · `CLAUDE.md` | 받은 **파일을 제자리에 놓습니다.** 내용을 복사할 필요가 없습니다 |

## ① 개인설정 — 설정 → 일반 → 「Claude 지침」

| 순서 | 할 일 |
|---|---|
| 1 | Claude 데스크탑에서 **설정**을 엽니다 |
| 2 | 왼쪽 목록 맨 위 **`일반`** |
| 3 | 「프로필」 아래 **「Claude 지침」** 이라는 큰 입력칸에 붙여넣습니다 |
| 4 | **창을 닫으면 자동 저장됩니다.** 저장 버튼은 없습니다 |
| 5 | **새 대화**를 열고 "내가 어떤 일을 하는 사람인지 알고 있어?" 라고 물어 확인합니다 |

> **「개인 설정」이라는 메뉴는 없습니다.** `일반` 탭 안의 「Claude 지침」이 그것입니다.
> 화면 설명에 *"채팅 및 Cowork 전반에 걸쳐 이 내용을 기억합니다"* 라고 적혀 있으면 제자리입니다.

## ② Cowork 전역 지침 — 설정 → Cowork → 「전역 지침」

| 순서 | 할 일 |
|---|---|
| 1 | 설정 → 왼쪽 목록 **`Cowork`** |
| 2 | **화면을 아래로 끝까지 내립니다** |
| 3 | 맨 아래 「전역 지침」 오른쪽의 **[편집]** 버튼 |
| 4 | 붙여넣고 창을 닫으면 자동 저장됩니다 |
| 5 | **새 대화**를 열고 "파일을 만들 때 네가 지켜야 할 규칙을 알려줘" 로 확인합니다 |

> **스크롤을 안 내리면 안 보입니다.** 여기서 많이 막힙니다.
> 같은 화면 맨 위의 「신뢰할 수 있는 Cowork 폴더 [관리]」는 자주 쓰는 폴더를 미리 등록해
> 매번 확인을 묻지 않게 하는 기능입니다.

## ③ 설정 파일 — 설정 → 데스크톱 앱 → 개발자 → [구성 편집]

**숨은 폴더 경로를 손으로 찾아갈 필요가 없습니다.** 버튼이 대신 열어줍니다.

| 순서 | 할 일 |
|---|---|
| 1 | 설정 → 왼쪽 목록 아래쪽 **`데스크톱 앱`** → **`개발자`** |
| 2 | 「로컬 MCP 서버」의 **[구성 편집]** 을 누릅니다 |
| 3 | 파일 탐색기가 열리고 **`claude_desktop_config`** 파일이 보입니다 |
| 4 | 그 파일을 **더블클릭** — 메모장이나 VS Code로 열립니다 |
| 5 | 내용을 바꾸고 **저장**합니다 (인코딩 UTF-8) |
| 6 | **Claude 데스크탑을 완전히 종료했다 다시 켭니다** → 아래 ⑤ 를 그대로 따라 하세요 |

**처음 쓰시는 분은** 3번에서 열린 폴더에 받은 `중요_claude_desktop_config_기본.json` 을
**`claude_desktop_config.json` 으로 이름을 바꿔 넣으면** 됩니다. 내용을 복사할 필요가 없습니다.

> ★ **고치기 전에 원본을 복사해 두세요.** 콤마 하나만 어긋나도 MCP가 하나도 안 뜹니다.
> ★ `claude_desktop_config_실습용.jsonc` 는 **그대로 넣으면 안 됩니다.** 주석(`//`)이 들어 있어
>   앱이 못 읽을 수 있습니다. 그건 읽고 이해하는 용도이고, 실제로 넣는 것은 주석 없는 `.json` 쪽입니다.

### MCP가 안 붙을 때도 이 화면에서 봅니다

같은 `개발자` 화면 왼쪽에 **붙어 있는 서버 목록**이 나옵니다. 하나를 고르면

- **`running`** 인지 아닌지
- 실행에 쓰는 **명령어**와 **인수**(경로가 맞는지 여기서 확인)
- **[로그 보기]** — 왜 실패했는지 이 로그에 적혀 있습니다

붉은 오류가 났을 때 "왜 안 되지" 하고 헤매지 마시고 **로그부터 여세요.**

## ④ CLAUDE.md — 파일을 직접 만듭니다

**설정 화면에는 이 항목이 없습니다.** `설정 → Claude Code` 탭에도 없습니다. 파일을 직접 만들어야 합니다.

`.claude` 는 숨은 폴더라 손으로 찾아가기 번거롭습니다.
[ClaudeCode_전역지침.md](ClaudeCode_전역지침.md) 안에 **Cowork에게 시켜서 만드는 프롬프트**가 들어 있으니
그대로 복사해 쓰시면 됩니다. **명령어 창에서 Claude Code를 쓰시는 분만 해당됩니다.**

## ⑤ 「Claude 를 완전히 종료한다」가 무슨 뜻인가

**창 오른쪽 위 X 를 눌러도 Claude 는 꺼지지 않습니다.**
화면에서만 사라지고 **뒤에서 계속 돌아갑니다.** 이 상태로 다시 열면
설정을 아무리 고쳐도 반영되지 않습니다. **여기서 가장 많이 막힙니다.**

| 순서 | 할 일 |
|---|---|
| 1 | 창의 **X** 를 눌러 창을 닫습니다 |
| 2 | 화면 **오른쪽 아래, 시계 왼쪽**을 보세요. **`∧`** (위를 향한 작은 화살표) 가 있습니다 |
| 3 | **`∧`** 를 클릭하면 아이콘이 여러 개 든 **작은 상자**가 뜹니다 |
| 4 | 그 안에서 **Claude 아이콘**을 찾습니다 — **검은 별표(✳) 모양**입니다. 마우스를 올리면 이름이 떠서 확인됩니다 |
| 5 | 그 아이콘에 **마우스 오른쪽 버튼** → **종료**(Quit) |
| 6 | **아이콘이 상자에서 사라지면** 완전히 꺼진 것입니다 |
| 7 | 시작 메뉴에서 Claude 를 다시 실행합니다 |

> **상자에 Claude 아이콘이 아예 없으면** 이미 꺼져 있는 것입니다. 그냥 다시 실행하세요.
> **`∧` 가 안 보이면** 아이콘이 이미 펼쳐져 있는 것입니다. 작업 표시줄 오른쪽을 그대로 살펴보세요.
> 사람마다 상자 안 아이콘 개수와 배치가 다릅니다. 개수로 찾지 마시고 **모양으로** 찾으세요.

**컴퓨터를 다시 시작하는 것과는 다른 이야기입니다.** Claude 만 껐다 켜면 됩니다.

# 3단계. Cowork 전역 지침 — 파일 사고 막기

Cowork은 Claude가 **내 컴퓨터의 파일을 직접 만들고 고치는 곳**입니다.
파일을 엉뚱한 데 저장하거나, 내가 손본 걸 덮어써 버리는 일이 자주 생깁니다.
그걸 막는 규칙입니다.

| 파일 | 이런 분께 |
|---|---|
| [Cowork_전역지침.md](Cowork_전역지침.md) | Cowork으로 문서·엑셀·PPT를 만드시는 분 |

개인설정과 달리 **분야를 나누지 않습니다.** 누구에게나 같은 내용이고, 고칠 곳도 없습니다.

| 순서 | 할 일 |
|---|---|
| 1 | 위 파일을 열어 회색 상자 안의 내용을 전부 복사합니다 |
| 2 | **설정 → Cowork → 아래로 스크롤 → 「전역 지침」 [편집]** (여는 법은 위 ② 참고) |
| 3 | 붙여넣고 닫으면 자동 저장 → **새 대화**를 열고 "파일을 만들 때 네가 지켜야 할 규칙을 알려줘" |

# 5단계. MCP 붙이기

여기부터가 이 자료의 핵심입니다.
지금까지는 Claude에게 **말하는 법**을 가르쳤다면, 여기서는 Claude에게 **눈과 손**을 달아줍니다.
시세·법령·공시자료를 기억에 의존하지 않고 **원본에서 직접 읽어 오게** 만드는 단계입니다.

> ### 오늘 다 못 붙여도 괜찮습니다. 다만 건너뛰지는 마세요.
>
> 키를 받고, 폴더를 만들고, 설정 파일을 고치는 일입니다.
> 앞 단계들처럼 붙여넣기 한 번으로 끝나지 않아 시간이 걸립니다.
> 그래도 이 단계는 **읽고 넘어가셔야 합니다.**
>
> - MCP가 무엇인지 알아야 **6단계 실습에서 커넥터를 왜 켜는지** 이해됩니다
> - MCP가 무엇인지 알아야 **7단계에서 시세가 안 나올 때 원인을 짚을 수 있습니다**
> - 붉은 오류가 떴을 때 **고장인지 준비가 덜 된 것인지** 구분할 수 있습니다
>
> **키는 나중에 넣으셔도 됩니다. 구조를 아는 것은 지금 하셔야 합니다.**

## 기본 config 안에는 세 종류가 섞여 있습니다

| 구분 | 서버 | 준비물 |
|---|---|---|
| **바로 되는 것 (7개)** | youtube · youtube-transcript · context7 · sequential-thinking · playwright · hwp-read · word | **없음.** 붙여넣고 재시작하면 끝 |

**키가 없는 상태로 붙여넣으면 그 5개는 붉은 오류가 납니다.** 고장이 아닙니다.
나머지 7개는 정상 작동합니다. 아직 준비가 안 됐으면 **그 블록들은 지우고 쓰셔도 됩니다.**

|---|---|---|
| 공공데이터포털 인증키 | https://www.data.go.kr | **3곳 — 전부 같은 값** |

**수업 전에 미리 발급받아 오시면 그날 시간을 벌 수 있습니다.**

## 커넥터와 config — 붙이는 길이 두 가지입니다

같은 MCP라도 붙이는 길이 둘이고, 준비물이 다릅니다. 이 차이를 알아두시면 다음 단계가 수월합니다.

| 길 | 어떻게 | 준비물 | 이 문서에서는 |
|---|---|---|---|
| **커넥터** | 설정 → 커넥터 에서 목록에서 고르고 연결 | 대개 없음. 로그인만 | 6단계 (PlayMCP) |
| **설정 파일 직접 편집** | 개발자 → [구성 편집] 로 열어 붙여넣고 재시작 | Node.js · uv · 인증키 | 5단계 · 7단계 |

커넥터가 쉽고, 설정 파일 쪽이 훨씬 많은 것을 할 수 있습니다.
**6단계 실습은 커넥터 길로 갑니다. 7단계 경매 분석은 설정 파일 길로 갑니다.**

거꾸로 앱부터 연결하면 **연결은 되는데 쓸 도구가 하나도 없습니다.**

마지막 줄에서도 많이 막힙니다. 커넥터를 방금 켰다면 **열려 있던 대화에서는 잡히지 않습니다.**

같은 문장을 넣어도 사람마다 다른 화면이 나옵니다. 고장이 아닙니다.
똑같은 화면이 필요할 때만 완성본 파일을 쓰세요.

# 7단계. 실전 — 경매 물건 분석

여기까지 오셨으면 이제 실제 업무에 씁니다.
5단계에서 붙인 MCP가 **여기서 본격적으로 일합니다.**
경매 서류를 넣으면 물건카드가 나오는 **프로젝트 한 벌**을 통째로 받으시는 단계입니다.

## 무엇을 해주나

경매 서류 PDF를 폴더에 넣고 **"이 물건 분석해줘"** 한 마디만 하면, 아래를 순서대로 검토해서
**PPTX 물건카드 22~24장**을 만들어 줍니다.

| 넣는 것 | 나오는 것 |
|---|---|
| 매각물건명세서 | 인수되는 권리가 있나 · 임차인이 몇 명이고 각각 대항력이 있나 |
| 등기부 (토지·건물) | 말소기준권리가 무엇이고 무엇이 지워지나 |
| 현황조사서 · 전입세대열람 | 실제로 누가 살고 있나 · 전입일이 근저당보다 빠른가 |
| 감정평가서 | 감정가가 적정한가 · 기준시점이 얼마나 지났나 |
| 문건/송달내역 | 채무자가 저항하고 있나 · **기일을 누가 세웠나** |
| 경매정보 출력물 | 유찰 회차 · 최저매각가격 |

여기에 더해 **권장 입찰가**, **취득세·재산세·종부세**(개인·법인 두 경우), **명도 난이도**,
그리고 마지막 장에 **「확인해야 할 것」** 이 나옵니다. 마지막 장이 사실상 결론입니다 —
답을 준 게 아니라 무엇을 더 봐야 하는지를 알려줍니다.

내 컴퓨터 아무 곳에나 만듭니다. 예를 들면 `C:\경매\` 처럼요.

```
C:\경매\평택 고덕동 1990-13\
C:\경매\화성 남양읍 2274-13\
```

사건번호로 짓지 않습니다 — 재경매로 사건번호가 바뀌어도 물건은 그대로이기 때문입니다.

## 어떤 MCP가 무슨 일을 하나

5단계에서 붙인 것들이 여기서 이렇게 쓰입니다.
**하나도 안 붙여도 서류만으로 분석은 됩니다.** 다만 시세·법령을 직접 못 가져와서
`[확인 필요]` 가 많아집니다.

| MCP | 안 붙이면 | 준비물 |
|---|---|---|
| ★ **korean-law** | 세율·법령을 기억에 의존합니다. 세법은 자주 바뀌어서 위험합니다 | OC만 (폴더 불필요) |
| ★ **real-estate** | **시세 대조를 못 합니다.** 감정가가 적정한지 판단할 근거가 사라집니다 | 키 + `C:\mcp` |
| datagokr | 건축물대장·상권 정보·온비드 공매를 못 가져옵니다 | 키 + `C:\mcp` |
| vworld-landuse | 개별공시지가·용도지역을 확인 못 합니다 | 키 + `C:\mcp` |

위 둘(**korean-law · real-estate**)부터 붙이시면 체감이 가장 큽니다.
`korean-law` 는 폴더가 필요 없어 가장 쉽습니다.

자세한 설명과 발급처는 [경매물건분석/필요한MCP.md](경매물건분석/필요한MCP.md) 에 있습니다.

## 첫 사용법

물건 폴더에 서류 PDF를 넣고, 프로젝트 안에서 **새 대화**를 열어 이렇게 말합니다.

```
이 물건 분석해줘
```

**매각물건명세서가 없으면 분석의 절반이 날아갑니다.** 이것만은 꼭 넣으세요.
**토지 등기부도 자주 빠집니다** — 건물 등기부만 넣으면 토지 권리를 못 봅니다.

자주 쓰는 다른 말들입니다.

```
물건카드 만들어줘. 개인·법인 두 경우로 세금 넣어줘
```
```
입찰가 다시 계산해줘. 다음 기일이 34.3%로 확인됐어
```
```
공시가격 000원으로 확인됐어. 보유세 다시 산출해줘
```
```
낙찰됐어. 명도 계획 만들어줘
```

## 미리 알아두실 것

주택 공시가격을 개인이 조회할 수 있는 공개 API가 없기 때문입니다.
정확한 값이 필요하면 [부동산공시가격알리미](https://www.realtyprice.kr) 에서 확인해 알려주세요.
알려주면 즉시 다시 계산합니다.

**종부세는 낙찰 다음 해가 첫 과세연도입니다.**
과세기준일이 매년 6월 1일이라, 6월 이후에 잔금을 내면 그 해 종부세는 없습니다.
그래서 현행 세율이 아니라 **다음 해 세율**로 계산합니다.
2026.08.03 재정경제부 세제개편안 기준이며 **국회 통과 전 정부안**입니다.

**낙찰 계수는 실측 데이터지만 시장에 따라 변합니다.**
산출일이 6개월을 넘으면 참고치로만 쓰고, 인근 낙찰사례로 반드시 교차 검증하세요.

**민간 추정시세는 쓰지 않습니다.**
국토교통부 실거래가만 씁니다. 경매정보 사이트의 AI 추정가도 쓰지 않습니다.

**물건카드를 남에게 보내지 마세요.** 임차인 정보가 들어 있습니다.

> 이 도구는 판단 재료를 모아줄 뿐 대신 결정하지 않습니다.
> 실제 입찰 전에는 등기부·매각물건명세서 원문과 전문가 확인이 반드시 필요합니다.
> 특정 물건의 입찰을 권유하지 않으며, 투자 판단과 그 결과는 본인 책임입니다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| 지침이 안 먹는 것 같다 | **새 대화**를 열었는지 확인하세요. 열려 있던 대화에는 안 붙습니다 |
| 설정 파일을 고쳤는데 그대로다 | Claude 를 **완전히** 종료했는지 확인하세요 (위 ⑤). 창의 X 로는 안 꺼집니다 |
| MCP 5개가 붉게 뜬다 | 키·폴더가 아직 없는 것입니다. 나머지 7개는 정상입니다 |
| 어느 MCP가 왜 실패했는지 모르겠다 | 설정 → 데스크톱 앱 → 개발자 → 그 서버를 고르고 **[로그 보기]** |
| 키를 넣었는데 인증 오류 | Encoding / Decoding 을 바꿔 넣어보세요. 앞뒤 공백도 확인 |
| 특정 조회만 실패한다 | 그 서비스를 **활용신청** 안 한 것입니다 |
| 금액을 엉뚱하게 읽는다 | 경매정보 PDF는 텍스트에 숫자가 없는 경우가 많습니다. "이미지로 읽어줘" 라고 하세요 |
| 시세를 못 가져온다 | `real-estate` 가 안 붙은 것입니다. 채팅창 `+` → `Connectors` 에서 확인하세요 |
| 슬라이드 글자가 겹친다 | `_card.js` 를 고쳐 다시 생성하게 하세요. PPTX를 손으로 고치지 마세요 |
