# 한국테마레이더 — 실습 안내

오늘의 등락 순위, 테마 카드, 테마 지도를 **한 화면에** 직접 만들어 보는 실습입니다.
Claude에게 한 문장씩 시키면서 화면을 키워 나갑니다.

> ⚠️ **이 실습은 도구 사용법을 익히는 것이 목적입니다.**
> 특정 종목의 매수·매도를 권하지 않습니다. 화면에 나오는 종목은 도구가 도는 것을 보여주는 재료일 뿐입니다.
> 투자 판단과 그 결과는 본인 책임입니다.

---

## 이 폴더에 있는 것

| 파일 | 무엇인가 |
|---|---|
| [`한국테마레이더.md`](한국테마레이더.md) | **여기부터 보세요.** 넣을 프롬프트 20개 |
| [`theme-radar-edu-full.html`](theme-radar-edu-full.html) | 완성본. 내려받아 브라우저로 열면 결과 화면을 미리 볼 수 있습니다 |

똑같은 화면이 필요하면 말로 시키지 말고 **완성본 파일을 주고 "이대로 만들어줘"** 하면 됩니다.

---

## 준비물

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 > 계정 |
| 도구함에 도구 2개를 담았는가 | playmcp.kakao.com (웹) |
| PlayMCP 커넥터가 켜져 있는가 | 채팅창 아래 `+` > `Connectors` |

담을 도구는 **한국 주식 정보**(시세·순위·차트)와 **네이버 검색 mcp**(뉴스) 둘입니다.

**순서가 있습니다.** 웹에서 먼저 담고, 그다음 앱에서 커넥터를 연결합니다.
거꾸로 하면 연결은 되는데 쓸 도구가 하나도 없습니다.

걸리는 시간은 **30~40분** 입니다.

---

## 시작하기 전에

**새 대화를 여세요.** 커넥터를 방금 켰다면 열려 있던 대화에서는 잡히지 않습니다.
여기서 가장 많이 막힙니다.

**한 번에 한 문장씩 넣으세요.** 화면이 바뀌는 것을 보고 다음으로 갑니다.
여러 개를 한꺼번에 넣으면 어디서 틀어졌는지 알 수 없습니다.

**사람마다 다른 화면이 나옵니다.** 실패가 아니라 정상입니다.
Claude가 매번 똑같이 만들지 않습니다.

**숫자가 나오면 출처를 물어보세요.** `이 숫자 어디서 온 거야?` 한 마디면 됩니다.
출처를 못 대는 숫자는 쓰지 않습니다.

---

> 시세·순위·차트는 한국투자증권(KIS) 공식 API 실측값이고, 뉴스는 네이버 뉴스 검색 결과입니다.
> 뉴스는 언론사 원문을 눌러 직접 확인하십시오.
