# 한국테마레이더

**한 번에 한 문장씩** 넣으세요. 화면이 바뀌는 것을 보고 다음으로 갑니다.
전부 20개, 30~40분 걸립니다.

> **완성 예시** — 같은 폴더의 [`theme-radar-edu-full.html`](theme-radar-edu-full.html) 을 내려받아
> 브라우저로 열면 다 만들었을 때 어떤 화면이 나오는지 볼 수 있습니다.
> 다만 **사람마다 다른 화면이 나옵니다.** 똑같이 나오지 않아도 실패가 아닙니다.

## 시작 전 확인

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 > 계정 |
| 도구함에 도구 2개를 담았는가 | playmcp.kakao.com (웹) |
| PlayMCP 커넥터가 켜져 있는가 | 채팅창 아래 `+` > `Connectors` |
| **새 대화**를 열었는가 | 왼쪽 사이드바 |

도구함에 담을 두 가지입니다.

| 도구 | 담당 |
|---|---|
| 한국 주식 정보 | 시세 · 순위 · 차트 |
| 네이버 검색 mcp | 뉴스 |

**순서가 있습니다.** 웹에서 먼저 담고, 그다음 앱에서 커넥터를 연결합니다.
거꾸로 하면 연결은 되는데 쓸 도구가 하나도 없습니다.

마지막 줄을 자주 빠뜨립니다. 커넥터를 방금 켰다면 열려 있던 대화에서는 잡히지 않습니다.

```

```

```

```

> 여기까지 숫자가 나오면 재료가 다 확보된 것입니다. 안 나오면 뒤는 전부 안 됩니다.


## 3부 · 테마 붙이기

```
이제 테마를 넣고 싶어. 요즘 거래대금이 많이 몰리는 테마 20개를 네가 골라서 순위표 아래에 카드로 나열해줘.
```

```
카드마다 그 테마 점수랑, 신선도·자금신호·촉매강도·모멘텀 네 가지를 막대로 보여줘.
```

```
카드마다 그 테마의 대표 ETF랑 관련주도 같이 보여주고, 각각 지금 몇 퍼센트인지 옆에 붙여줘.
```

```
카드마다 대표 ETF랑 대표 관련주의 최근 한 달 흐름을 한 그래프에 두 선으로 그려줘. 시작을 0%로 맞춰서.
```

```
그 테마가 지금 왜 움직이는지도 카드에 한 줄로 적어주고 날짜를 붙여줘.
```

```
카드마다 뉴스 버튼을 만들어줘. 누르면 그 테마 이름으로 뉴스를 검색해서 제목을 5개 가져오고, 제목을 누르면 원문이 열리게 해줘.
```

> 테마와 종목은 **Claude가 정한 것**입니다. 정답이 아닙니다.
> 마음에 안 들면 이렇게 바꾸세요 — `테마에서 "조선"을 빼고 "방산"을 넣어줘.`

```

```

```
동그라미 크기를 점수에 맞춰 다르게 하고, 겹치면 알아서 밀어내서 안 겹치게 해줘.
```

## 자주 막히는 곳

| 증상 | 원인 | 대처 |
|---|---|---|
| 커넥터를 못 찾는다 | 새 대화가 아님 | 새 대화를 열고 다시 |
| 시세는 되는데 뉴스만 안 된다 | 도구함에 네이버 검색을 안 담음 | 웹에서 담고 새 대화 |
| 아티팩트가 안 만들어진다 | 무료 요금제 | Pro 이상 필요 |
| 화면은 뜨는데 숫자가 빈다 | 도구 호출 실패 | `왜 데이터가 안 들어오는지 확인해줘` |
| 금액이 `142.2만원` 으로 나온다 | 지시가 무시됨 | `금액을 전부 원 단위 콤마로 다시 해줘` |
| 고쳐달라니 화면이 통째로 바뀐다 | 범위를 안 정해줌 | `다른 부분은 그대로 두고 ○○만 고쳐줘` |
| 어제 값이 나온다 | 장 시작 전·주말 | 고장 아님 |

**Claude가 되물으면 당황하지 마세요.** "어떤 테마를 원하세요?" 같은 질문이 옵니다.
`모르면 네가 정해줘` 라고 답해도 됩니다.

**사람마다 다른 화면이 나옵니다.** 실패가 아니라 정상입니다.
똑같이 만들고 싶으면 말로 시키는 게 아니라 파일을 주고 "이대로 만들어줘" 해야 합니다.
