# 코스피200 등락상위 — 실습 안내

코스피200 200종목 중에서 **오늘·이번 주·이번 달 많이 오르내린 종목**을 한 화면에 모아 보는 실습입니다.
지수 요약, 일간 상승·하락 TOP10, 주간·월간 TOP10을 Claude에게 한 문장씩 시켜 만듭니다.

> ⚠️ **이 실습은 도구 사용법을 익히는 것이 목적입니다.**
> 특정 종목의 매수·매도를 권하지 않습니다. 화면에 나오는 종목은 도구가 도는 것을 보여주는 재료일 뿐입니다.
> 투자 판단과 그 결과는 본인 책임입니다.

똑같은 화면이 필요하면 말로 시키지 말고 **완성본 파일을 주고 "이대로 만들어줘"** 하면 됩니다.

---

## 준비물 — 앞의 실습보다 무겁습니다

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 > 계정 |
| 한국투자증권 KIS 커넥터가 붙었는가 | 채팅창 아래 `+` > `Connectors` |

**한국투자증권 계좌를 만들고 KIS Open API 를 신청해 앱키를 받아야 합니다.**
그 키를 설정 파일에 넣어야 커넥터가 붙습니다.

**키가 없으면 이 실습은 한 줄도 진행되지 않습니다.** 수업 시간에 강사와 같이 붙이세요.
테마레이더 실습은 PlayMCP 만으로 됐지만, 이 실습은 그렇지 않습니다.

걸리는 시간은 **40~50분** 입니다.

---

## 시작하기 전에

**새 대화를 여세요.** 커넥터를 방금 켰다면 열려 있던 대화에서는 잡히지 않습니다.
여기서 가장 많이 막힙니다.

**한 번에 한 문장씩 넣으세요.** 화면이 바뀌는 것을 보고 다음으로 갑니다.
여러 개를 한꺼번에 넣으면 어디서 틀어졌는지 알 수 없습니다.

**사람마다 다른 화면이 나옵니다.** 실패가 아니라 정상입니다.

**숫자가 나오면 출처를 물어보세요.** `이 숫자 어디서 온 거야?` 한 마디면 됩니다.

---

## 이 실습에서 배우는 것

앞의 테마레이더가 **화면을 키워 나가는 연습**이었다면, 이쪽은 **도구를 여러 번 부르는 화면을 다루는 연습**입니다.

**한 화면에 도구를 아홉 번 부릅니다.** 지수 3개 + 일간 2개 + 주간 2개 + 월간 2개.
이렇게 되면 반드시 일부가 실패합니다. 증권사 API에는 초당 호출 한도가 있기 때문입니다.

그래서 실습 후반에 이런 것들을 시킵니다.

- 한꺼번에 부르지 말고 **사이를 두고 순서대로** 부르기
- 한도에 걸리면 **잠깐 쉬었다 다시** 시도하기
- 일부만 실패하면 **그 칸만 비우고 경고**를 띄우기 — 화면 전체를 죽이지 않기
- 받아온 값을 **저장해 뒀다가 다시 열면 먼저 보여주기**

**「되는 화면」과 「망가져도 버티는 화면」의 차이가 여기서 갈립니다.**

또 하나, 업종 배지는 **API 가 주지 않는 값**입니다. 화면 안에 분류표를 직접 넣어 채웁니다.
없는 값을 지어내지 않고 어디서 왔는지 아는 방식으로 채우는 것 — 이게 요령입니다.
