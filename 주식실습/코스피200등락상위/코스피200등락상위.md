# 코스피200 등락상위

**한 번에 한 문장씩** 넣으세요. 화면이 바뀌는 것을 보고 다음으로 갑니다.
전부 21개, 40~50분 걸립니다.

> **완성 예시** — 같은 폴더의 [`kospi200-movers-full.html`](kospi200-movers-full.html) 을 내려받아
> 브라우저로 열면 다 만들었을 때 어떤 화면이 나오는지 볼 수 있습니다.
> 다만 **사람마다 다른 화면이 나옵니다.** 똑같이 나오지 않아도 실패가 아닙니다.

## 시작 전 확인

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 > 계정 |
| **한국투자증권 KIS 커넥터가 붙었는가** | 채팅창 아래 `+` > `Connectors` |
| **새 대화**를 열었는가 | 왼쪽 사이드바 |

**이 실습은 준비물이 무겁습니다.** 앞의 테마레이더보다 한 단계 어렵습니다.

한국투자증권 **계좌를 만들고 KIS Open API 를 신청해 앱키를 받아야** 합니다.
그 키를 설정 파일에 넣어야 커넥터가 붙습니다. 신청 방법은 `경매물건분석/필요한MCP.md` 방식과 같습니다.

**키가 없으면 이 실습은 한 줄도 진행되지 않습니다.** 수업 시간에 강사와 같이 붙이세요.

---

## 1부 · 도구가 도는지 먼저 본다

```
나는 코스피200 등락 상위를 한 화면에 보는 아티팩트를 만들고 싶어.
```

```
내가 지금 쓸 수 있는 커넥터랑 도구에 뭐가 있는지 먼저 알려줘.
```

```
그 도구로 코스피 지수 현재값을 가져와 봐.
```

```
코스피200에서 오늘 많이 오른 종목 10개도 뽑아줘.
```

> 여기까지 숫자가 나오면 재료가 다 확보된 것입니다. 안 나오면 뒤는 전부 안 됩니다.
> 안 나오면 **키가 잘못 들어갔거나 새 대화가 아닌 것**입니다. 둘 중 하나입니다.

---

## 2부 · 화면 뼈대 만들기

```
좋아, 방금 본 걸 아티팩트로 만들어줘. 제목은 "KOSPI 200 등락 상위"로 해줘.
```

```
맨 위에 지수 요약을 세 칸으로 넣어줘. 코스피, 코스피200, 코스닥. 칸마다 지수값이랑 전일대비, 등락률, 그리고 상승·보합·하락 종목수를 같이 보여줘.
```

```
그 아래에 상승 TOP10과 하락 TOP10을 좌우 두 칸으로 나눠줘.
```

```
줄마다 순위, 종목코드, 종목명, 현재가, 등락률을 보여줘.
```

```
금액은 원 단위 콤마로 해줘. 1,558,000원 이런 식으로. 등락률은 소수 둘째자리까지 쓰고 오른 건 앞에 + 를 붙여줘.
```

```
색을 국내 증권사 관행대로 해줘. 오르면 빨강, 내리면 파랑, 보합은 회색.
```

> 색을 반대로 만들면 국내 사용자는 순간 반대로 읽습니다. 미국식과 다릅니다.

## 3부 · 업종 배지 붙이기

```
종목마다 어느 업종인지 배지를 이름 옆에 붙여줘.
```

```
업종은 도구로 못 가져오니까, 종목코드로 업종을 정하는 표를 화면 안에 직접 넣어줘. 표에 없는 종목은 종목명으로 짐작하고, 그것도 안 되면 "기타"로 해줘.
```

> **왜 표를 직접 넣나요** — 시세 도구는 업종을 주지 않습니다.
> 없는 것을 억지로 만들어 내지 않고, **어디서 온 값인지 아는 방식**으로 채우는 것이 요령입니다.

## 4부 · 기간별 카드 하나 더

```
아래에 카드를 하나 더 만들어서 주간 상승 TOP10과 월간 상승 TOP10을 넣어줘. 주간은 5거래일, 월간은 20거래일 기준으로.
```

```
그 아래에 주간 하락 TOP10과 월간 하락 TOP10도 넣어줘. 위와 구분선으로 나눠줘.
```

---

## 5부 · 쓰기 편하게 다듬기

```
맨 위에 새로고침 버튼을 하나 만들어줘. 누르면 다시 불러오게.
```

```
불러온 값을 저장해 뒀다가, 다시 열면 저장된 걸 먼저 보여줘. 언제 받은 값인지도 제목 옆에 적어줘.
```

```
종목코드나 종목명을 누르면 네이버 금융의 그 종목 페이지가 새 탭으로 열리게 해줘.
```

```
도구를 한꺼번에 부르면 초당 한도에 걸리더라. 조금씩 사이를 두고 순서대로 부르고, 한도에 걸리면 잠깐 쉬었다 다시 시도하게 해줘.
```

```
여러 개 중 일부만 실패하면 그 칸만 비우고 맨 위에 경고를 띄워줘. 전부 실패할 때만 멈추고.
```

> 이 두 줄이 이 실습의 핵심입니다. **도구를 여러 번 부르는 화면은 반드시 일부가 실패합니다.**
> 실패를 어떻게 다룰지 미리 시켜 두는 것이 만드는 사람의 몫입니다.

## 자주 막히는 곳

| 증상 | 원인 | 대처 |
|---|---|---|
| 커넥터를 못 찾는다 | 새 대화가 아님 | 새 대화를 열고 다시 |
| 도구는 보이는데 값이 안 온다 | 앱키가 틀렸거나 만료 | 설정 파일의 키를 다시 확인 |
| 몇 칸만 비어 있다 | 초당 호출 한도 | `사이를 더 두고 다시 불러줘` |
| 전부 비어 있다 | 장 시작 전·주말 | 고장 아님. 저장된 값이 나옵니다 |
| 금액이 `155.8만원` 으로 나온다 | 지시가 무시됨 | `금액을 전부 원 단위 콤마로 다시 해줘` |
| 오른 종목이 파랗다 | 미국식으로 만듦 | `국내 관행대로 오르면 빨강으로 바꿔줘` |
| 고쳐달라니 화면이 통째로 바뀐다 | 범위를 안 정해줌 | `다른 부분은 그대로 두고 ○○만 고쳐줘` |
| 업종이 전부 "기타" | 표가 안 들어감 | `업종 표가 화면 안에 들어갔는지 확인해줘` |

**Claude가 되물으면 당황하지 마세요.** `모르면 네가 정해줘` 라고 답해도 됩니다.

**사람마다 다른 화면이 나옵니다.** 실패가 아니라 정상입니다.
똑같이 만들고 싶으면 말로 시키는 게 아니라 완성본 파일을 주고 "이대로 만들어줘" 해야 합니다.
