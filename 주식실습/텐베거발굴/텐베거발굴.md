# 텐베거 발굴

**아티팩트 하나와 예약작업 하나**를 만듭니다. 앞의 두 실습과 다른 점이 여기입니다 —
만들고 끝이 아니라, **매월 1일에 알아서 도는 것**을 걸어 둡니다.

| 만드는 것 | 무엇인가 |
|---|---|
| 아티팩트 `tenbagger-watch` | 워치리스트 관제판. **상태가 저장되는 곳** |
| 예약작업 `tenbagger-monthly-day1-1100` | 매월 1일 11시에 전수 스크리닝을 돌려 관제판을 갱신 |

**두 개가 짝입니다.** 예약작업은 매번 새 대화에서 시작해 이전 기억이 없습니다.
그래서 **아티팩트를 읽어서 「지난번에 뭐가 들어 있었는지」를 알아냅니다.**
아티팩트가 먼저 있어야 예약작업이 돕니다.

> **완성 예시** — 같은 폴더의 [`tenbagger-watch-full.html`](tenbagger-watch-full.html) 을 내려받아
> 브라우저로 열면 채워졌을 때 어떤 화면이 나오는지 볼 수 있습니다.
> 전체 절차와 4축 판정 기준은 [`텐베거_발굴시스템_작업지시서.md`](텐베거_발굴시스템_작업지시서.md) 에 있습니다.

## 시작 전 확인

| 확인할 것 | 어디서 |
|---|---|
| 요금제가 Pro 이상인가 | 설정 > 계정 |
| **API 키 2종을 받았는가** | DART · 한국투자증권 KIS |
| **MCP 3종이 붙었는가** | 채팅창 아래 `+` > `Connectors` |
| **새 대화**를 열었는가 | 왼쪽 사이드바 |

**이 실습은 준비물이 가장 무겁습니다.** 앞의 두 실습을 마친 뒤에 하세요.

한국투자증권은 **계좌가 있어야** 키가 나옵니다. 없으면 비대면 개설부터 1~2일 걸립니다.
DART는 무료이고 즉시 나옵니다. 발급 절차는 작업지시서 3장에 있습니다.

### 네이버 뉴스는 키가 필요 없습니다

뉴스 검색은 **PlayMCP 커넥터**로 씁니다. 개인 키를 따로 받지 않습니다.
playmcp.kakao.com 에서 도구함에 **「네이버 검색 mcp」** 를 담고, Claude 데스크탑에서 PlayMCP 커넥터를 켜면 됩니다.

> 네이버 개발자센터에서 검색 API 키를 새로 받기 어렵다는 제보가 있습니다.
> PlayMCP 로 가면 그 문제를 우회할 수 있고, 준비물도 하나 줄어듭니다.

---

## 1부 · 도구가 도는지 먼저 본다

```
내가 지금 쓸 수 있는 커넥터랑 도구에 뭐가 있는지 알려줘.
```

```
삼성전자(005930) 현재가랑 2025년 3분기 재무제표 조회해봐. 그리고 외국인 30일 수급도.
```

> **셋이 다 나와야 다음으로 갑니다.** 시세는 KIS, 재무제표는 DART, 수급도 KIS입니다.
> 하나라도 안 나오면 그 키가 잘못 들어간 것입니다. 여기서 멈추고 고치세요.

---

## 2부 · ★ 내 MCP 접두어 확인 — 이 단계를 건너뛰면 예약작업이 100% 실패합니다

MCP 도구 이름 앞에는 **설치할 때마다 달라지는 고유 ID**가 붙습니다.

```
mcp__b68f9e48-afcd-44fc-b9e2-15b50d00b660__koreaStock-stock_get_quote
   └────────── 이 부분이 사람마다 다릅니다 ──────────┘
```

작업지시서와 아티팩트에 적힌 ID는 **만든 사람 것**입니다. 그대로 쓰면 도구를 못 찾습니다.

```
지금 연결된 MCP 도구 중에서 koreaStock, opendart, kis, NaverSearch 관련 도구의 정확한 전체 이름(mcp__로 시작하는 풀 네임)을 그대로 알려줘.
```

**알려주는 이름을 메모장에 그대로 옮겨 적으세요.** 아래 다섯 개가 필요합니다.

| 역할 | 원본의 이름 | 내 환경의 이름 |
|---|---|---|
| 시세 조회 | `{S}koreaStock-stock_get_quote` | |
| 주가 이력 | `{S}koreaStock-stock_get_price_history` | |
| 종목 뉴스 | `{S}koreaStock-market_get_news` | |
| KIS 수급 | `mcp__kis__call-kis-api` | |
| 네이버 뉴스 | `{S}NaverSearch-search_news` | |

작업지시서의 `{S}` 는 **자리표시자**입니다. 붙여넣기 전에 메모장에서 **「모두 바꾸기」로 전부 치환**하세요.

> 여기서 가장 많이 막힙니다. 도구는 분명히 붙었는데 예약작업만 계속 실패한다면 십중팔구 이것입니다.

---

## 3부 · 관제판 아티팩트 만들기 (백지 상태로)

**종목이 하나도 없는 빈 관제판**부터 만듭니다. 채우는 것은 예약작업이 합니다.

작업지시서 **6장 「4단계 — 아티팩트(관제판) 만들기」** 의 회색 상자를 통째로 복사해 붙여넣으세요.
길지만 **한 번에 넣는 것이 맞습니다.** 이건 대화가 아니라 설계도라서 쪼개면 앞뒤가 어긋납니다.

붙여넣기 전에 **`{S}` 를 2부에서 확인한 본인 접두어로 바꾸는 것**을 잊지 마세요.

만들어지면 이렇게 확인합니다.

```
지금 만든 아티팩트 열어줘.
```

**이렇게 되면 성공**

- 탭이 **6개** 보인다 — 종목 현황 · 종목별 상세 · 경계종목 · 뉴스 · 변경 이력 · 편입 근거
- 「아직 편입된 종목이 없습니다」 안내가 보인다
- 오류 메시지 없이 뜬다

안 되면 이렇게 고칩니다.

```
탭이 6개가 아니야. 빠진 탭을 채워줘. 나머지는 그대로 두고.
```

```
WATCHLIST_START 마커가 안 보여. 스크립트 안에 마커 블록을 다시 넣어줘.
```

> **마커가 핵심입니다.** `WATCHLIST_START` · `WATCHLIST_END` · `CHANGELOG_START` · `CHANGELOG_END`
> 네 개입니다. 예약작업이 **이 마커를 찾아 그 사이를 통째로 갈아끼웁니다.**
> 마커가 없거나 글자가 다르면 매달 갱신이 조용히 실패합니다.

---

## 4부 · 예약작업 등록하기

작업지시서 **부록 A** 를 통째로 복사해 메모장에 붙여넣고, **`{S}` 를 모두 바꾼 뒤** 다시 전체 복사합니다.

그리고 대화창에 이렇게 넣습니다.

```
매월 1일 오전 11시에 실행되는 예약작업을 만들어줘.
taskId는 tenbagger-monthly-day1-1100,
설명은 "텐베거 발굴 월간 실행 (매월 1일 11:00) — 4축 교차검증 전수 스크리닝 + 워치리스트 편입·제외 산출 + 아티팩트 갱신".

프롬프트는 아래 내용을 그대로 써줘. 요약하거나 줄이지 마.

---여기부터---
(부록 A 붙여넣기)
---여기까지---
```

**「요약하거나 줄이지 마」를 빼지 마세요.** 빼면 Claude가 알아서 압축합니다.
그러면 7단계 워크플로가 4단계쯤으로 줄어들고, 줄어든 부분은 매달 조용히 실행되지 않습니다.

**이렇게 되면 성공** — 왼쪽 사이드바 **`예정됨`** 에 `tenbagger-monthly-day1-1100` 이 보입니다.

---

## 5부 · 첫 실행 — 반드시 「지금 실행」을 먼저 눌러 보세요

**이 단계를 건너뛰면 첫 회차가 통째로 날아갑니다.**

예약작업이 무인으로 돌 때 **도구 승인 창이 뜨면 거기서 멈춥니다.** 답할 사람이 없기 때문입니다.
25분짜리 작업이 승인 창 앞에서 그대로 서 있게 됩니다.

1. 사이드바 **`예정됨`** → `tenbagger-monthly-day1-1100` → **`지금 실행`**
2. 실행 중 뜨는 도구 승인 요청을 **전부 허용**
3. 한 번 허용하면 다음 회차부터 자동으로 적용됩니다

**돌아가는 동안 앱을 끄지 마세요.** 25~40분 걸립니다.

첫 실행에서 나와야 하는 숫자입니다.

| 단계 | 정상 범위 |
|---|---|
| 스크리닝 대상 | 1,500~2,000종목 |
| 실적 변곡 통과 | 200~400종목 |
| 재무 필터 통과 | 100~250종목 |
| 정밀검증 대상 | 40~50종목 |
| **최종 편입** | **0~10종목** |

> **최종 편입이 0종목이어도 정상입니다.** 통과선에 예외를 만들지 않는 것이 이 시스템의 핵심입니다.
> 반대로 10종목이 넘게 나오면 **필터가 제대로 안 걸린 것**입니다. 리포트의 4축 수치를 직접 검산해 보세요.

## 다 만든 뒤에 해볼 것

```
이 리포트에 나오는 수치들이 각각 어느 MCP 호출 결과인지 알려줘.
```

출처를 못 대는 숫자는 쓰지 않습니다. **근거 없는 수치가 섞이는 것이 이 시스템에서 가장 위험한 실패입니다.**

```
아티팩트 열어서 종목이 채워졌는지 확인해줘.
```

갱신에 실패했으면 산출물 폴더에 `tenbagger-watch.html` 이 남아 있습니다.
다음 대화에서 `아티팩트 갱신해줘` 라고 하면 반영됩니다.

## 자주 막히는 곳

| 증상 | 원인 | 대처 |
|---|---|---|
| 도구가 안 보인다 | Store 버전인데 `%APPDATA%\Claude\` 에 설정을 넣음 | 작업지시서 4-2의 Store 경로로 다시 |
| 재시작했는데 안 된다 | 창만 닫음 | **완전 종료.** 트레이 아이콘 우클릭 → 종료 |
| `Server disconnected` | 설정 파일 JSON 문법 오류 | 쉼표·중괄호 확인 |
| 예약작업만 계속 실패 | **`{S}` 를 안 바꿈** | 2부로 돌아가 접두어 확인 |
| 25분 돌다 멈춰 있다 | 도구 승인 창 대기 | 「지금 실행」으로 미리 승인 (5부) |
| DART가 전부 `NO_DATA` | 그 분기 보고서 미공시 | 삼성전자로 같은 조회를 해 보면 판별됩니다 |
| KIS 수급만 안 된다 | 모의투자 계정 | **실전투자 계정 키**로 교체 |
| `rate limit` 이 쏟아진다 | DART 일일 한도(20,000건) 초과 | 다음 날 재시도. 하루 두 번 돌리지 마세요 |
| 금액이 `12.3억원` 으로 나온다 | 표기 규칙이 무시됨 | `원 단위 풀 콤마로 다시 써줘` |
| 아티팩트를 수정할 수 없다고 한다 | **정상입니다** | 원본은 읽기 전용. 새 파일을 만들어 갱신하는 것이 정해진 절차 |

**아티팩트 경로에 한글이 깨져 보여도 고치지 마세요.** `臾몄꽌` 같은 글자가 나와도
**그대로 써야 읽힙니다.** 예쁘게 고치면 엉뚱한 폴더를 가리켜 조용히 실패합니다.

---

> 재무는 DART 원본, 시세·수급은 한국투자증권(KIS), 뉴스는 네이버 검색 결과입니다.
> **조사 결과이며 매수 추천이 아닙니다.** 애널리스트 커버리지가 희박한 소형주로 유동성이 낮고 변동성이 큽니다.
> 이 실습은 예약작업과 아티팩트를 만드는 법을 익히는 것이 목적입니다.
> 투자 판단과 그 결과는 본인 책임입니다.
