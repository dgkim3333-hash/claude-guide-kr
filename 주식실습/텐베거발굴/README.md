# 텐베거 발굴 — 실습 안내

한국 상장주식 중 **아직 아무도 보고 있지 않은데 실적이 꺾여 올라가는 종목**을 찾아
**매월 1일 자동으로 워치리스트를 갱신하는 시스템**을 만듭니다.

이 실습에서 만드는 것은 **두 개, 그리고 그 둘은 짝입니다.**

| 만드는 것 | 무엇인가 |
|---|---|
| 아티팩트 `tenbagger-watch` | 워치리스트 관제판. **상태가 저장되는 곳** |
| 예약작업 `tenbagger-monthly-day1-1100` | 매월 1일 11시에 전수 스크리닝을 돌려 관제판을 갱신 |

예약작업은 매번 새 대화에서 시작해 **이전 기억이 없습니다.**
그래서 아티팩트를 읽어 「지난번에 뭐가 들어 있었는지」를 알아냅니다.
**아티팩트가 먼저 있어야 예약작업이 돕니다.** 순서를 바꾸면 안 됩니다.

> ⚠️ **조사 결과이며 매수 추천이 아닙니다.**
> 애널리스트 커버리지가 희박한 소형주로 유동성이 낮고 변동성이 큽니다.
> 이 실습은 **예약작업과 아티팩트를 만드는 법**을 익히는 것이 목적입니다.
> 투자 판단과 그 결과는 본인 책임입니다.

## 이 실습에서 배우는 것

앞의 두 실습이 **화면 만들기**였다면, 이건 **자동으로 도는 것을 거는 연습**입니다.

**① 예약작업은 기억이 없습니다.** 그래서 상태를 어딘가에 적어 둬야 합니다.
여기서는 아티팩트가 그 역할을 합니다. 아티팩트 안에 `WATCHLIST_START` 같은 **마커**를 심어 두고,
매달 그 사이를 통째로 갈아끼웁니다. **마커 이름(`WATCHLIST_START` 등)이 틀리면 갱신할 자리를 못 찾습니다.** 양옆 등호 개수나 뒤에 붙은 설명 문구는 달라도 됩니다 — 이름으로 찾기 때문입니다.

**② MCP 도구 이름에는 사람마다 다른 ID가 붙습니다.**
남의 프롬프트를 그대로 가져다 쓰면 도구를 못 찾습니다.
실습 2부에서 자기 ID를 확인하고 `{S}` 를 전부 바꾸는 이유입니다.
**예약작업이 실패하는 이유 1번이 이것입니다.**

**③ 무인으로 도는 작업은 물어볼 수 없습니다.**
도구 승인 창이 뜨면 답할 사람이 없어 거기서 멈춥니다.
그래서 **「지금 실행」으로 먼저 한 번 돌려 승인을 받아 둡니다.**

**④ 통과선에 예외를 만들지 않습니다.**
최종 편입이 0종목이어도 정상입니다. 반대로 10종목이 넘게 나오면 필터가 안 걸린 것입니다.
**기준을 무르게 하면 기준 전체가 무의미해집니다.**

## 미리 알아두실 것 두 가지

완성본 아티팩트를 뜯어보니 **작업지시서와 표기가 다른 데가 있습니다.** 실습 전에 알아두세요.

**마커 표기가 자동화 규칙과 다릅니다 — 네 개 전부입니다.** 작업지시서 6장·부록 A는 `/* ==== WATCHLIST_START ==== */` 처럼 쓰라고 하는데,
완성본(`tenbagger-watch-full.html`)은 `WATCHLIST_START` / `WATCHLIST_END` / `CHANGELOG_START` / `CHANGELOG_END` **네 개 마커 모두** 등호 개수가 다르고 이름 뒤에 설명 문구가 붙어 있습니다.
(예: `/* ============ WATCHLIST_START — 주간 프로젝트가 이 블록을 교체합니다 ============ */`) 앞서 이 문서는 `WATCHLIST_START` 하나만 예로 들었지만, 실제로는 네 개 모두 그렇습니다.

마커를 찾는 고정 규칙(정규식·스크립트)은 따로 없습니다. 매달 Claude가 문서를 읽고 해당 블록을 갈아끼우는 방식입니다.
그래서 작업지시서 6장과 부록 A에 **「마커는 이름으로 찾고, 양옆 등호 개수나 설명 문구 같은 장식은 무시한다」는 규칙을 명시**했습니다 (2026-08-18).
표기 자체를 통일하지 않은 이유는 — 문서 예시나 완성본 HTML 어느 한쪽을 고치면, 사용자가 이미 실제로 운영 중인 아티팩트의 마커와 어긋날 수 있기 때문입니다.
다만 이 규칙을 명시했다고 매달 갱신이 항상 성공한다고 단정할 수는 없습니다. 실제 갱신 결과는 실행해서 확인하세요.

**메타 설명의 탭 개수가 옛날 것입니다.** 화면 탭은 6개인데 설명에는 5개(경계종목 누락)로 적혀 있습니다.
화면 동작에는 영향이 없습니다.
