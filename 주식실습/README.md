# 주식 실습

Claude로 주식 자료를 다뤄 보는 실습 모음입니다.
**실습 하나에 폴더 하나**입니다. 폴더를 열면 그 실습에 필요한 것이 다 들어 있습니다.

> ⚠️ **이 실습들은 도구 사용법을 익히는 것이 목적입니다.**
> 특정 종목의 매수·매도를 권하지 않습니다. 화면에 나오는 종목은 도구가 도는 것을 보여주는 재료일 뿐입니다.
> 투자 판단과 그 결과는 본인 책임입니다.

## 실습하기 전에

**새 대화를 여세요.** 커넥터를 방금 켰다면 열려 있던 대화에서는 잡히지 않습니다.
여기서 가장 많이 막힙니다.

**한 번에 한 문장씩 넣으세요.** 화면이 바뀌는 것을 보고 다음으로 갑니다.
여러 개를 한꺼번에 넣으면 어디서 틀어졌는지 알 수 없습니다.

**사람마다 다른 화면이 나옵니다.** 실패가 아니라 정상입니다.
Claude가 매번 똑같이 만들지 않습니다.

**숫자가 나오면 출처를 물어보세요.** `이 숫자 어디서 온 거야?` 한 마디면 됩니다.
출처를 못 대는 숫자는 쓰지 않습니다.

## 새 실습을 추가할 때 (강사용)

폴더를 하나 만들고 그 안에 넣습니다.

```
주식실습/
├── README.md            ← 이 파일. 표에 한 줄 추가
├── 한국테마레이더/
│   ├── 한국테마레이더.md
│   └── theme-radar-edu-full.html
└── (새 실습)/
    └── (새 실습).md
```

폴더 이름과 문서 이름을 같게 씁니다. 나중에 찾기 쉽습니다.
