# 엑셀 다중선택 탐색 시트

**조건을 겹쳐 좁히면 결과가 화면 위쪽에 바로 펼쳐지는 엑셀**을 Claude 가 직접 만들어 주는 실습입니다.
파일을 새로 쓰는 게 아니라, **열려 있는 엑셀을 움직입니다.**

## 먼저 알아두실 것

**예제는 가상 자료입니다.** 기관명·사건번호·금액은 모두 임의로 만들었고 주소는 동까지만 남겼습니다.
실제 물건과 아무 관련이 없으니 **데이터 자체에는 의미를 두지 마십시오.**

**엑셀 앱이 있어야 제대로 열립니다.** 휴대폰에서는 슬라이서가 동작하지 않을 수 있습니다. **PC 에서 눌러 보시길 권합니다.**

## 슬라이서를 살리려면

같은 파일을 python 으로 열었다 저장하면 **슬라이서가 통째로 날아갑니다.**
그래서 Excel(Windows) MCP 로 **실제 엑셀을 띄워** 조작합니다. 이 차이가 이 실습의 핵심입니다.
