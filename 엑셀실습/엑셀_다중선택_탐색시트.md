# 엑셀 「다중선택 탐색 시트」 — Claude가 만든 것

조건을 여러 개 겹쳐 누르면 **결과 목록이 화면 위쪽에 바로 펼쳐지는** 엑셀입니다.
필터를 걸고 스크롤을 내려 찾을 필요가 없습니다.

> **이 문서는 엑셀 기능 이야기입니다.** 예제로 쓴 자료가 경매 물건이긴 하지만,
> 경매를 설명하려는 문서가 아닙니다. **어떤 목록형 자료에도 똑같이 쓸 수 있습니다.**
> 회원 명부, 매출 내역, 재고 목록, 거래처 리스트 — 열이 여러 개인 표라면 무엇이든 됩니다.

---

## 어떻게 만들어졌나

사람이 한 일은 **말로 시킨 것뿐**입니다.

| 단계 | 누가 | 무엇을 |
|---|---|---|
| 1 | Claude | **크롬 브라우저를 직접 열어** 자료 사이트에 접속 |
| 2 | Claude | 조건을 넣어 검색하고 **목록을 통째로 긁어옴** |
| 3 | Claude | **엑셀을 직접 실행해** 표·슬라이서·피벗·수식을 만듦 |
| 4 | Claude | 서식·숫자 형식까지 맞추고 저장 |

**둘 다 Claude 데스크탑에 붙인 도구로 한 것입니다.**

- 브라우저 조작 → **Claude in Chrome** (또는 playwright MCP)
- 엑셀 조작 → **Excel (Windows) MCP** — 실제로 엑셀 창을 띄워 셀을 쓰고 슬라이서를 얹습니다

화면에서 엑셀이 저절로 움직이는 것을 볼 수 있습니다. 매크로가 아니라 **엑셀 자체를 조종**하는 것입니다.

---

## 시트 세 장의 구실

| 시트 | 무엇 |
|---|---|
| **탐색** | 슬라이서를 눌러 조건을 좁히면 결과가 위쪽에 펼쳐집니다 |
| **피벗집계** | 항목별 건수·합계를 교차표로 |
| **대시보드** | 한 장 요약 |

---

## 핵심은 네 가지 기능의 조합

### ① 표 (ListObject)

원본 자료를 그냥 셀에 두지 않고 **「표」로 지정**합니다. 이게 출발점입니다.
표로 만들면 행이 늘어도 수식·피벗·슬라이서가 **자동으로 따라옵니다.**

> 만드는 법 — 자료 아무 칸이나 누르고 `Ctrl + T`

### ② 슬라이서

표에 붙이는 **버튼 상자**입니다. 필터 화살표를 누르고 목록을 뒤지는 대신,
버튼을 눌러 켜고 끕니다. **여러 개를 겹쳐 누를 수 있는 것**이 핵심입니다.

이 예제에는 슬라이서가 일곱 개 붙어 있습니다.
하나를 누르면 나머지 슬라이서에서 **해당 없는 항목이 흐려집니다.** 조합이 없는 조건을 미리 알려주는 것입니다.

> 만드는 법 — 표를 누르고 `삽입 → 슬라이서`
> 해제 — 슬라이서 오른쪽 위 **지우개 아이콘**

### ③ FILTER 수식으로 결과를 끌어올리기

슬라이서만 쓰면 결과가 **원본 표가 있는 자리에서** 걸러집니다.
원본이 500행 아래에 있으면 매번 거기까지 내려가야 합니다.

그래서 원본 표를 **아래로 내려두고**, 화면 위쪽에 `FILTER` 수식을 두어
**걸러진 결과만 위로 끌어올립니다.** 결과 건수가 늘고 줄면 표시 영역도 저절로 늘고 줄어듭니다.

```
=FILTER(표범위, 보조열=1)
```

이런 식으로 한 칸에만 넣으면 아래·오른쪽으로 **저절로 펼쳐집니다.** 이것을 **스필(spill)** 이라고 합니다.

### ④ SUBTOTAL 로 「지금 보이는 것만」 세기

`SUM` 은 숨겨진 행까지 전부 더합니다. **`SUBTOTAL` 은 화면에 보이는 행만** 계산합니다.
그래서 슬라이서를 누를 때마다 상단의 건수·합계·평균이 **즉시 따라 움직입니다.**

```
=SUBTOTAL(103, 범위)   → 보이는 행만 개수
=SUBTOTAL(109, 범위)   → 보이는 행만 합계
```

이 네 가지가 맞물리면 **버튼 몇 개로 몇백 건을 몇 건으로 좁히고, 그 결과가 곧바로 위에 뜨는** 시트가 됩니다.

## 예제 파일

| 파일 | 내용 |
|---|---|
| [엑셀_다중선택_탐색시트_예제.xlsx](엑셀_다중선택_탐색시트_예제.xlsx) | 슬라이서 7개 · 피벗 3개 · 32건 |

**받는 법** — 파일 이름을 누른 뒤 오른쪽 위 **다운로드 버튼(아래쪽 화살표)**.
파일 이름에 오른쪽 버튼으로 저장하면 엉뚱한 파일이 받아집니다.

> ### 이 예제는 32건만 들어 있습니다
>
> **엑셀 기능을 보여드리려고 줄인 것입니다.** 원본은 181건이었고,
> 네 종류 금융기관에서 **8건씩만 골라 32건**을 남겼습니다.
> 슬라이서를 눌러볼 수 있을 만큼만 남긴 것이니 **자료 내용 자체에는 의미를 두지 마십시오.**
>
> 이름은 원본 사이트에서 이미 `○○○` 로 가려진 상태 그대로입니다.

**열어보면 이렇게 해보세요.**

1. 위쪽 슬라이서에서 **채권자 구분** 하나를 눌러봅니다 → 아래 목록이 줄어듭니다
2. **용도군**을 하나 더 눌러봅니다 → 두 조건이 겹쳐 더 줄어듭니다
3. 위쪽 **건수·합계 숫자가 같이 바뀌는지** 봅니다
4. 슬라이서 오른쪽 위 **지우개**로 해제합니다

## 내 자료로 만들어보려면

Claude 데스크탑에 **Excel (Windows) MCP** 를 붙인 뒤, 자료를 주고 이렇게 말하면 됩니다.

```
이 표로 다중선택 탐색 시트를 만들어줘.
원본 표는 아래로 내리고, 위에는 슬라이서와 결과 목록을 두고,
슬라이서를 누르면 건수와 합계가 같이 바뀌게 해줘.
```

**엑셀을 켜둔 채로 시키지 마세요.** 파일이 잠겨서 조작이 막힙니다.

> 엑셀 조작은 Claude가 실제 엑셀 창을 띄워 하는 일이라, 시키는 동안 화면에서 엑셀이 움직입니다.
> 「지켜보기」로 두면 무엇을 하는지 눈으로 볼 수 있고, 숨겨두면 더 빠릅니다.
